# UVa 10420 - List of Conquests


## 題目簡述

計算 Don Juan 在各個國家分別認識了多少位女人，並將國家名稱依英文字母順序排列輸出。<br>
給定 $n$ 行字串，每行的第一個單字代表「國家」，後面的文字則代表「女人的名字」。<br>
請統計每個國家出現的次數，並按字母順序輸出國家名稱與對應的次數。

**Sample Input**：

  **3**  $\rightarrow$ 測資數量。<br>
  **Spain Donna Elvira**  $\rightarrow$ 第一個單字是國家，後面的字串是人名。<br>
  **England Jane Doe**<br>
  **Spain Donna Anna**

**Sample Output**：

  **England 1**  $\rightarrow$ 依據國家名稱的英文字母順序排列。<br>
  **Spain 2**    $\rightarrow$ 輸出國家名稱與對應的次數，中間以一個空白隔開。


## 程式碼


利用 **map<string, int>** 來紀錄並統計國家的出現次數。<br>
每次讀取第一個單字作為國家名稱 `cin >> country`，剩餘的整行文字利用 `getline` 讀取並忽略。<br>
最後遍歷 map，它會**自動按照國家名稱的字母順序**印出結果。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int n;
	cin>>n;
	map<string,int> countrys;
	string country,text;
	for(int i=0;i<n;i++){
		cin>>country;
		getline(cin,text);
		countrys[country]++;
	}
	for(auto const& it:countrys){ //自動把 countrys當成不能更改的常數讀取，把 value1放入name，value2放入count 
		cout<<it.first<<" "<<it.second<<endl;
	}
	return 0;
}
```
