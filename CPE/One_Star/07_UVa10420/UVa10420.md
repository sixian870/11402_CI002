# UVa 10420 - List of Conquests


## 題目簡述

給定 $N$ 行紀錄，每一行代表某位情聖在某個國家征服的一位女性。每一行的第一個單字為**國家名稱**，後面跟隨的是該名女性的名字（名字可能包含空格）。請統計他在各個國家總共征服了多少人，並將國家名稱按照**英文字母順序（字典序）**由小到大依序印出。

**Sample Input**：

  **3** $\rightarrow$ 共有 3 行紀錄。<br>
  **Spain Donna Elvira** $\rightarrow$ 國家為 Spain，女性名字為 Donna Elvira。<br>
  **England Donna Anna**<br>
  **Spain Leporello**

**Sample Output**：

  **England 1** $\rightarrow$ 依據字母排序，England 排在 Spain 前面。<br>
  **Spain 2** $\rightarrow$ Spain 總共出現了 2 次。每組輸出結果佔獨立的一行。


## 程式碼

1. **切分國家與姓名**：每一行的第一個單字是國家，後面才是姓名。本程式先使用 `cin >> country` 精準切出第一個單字，再利用 `getline(cin, text)` 把後面整行殘餘的姓名連同空格一次抓走。這樣既不會漏字，也成功分開了資料。
2. **自動排序與次數累加**：利用 `std::map<string, int>` 儲存「國家」與「出現次數」。每次讀到國家時直接執行 `countrys[country]++`。`map` 的底層會自動依據 Key（國家名稱）的字母順序排好，省去了後續手動排序的步驟。
3. **遍歷**：在輸出時，使用 C++11 的範圍 Base 迴圈（`for (auto const& it : countrys)`），搭配 `it.first`（國家）與 `it.second`（人數），能以極精簡且安全的常數唯讀方式將結果完整倒出。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int n;
	cin>>n;
	map<string,int> countrys;
	string country,text;
	for(int i=0;i<n;i++){
		cin>>country;
		getline(cin,text);
		countrys[country]++;
	}
	for(auto const& it:countrys){ //自動把 countrys當成不能更改的常數讀取，把 value1放入name，value2放入count 
		cout<<it.first<<" "<<it.second<<endl;
	}
	return 0;
}
```
