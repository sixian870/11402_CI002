# UVa 11063 - B2-Sequence


## 題目簡述

給定一個長度為 $N$ 的整數數列，請判斷它是否滿足「B2 數列」的定義：
1. **數列皆大於等於 1 且嚴格遞增**：即 $1 \le B_1 < B_2 < B_3 < \dots < B_n$。
2. **任兩數之和皆不重複**：數列中任意兩個數字相加（ **包含自己加自己**），產生的所有總和結果都必須是唯一的。

每一組測試資料輸出結束後，不論是否為最後一組，**都必須多輸出一行空白行**。

**Sample Input**：

  **4** $\rightarrow$ 數列長度 $N$。<br>
  **1 2 4 8** $\rightarrow$ 數列內容。<br>
  **4**<br>
  **3 7 10 14**

**Sample Output**：

  **Case #1: It is a B2-Sequence.** <br>
  <br>
  **Case #2: It is not a B2-Sequence.** <br>
  <br> $\rightarrow$ 每組輸出後都要有一個空行。<br>


## 程式碼

1.  在讀取時就檢查「是否 $\ge 1$」與「是否嚴格遞增」；若合格則進一步利用雙層迴圈將所有兩數之和（含自己加自己）丟進 `sum` 陣列中。<br>
2.  最後將 `sum` 排序，並檢查是否有相鄰元素相等（即總和重複），即可判定是否為 B2 數列。

```cpp
#include<iostream>
#include<vector>
using namespace std;
int main() {
	int col, row;
	cin >> col >> row;
	vector<vector<bool>> M(row + 1, vector<bool>(col + 1, false));
	int x, y;
	char d;
	while (cin >> x >> y >> d) {
		char dir[4] = { 'E','S','W','N' };
		int dx[4] = { 1,0,-1,0 };
		int dy[4] = { 0,-1,0,1 };
		string cmd;
		cin >> cmd;
		int idx;
		for (int i = 0; i < 4; i++) {
			if (dir[i] == d) {
				idx = i;
				break;
			}
		}
		bool lost = false;
		for (char c : cmd) {
			if (c == 'R') {
				idx = (idx + 1) % 4;//避免超索引範圍 index:0~3
			}
			else if (c == 'L') {
				idx = (idx + 3) % 4;//避免超索引範圍 index:0~3
			}
			else if (c == 'F') {
				if (x + dx[idx] > col || x + dx[idx] <0 || y + dy[idx]>row || y + dy[idx] < 0) {
					if (M[x][y] == true) {
						continue;
					}
					else {
						M[x][y] = true;
						lost = true;
						break;
					}
				}
				else {
					x += dx[idx];
					y += dy[idx];
				}
			}
		}
		if (lost) {
			cout << x << " " << y << " " << dir[idx] << " LOST\n";
		}
		else {
			cout << x << " " << y << " " << dir[idx] << "\n";
		}
	}
	return 0;
}
```
