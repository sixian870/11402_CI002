# UVa 10062 - Tell me the frequencies!


## 題目簡述

給定一行字串（可能包含空格與各式各樣的字元），統計這段文字中每一個字元出現的次數（頻率），並輸出每個字元的 **ASCII 碼**與其**出現次數**。

**排序與輸出規則**：
1. **排序規則**：
  - 優先依照**出現次數由小到大**排序（升序）。
  - 若出現次數相同，則依照**ASCII 碼由大到小**排序（降序）。
2. **空行要求**：**每兩組測試資料的輸出之間，必須以一個空行隔開**。最後一組測資的結尾則不用多留空行。

**Sample Input**：

  **AAABBC** $\rightarrow$ 第一個測資。<br>
  **122333**

**Sample Output**：

  **67 1** $\rightarrow$ 'C' 出現 1 次（ASCII 67）。<br>
  **66 2** $\rightarrow$ 'B' 出現 2 次（ASCII 66）。<br>
  **65 3** $\rightarrow$ 'A' 出現 3 次（ASCII 65）。<br>
  <br> $\rightarrow$ **兩組測資輸出之間必須有一個空行！** <br>
  **49 1** $\rightarrow$ '1' 出現 1 次（ASCII 49）。<br>
  **50 2** $\rightarrow$ '2' 出現 2 次（ASCII 50）。<br>
  **51 3** $\rightarrow$ '3' 出現 3 次（ASCII 51）。<br>
  $\rightarrow$ **最後一個測資不用空行** <br>


## 程式碼

1. 利用一個自訂結構 `Data` 儲存字元的 ASCII 碼與出現次數。
2. 透過自訂的比較函式 `cmp` 來精確控制排序邏輯：若次數不同則次數小的排前面；若次數相同則 ASCII 碼大的排前面。
3. 在 `main` 函式中，利用 `firstline` 標記來控制「只有在兩組輸出之間才印出空行」的格式要求。

> 某些測試資料可能包含擴展 ASCII 字元，在作為陣列索引時，必須強轉成 `(unsigned char)` 才能防止索引值變成負數而導致 Runtime Error。

```cpp
#include<bits/stdc++.h>
using namespace std;
struct Data{
	int ascii;
	int count;
};
bool cmp(Data a,Data b){
	if(a.count!=b.count) return a.count<b.count;
	return a.ascii>b.ascii;
}
int main(){
	string s;
	bool firstline=true;
	while(getline(cin,s)){
		if(!firstline) cout<<endl;
		firstline=false;
		int arr1[256]={0};
		for(char c:s){
			arr1[(unsigned char)c]++;
		}
		vector<Data> arr2;
		for(int i=0;i<256;i++){
			if(arr1[i]!=0){
				arr2.push_back({i,arr1[i]}); //ascii=i,count=arr1[i]
			}
		}
		sort(arr2.begin(),arr2.end(),cmp);
		for(auto n:arr2){
			cout<<n.ascii<<" "<<n.count<<endl;
		}
	}
	return 0;
}
```
