# UVa 10190 - Divide, But Quite Conquer!


## 題目簡述

給定兩個正整數 $n$ 與 $m$，我們要檢查是否可以透過不斷將 $n$ 除以 $m$（即 $n, n/m, n/m^2, \dots$）一路完美整除，直到最後結果剛好變成 1。<br>
如果在除法的過程中任何一步出現無法整除的情況，或者輸入的數值不符合合理的除數範圍（如 $m < 2$ 或 $n < 2$），則直接判定為無趣的序列，輸出 `Boring!`。否則，依序輸出這條除法數列，中間以一個空白隔開。

**Sample Input**：

  **125 5** $\rightarrow$ 每行包含兩個正整數 $n$ 與 $m$ 。<br>
  **30 3**<br>
  **80 2**<br>
  **81 3**

**Sample Output**：

  **125 25 5 1** $\rightarrow$ $125 \rightarrow 25 \rightarrow 5 \rightarrow 1$ 皆完美整除，印出數列。<br>
  **Boring!** $\rightarrow$ $30 / 3 = 10$，但 $10$ 無法被 $3$ 整除，故判定為 Boring!。<br>
  **Boring!** $\rightarrow$ $80 / 2 = 40 \rightarrow 20 \rightarrow 10 \rightarrow 5$，但 $5$ 無法被 $2$ 整除，故判定為 Boring!。<br>
  **81 27 9 3 1**  $\rightarrow$ $81 \rightarrow 27 \rightarrow 9 \rightarrow 3 \rightarrow 1$ 皆完美整除，印出數列。


## 程式碼

1. 當 $m < 2$ 時（例如 $m = 1$ 或 $m = 0$），會造成無窮迴圈或除以 0 的錯誤，必須直接判定為 `Boring!`。
2. 利用 `vector` 可以在 `while` 迴圈內一邊檢查 `temp % m == 0`，一邊把除完的結果 `push_back` 進去，只要中途有一次失敗就提前結束並印出 `Boring!`。

```cpp
#include <iostream>
#include <vector>

using namespace std;

void solve(long long n, long long m) {
    // 邊界條件：m < 2 是無效的，且 n 必須大於 0
    if (m < 2 || n < 2) {
        cout << "Boring!" << endl;
        return;
    }
    vector<long long> result;
    long long temp = n;

    while (temp > 1) {
        if (temp % m != 0) {
            cout << "Boring!" << endl;
            return;
        }
        temp /= m;
        result.push_back(temp);
    }

    cout << n;
    for (long long val : result) {
        cout << " " << val;
    }
    cout << endl;
}

int main() {
    long long n, m;
    while (cin >> n >> m) {
        solve(n, m);
    }
    return 0;
}
```
