# UVa 10642 - Can You Solve It?


## 題目簡述

在一個二維座標平面上（僅限 $x \ge 0, y \ge 0$ 的區域），有一條無限延伸的單行道路線。<br>
這條路線從 $(0,0)$ 出發，並依據「右上到左下」的斜線方向一條接一條地蛇行移動：

<img width="280" alt="螢幕擷取畫面 2026-06-07 193525" src="https://github.com/user-attachments/assets/e3285896-8039-4674-8c37-cfe3386df2d4" />

題目會給定起點座標 $(x_1, y_1)$ 與終點座標 $(x_2, y_2)$，請計算出順著這條路線規則，從起點走到終點一共需要移動多少步？

**Sample Input**：

  **3** $\rightarrow$ 測資數量。<br>
  **0 0 0 1** $\rightarrow$ 第一組：起點 (0,0)，終點 (0,1)。<br>
  **0 0 1 0** $\rightarrow$ 第二組：起點 (0,0)，終點 (1,0)。<br>
  **0 0 0 2** $\rightarrow$ 第三組：起點 (0,1)，終點 (0,2)。

**Sample Output**：

  **Case 1: 1** $\rightarrow$ 從 (0,0) 到 (0,1) 需走 1 步。<br>
  **Case 2: 2** $\rightarrow$ 從 (0,0) 到 (1,0) 需走 2 步。<br>
  **Case 3: 3** $\rightarrow$ 從 (0,1) 到 (0,2) 需走 3 步。。


## 程式碼

```
y 軸
▲
│ (0,3)[6]
│ (0,2)[3]  (1,2)[7]
│ (0,1)[1]  (1,1)[4]  (2,1)[8]
│ (0,0)[0]  (1,0)[2]  (2,0)[5]  (3,0)[9]
└───────────────────────────────────────────► x 軸
input:起始點與終點
output:路徑距離
x+y=
0:1
1:2
2:3
3:4
x+y=s:s-1
if start=(1,0) end=(2,1)
(0,0)~(1,0)=1+(1)=2
(0,0)~(2,1)=1+2+3+(2)=8
(1,0)~(2,1)=1+2+3+(2)-1-(1)+1=2+3+(2)-(1)=8-2=6
if start=(a,b) end=(c,d)
(0,0)~(a,b)=1+...+(a+b)+(a)
(0,0)~(c,d)=1+...+(c+d)+(c)
(a,b)~(c,d)=(a+b+1)+...+(c+d)+(c)-(a)
```

> `long long ans` 避免溢位

```cpp
#include<iostream>
using namespace std;
int main() {
	int t;
	cin >> t;
	int count = 1;
	while (t--) {
		long long a, b, c, d;
		long long ans = 0;
		cin >> a >> b >> c >> d;
		for (int i = a + b + 1; i <= c + d; i++) {
			ans += i;
		}
		ans = ans + c - a;
		cout << "Case " << count++ << ": " << ans << "\n";
	}
	return 0;
}
```
