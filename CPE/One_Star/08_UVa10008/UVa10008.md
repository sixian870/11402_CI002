# UVa 10008 - What's Cryptanalysis?


## 題目簡述

讀取數行文字，並計算其中每個英文字母出現的次數。<br>
統計時一律視為大寫，且忽略所有非英文字母的字元（如數字、標點符號與空白）。<br>
最後的輸出必須依照字母出現的「次數」由大到小排序；若有字母出現的次數相同，則依據該字母的「ASCII 碼（字母順序）」由小到大排列輸出。

**Sample Input**：

  **3**  $\rightarrow$ 測資數量。<br>
  **This is a test.**  $\rightarrow$ 測資包含大小寫字母、數字、空格與標點符號。<br>
  **Count me 1 2 3 4 5.** <br>
  **Wow!!!! Is this question easy?**

**Sample Output**：

  **S 7**<br>
  **T 6**<br>
  **I 5**<br>
  **E 4**<br>
  **O 3**<br>
  **A 2**<br>
  **H 2**<br>
  **N 2**<br>
  **U 2**<br>
  **W 2**<br>
  **C 1**<br>
  **M 1**<br>
  **Q 1**<br>
  **Y 1**


## 程式碼

1.	宣告一個 struct 來同時儲存字母與其出現次數。<br>
2.	讀取文字時，利用 `isalpha()` 判斷是否為字母，並用 `toupper()` 統一轉為大寫後統計次數。
3.	最後透過自訂的 compare 函式搭配 sort()，完成「先依次數遞減排序，次數相同再依字母順序遞增排序」的要求。

```cpp
#include<bits/stdc++.h>
using namespace std;
struct Data{
	char name;
	int count;
};
bool compare(Data a,Data b){
	if(a.count!=b.count){ //次數不一樣 
		return a.count>b.count; //回傳次數多的在前面 
	}
	else{ //次數一樣
		return a.name<b.name; //回傳 ASCII碼小的在前面 
	}
}
int main(){
	int n; //行數
	cin>>n;
	cin.ignore();
	
	vector<Data> alpha(26); //不能設為 0要錄入字母 
	for(int i=0;i<26;i++){
		alpha[i].name='A'+i;
		alpha[i].count=0;
	}
	
	string line;
	while(n--){ //有幾行就執行幾次 
		getline(cin,line);
		for(char c:line){
			if(isalpha(c)){
				c=toupper(c);
				alpha[c-'A'].count++;
			}
		}
	}
	sort(alpha.begin(),alpha.end(),compare);
	
	for(int j=0;j<26;j++){
		if(alpha[j].count>0){
			cout<<alpha[j].name<<" "<<alpha[j].count<<endl;
		}
	}
	return 0;
}
```
