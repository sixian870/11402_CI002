# UVa 10415 - Eb Alto Saxophone Player


## 題目簡述

演奏中音薩克斯風（Eb Alto Saxophone）時，總共有 10 個按鍵需要用 10 隻手指頭來控制（左手 5 隻、右手 5 隻，編號分別為 1 到 10）。<br>
給定一串要演奏的音符字串（包含低音與高音的 `c, d, e, f, g, a, b, C, D, E, F, G, A, B`），計算在演奏完整首歌曲的過程中，**這 10 隻手指頭各自「按下去（press）」了多少次**？

**狀態轉移**：
1. **維持按著不計數**：如果換下一個音符時，某隻手指本來就是按著的，且新音符也需要它，那它只需要「繼續按著」就好，不需要放開再重按（此時按下去的次數**不增加**）。
2. **觸發計數條件**：只有當某個手指在上一刻是放開的（`pressed[i] == false`），而新音符需要它按下去（`next[i] == true`）時，該手指的計數器才加 1。

**Sample Input**：

  **3** $\rightarrow$ 測資數量 $t$。<br>
  **cdefgab** $\rightarrow$ 第一首歌曲的音符字串。<br>
  **BAGFEDC**
  **CbCaDCbCbCCbCbabCCbCbabae**

**Sample Output**：

  **0 1 1 1 0 0 1 1 1 1** $\rightarrow$ 第一首歌曲 10 隻手指各自按下的總次數。<br>
  **1 1 1 1 0 0 1 1 1 0**
  **1 8 10 2 0 0 2 2 1 0**


## 程式碼

1. 利用 `map<char, vector<int>>` 建立每個音符與其所需按鍵編號的對應表。
2. 透過 `getline` 讀取歌曲，並使用兩個布林陣列：`pressed` 記錄目前的按鍵狀態，`next` 記錄下一個音符的按鍵狀態。
3. 當發現 `next[i] == true` 且 `pressed[i] == false` 時，代表手指執行了「按下去」的動作，對應的 `count` 陣列便加 1。
4. 每演奏完一個音符，便將狀態更新（`pressed = next`）。

```cpp
#include<bits/stdc++.h>
using namespace std;

map<char, vector<int>> finger = {
	{'c',{2,3,4,7,8,9,10}},
	{'d',{2,3,4,7,8,9}},
	{'e',{2,3,4,7,8}},
	{'f',{2,3,4,7}},
	{'g',{2,3,4}},
	{'a',{2,3}},
	{'b',{2}},
	{'C',{3}},
	{'D',{1,2,3,4,7,8,9}},
	{'E',{1,2,3,4,7,8}},
	{'F',{1,2,3,4,7}},
	{'G',{1,2,3,4}},
	{'A',{1,2,3}},
	{'B',{1,2}}
};

int main() {
	int t;
	cin >> t;
	cin.ignore();
	while (t--) {
		string s;
		//cin >> s;可能含有空字串(空行)
		getline(cin, s);
		vector<int> count(10, 0); //index 0~9
		vector<bool> pressed(11, false); //index 1~10
		for (char c : s) {
			vector<int> now = finger[c];
			vector<bool> next(11, false);
			for (int i : now) {
				next[i] = true;
			}
			for (int i = 1; i <= 10; i++) {
				if (next[i] == true && pressed[i] == false) {
					count[i - 1]++;
				}
			}
			pressed = next;
		}
		for (int i = 0; i < 10; i++) {
			cout << count[i] << (i == 9 ? "" : " ");
		}
		cout << endl;
	}
	return 0;
}
```
