# UVa 10268 - 498-bis


## 題目簡述

給定一個整數 $x$ 以及一個多項式 $P(x)$ 的各項係數，你的任務是計算該多項式的一階導數（導函數）在 $x$ 點的值，也就是求出 $P'(x)$ 的解。<br>
多項式形式為： $P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$ <br>
其一階導函數為： $P'(x) = n \cdot a_n x^{n-1} + (n-1) \cdot a_{n-1} x^{n-2} + \dots + 1 \cdot a_1$

**Sample Input**：

  **7**  $\rightarrow$ x=7。<br>
  **1 -1**  $\rightarrow$ 包含多項式從最高次到常數項的係數。<br>
  **3**<br>
  **1 2 3**

**Sample Output**：

  **1**    $\rightarrow$  $P(x) = x - 1 \rightarrow P'(x) = 1$，代入 $x=7$ 得到 1。<br>
  **8**    $\rightarrow$  $P(x) = x^2 + 2x + 3 \rightarrow P'(x) = 2x + 2$，代入 $x=3$ 得到 8。


## 程式碼

1.  因為不知道要讀幾個數字，所以要利用 stringstream 與 vector 動態讀取未知數量的多項式係數。
2.  3 $\rightarrow$ x=3 $\rightarrow$ size()=3
3.  1 2 3 $\rightarrow$ a[0]=1,a[1]=2,a[2]=3
4.  $f(x) = 1 x^2 + 2 x^1 + 1 x^0 = x^2 + 2x + 1$ $\rightarrow$ $a[0] x^{a.size() - 1}$
5.  $f'(x) = 1* 2 x^1 + 2* 1 x^0 + 0 = 2x + 2$ $\rightarrow$ $a[0] (size()-1) x^{a.size()-2} + a[1] (size()-2) x^{a.size()-3}$
6.  $f'(3) = 2 (3) + 2 = 8$

> 要用 `long long`

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	long long x;
	while(cin>>x){
		cin.ignore();
		string num;
		getline(cin,num);
		stringstream ss(num);
		long long c;
		vector<long long> a;
		while(ss>>c){
			a.push_back(c);
		}
		long long n=a.size()-1;
		long long total=0;
		//a[0]*(n)*x^(n-1)+a[1]*(n-1)*x^(n-2)
		for(int i=0;i<n;i++){
			total=total*x+a[i]*(n-i);
		}
		cout<<total<<"\n";
	}
	return 0;
}
```
