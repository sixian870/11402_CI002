## 程式碼

1. 樹木名稱中可能包含空格（例如 `Red Pine`），因此不能使用 `cin >>` 讀取，必須使用 `getline(cin, s)` 讀取一整行。
2. 在讀入測資組數 $t$ 之後，輸入緩衝區內會殘留一個換行符號，用 `cin.ignore()` 清除，再用 `getline(cin, s)`處理第一組測資前的空白行。
3. 利用 `std::map<string, int>` 的特性在遍歷輸出時，自動以 Key（樹名）的字母順序由小到大輸出。

```cpp
#include<iostream>
#include<string>
#include<map>
#include<iomanip>
using namespace std;
int main() {
	int t;
	cin >> t;
	cin.ignore();
	string s;
	getline(cin, s); //第一個space
	bool isFirst = true;
	while (t--) {
		map<string, int> tree;
		int total = 0;
		while (getline(cin, s) && !s.empty()) { //後續space
			tree[s]++;
			total++;
		}
		if (!isFirst) cout << "\n";
		for (auto const& i : tree) { //map自動排序
			cout << i.first << " " << fixed << setprecision(4) << (double)i.second / total * 100 << endl;
		}
		isFirst = false;
	}
	return 0;
}
```
