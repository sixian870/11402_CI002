# UVa 10050 - Hartals


## 題目簡述

在一個國家中，有許多政黨會發起罷工（Hartals）。每個政黨都有一個固定的罷工週期參數 $h$，代表該政黨每隔 $h$ 天就會發起一次罷工（也就是在第 $h, 2h, 3h \dots$ 天進行罷工）。<br>
已知模擬從**星期日**開始算作第一天（Day 1），因此：
- 星期日 $\rightarrow$ Day 1, 8, 15...
- 星期五 $\rightarrow$ Day 6, 13, 20... （滿足 $i \pmod 7 == 6$）
- 星期六 $\rightarrow$ Day 7, 14, 21... （滿足 $i \pmod 7 == 0$）

題目會給定總天數 $d$ 以及各政黨的罷工週期，請計算在這些天數中，**扣除掉星期五與星期六（週末不屬於工作日）之後**，總共因為罷工而浪費了多少個工作日？

**Sample Input**：

  **1** $\rightarrow$ 測資組數 $t$。<br>
  **14** $\rightarrow$ 總模擬天數 $d$。<br>
  **3** $\rightarrow$ 政黨的數量 $n$。<br>
  **3** $\rightarrow$ 政黨 1 的罷工參數（每 3 天罷工一次）。<br>
  **4** $\rightarrow$ 政黨 2 的罷工參數（每 4 天罷工一次）。<br>
  **8** $\rightarrow$ 政黨 3 的罷工參數（每 8 天罷工一次）。

**Sample Output**：

  **5** $\rightarrow$ 在 14 天內，第 3, 4, 8, 9, 12 天為遭到浪費的工作日（第 6 天因是五、第 14 天因是六而扣除）。
  ```
  算浪費幾天工作日，從星期日開始，五六不算!!!
  Su Mo Tu We Th Fi Sa Su Mo Tu We Th Fi Sa
        a        x        a        a
           b           b           b
                       c
  Total: 5
  ```


## 程式碼

1.  利用一個布林陣列 `totalday` 模擬總天數，檢查每天是否符合任一政黨的罷工週期，若符合則標記為 `true`。
2.  接著利用 `% 7` 的餘數特性判定該天是否為五或六，若是週末則強制變更回 `false`。
3.  最後重新統計陣列中為 `true` 的天數總和即為答案。

```cpp
#include<iostream>
#include<vector>
using namespace std;
int main() {
    int t;
    cin >> t;
    while (t--) {
        int count = 0;
        int d, n;
        cin >> d >> n;
        vector<bool> totalday(d + 1, false); //index = 1~d // false: 工作日, true: 休息日
        vector<int> p(n);
        for (int i = 0; i < n; i++) {
            cin >> p[i];
        }
        for (int i = 1; i <= d; i++) { // 1-n day
            for (int j = 0; j < n; j++) { // p[j]
                if (i % p[j] == 0) {
                    totalday[i] = true;
                    if (i % 7 == 6 || i % 7 == 0) {
                        totalday[i] = false; // 五六
                    }
                }
            }
        }
        for (int i = 1; i <= d; i++) {
            if (totalday[i] == true) {
                count++;
            }
        }
        cout << count << "\n";
    }
    return 0;
}
```
