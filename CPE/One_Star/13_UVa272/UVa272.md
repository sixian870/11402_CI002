# UVa 272 - TEX Quotes


## 題目簡述

在排版軟體 $\text{T}_{\text{E}}\text{X}$ 中，雙引號有特殊的呈現方式，標準的雙引號 `"` 必須被交替替換：
* 第一次（奇數次）出現的雙引號 `"` 轉換為兩個反單引號 ` `` `
* 第二次（偶數次）出現的雙引號 `"` 轉換為兩個正單引號 `''`

其餘字元（包含空白與換行）原樣輸出。

**Sample Input**：

  **"To be or not to be," quoth the Bard, "that** <br>
  **is the question".** <br>
  **The programming contestant replied: "I must disagree.** <br>
  **To \`C' or not to \`C', that is The Question!"**

**Sample Output**：

  **\`\`To be or not to be,'' quoth the Bard, \`\`that** <br>
  **is the question''.** <br>
  **The programming contestant replied: ``I must disagree.** <br>
  **To \`C' or not to \`C', that is The Question!''**


## 程式碼

1.  利用一個計數變數 count 來紀錄當前雙引號出現的是奇數次還是偶數次。
2.  每次讀取到 " 時，將 count 狀態切換：若為奇數次則輸出 ``` ，偶數次則輸出 ''`，其餘字元則直接印出。

* 字串
```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	string text;
	int count=0;
	
	while(getline(cin,text)){
		for(int i=0;i<text.length();i++){
			if(text[i]=='"'){
				count=(count+1)%2;
				if(count==1){
					cout<<"``";
				}
				if(count==0){
					cout<<"''";
				}
			}
			else{
				cout<<text[i];
			}
		}
		cout<<endl;//getline要換行 
	}
}
```

* 字元
```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	char text;
	int count=0;
	
	while(cin.get(text)){//完整讀取 text包括空白與換行,cin>>text會跳過空白與換行 
		if(text=='"'){
			count=(count+1)%2;
			if(count==1){
				cout<<"``";
			}
			if(count==0){
				cout<<"''";
			}
		}
		else{
			cout<<text;
		}
	}
	return 0;
}
```
