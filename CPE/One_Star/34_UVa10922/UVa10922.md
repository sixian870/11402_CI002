# UVa 10922 - 2 the 9s


## 題目簡述

給定一個正整數，請判斷它是不是 9 的倍數。如果是的話，還要進一步求出它的「9-degree（9次數）」。

**Sample Input**：

  **999999999999999999999** $\rightarrow$ 輸入一個超大正整數（長度可達 1000 位數）。<br>
  **9**<br>
  **9999999999999999999999999999998** <br>
  **0** $\rightarrow$ 輸入 0 時，測試結束。

**Sample Output**：

  **999999999999999999999 is a multiple of 9 and has 9-degree 3.** $\rightarrow$ 21 個 9 相加為 189 $\rightarrow$ 1+8+9=18 $\rightarrow$ 1+8=9，共 3 次。<br>
  **9 is a multiple of 9 and has 9-degree 1.** $\rightarrow$ 本身即為 9 的倍數，9-degree 為 1。<br>
  **9999999999999999999999999999998 is not a multiple of 9.**  $\rightarrow$ 30 個 9 加 8 為 278 $\rightarrow$ 不為 9 的倍數。


## 程式碼

1. 建立一個 `getsum` 函式將字串中的每個字元扣掉 `'0'` 轉為數值後加總。
2. 在 `main` 函式中，若初次得到的 `sum` 無法被 9 整除，直接印出不是 9 的倍數。
3. 若能整除，則將 `degree` 預設為 1，並利用 `while(sum != 9)` 迴圈，持續透過 `% 10` 與 `/ 10` 拆解並重新計算各位數之和，直到 `sum` 剛好等於 9 為止，每跑一次迴圈便將次數加 1。

> **數學原理與規則**：
> 1. **9的倍數判別法**：如果一個數字的「所有數位（digits）相加總和」是 9 的倍數，那這個數字本身就一定是 9 的倍數。
> 2. **9-degree 的定義**：將一組數字的各位數全部相加後，如果結果還不是 9，就繼續把新結果的各位數再度相加，直到最後的結果等於 9 為止。**總共進行加總的次數**就是它的 9-degree。
>    - 例如數字 `9`：加總 0 次（本身就是 9），但依題目定義其 9-degree 為 1。
>    - 例如數字 `99`：第一次加總 $9+9=18$，第二次加總 $1+8=9$，總共加了 2 次，所以 9-degree 為 2。
> * 題目給定的數字可能**長達 1000 位數**！這遠遠超出了 `long long` 的極限，因此**絕對要用字串（`string`）來讀取**。

```cpp
#include<iostream>
using namespace std;

int getsum(string s) {
	int sum = 0;
	for (char c : s) {
		sum += (c - '0');//string  int
	}
	return sum;
}
int main() {
	string s;
	while (cin >> s && s != "0") {
		int sum = getsum(s);
		if (sum % 9 != 0) {
			cout << s << " is not a multiple of 9.\n";
		}
		else {
			int degree = 1;
			while (sum != 9) {//sum=180
				int digit = 0;
				int temp_sum = sum;
				while (temp_sum > 0) { //temp_sum=180
					digit += (temp_sum % 10);
					temp_sum /= 10;
				}
				sum = digit;
				degree++;
			}
			cout << s << " is a multiple of 9 and has 9-degree " << degree << ".\n";
		}
	}
	return 0;
}
```
