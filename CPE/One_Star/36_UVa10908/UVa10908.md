# UVa 10908 - Largest Square


## 題目簡述

給定一個 $M \times N$ 的字元網格，並提供 $Q$ 個詢問。<br>
每個詢問會給定一個網格內的中心點座標 $(\text{row}, \text{col})$。<br>
**求出以該點為中心，且正方形範圍內所有字元都與中心點字元完全相同的最大正方形「邊長」是多少？**

**Sample Input**：

  **1** $\rightarrow$ 測資組數 $T$。<br>
  **7 10 4** $\rightarrow$ 第一組網格列數 $M$、行數 $N$、詢問數 $Q$。<br>
  **abbbaaaaaa** $\rightarrow$ 網格內容。<br>
  **abbbaaaaaa**<br>
  **abbbaaaaaa**<br>
  **aaaaaaaaaa**<br>
  **aaaaaaaaaa**<br>
  **aaccaaaaaa**<br>
  **aaccaaaaaa**<br>
  **1 2** $\rightarrow$ 詢問的中心點座標 $(\text{row}, \text{col})$。<br>
  **2 4**<br>
  **4 6**<br>
  **5 2**

**Sample Output**：

  **7 10 4** $\rightarrow$ 每一組 Case 開始前，必須原封不動印出該組的 $M, N, Q$。<br>
  **3** $\rightarrow$ 以 (1, 1) 為中心的最大同字元正方形邊長為 3（即整個 $3 \times 3$ 區間皆為 `'b'`）。<br>
  **1**<br>
  **5**<br>
  **1**


## 程式碼

1. 先用動態陣列讀取地圖。
2. 因為規定 $(\text{row}, \text{col})$ 必須是正方形的「唯一中心點」，所以可能的邊長依序為 $1, 3, 5, 7, \dots$。初始狀態下中心點自己一定符合，故邊長 `ans = 1`，嘗試擴張半徑 `r = 1`。
3. 每次企圖往外擴張一圈時，必須先檢查正方形的四個邊界是否超出網格範圍（小於 0 或大於等於 $M, N$）。若在界內，則以雙層 `for` 迴圈掃描該範圍內的所有字元。
4. 一旦在內層迴圈發現字元與中心點不同，必須將標記 `same` 設為 `false` 並執行第一道 `break`；在外層 `for` 迴圈內必須緊接著補上 `if (!same) break;` 才能徹底跳出，否則外層迴圈會繼續執行。
5. 針對每個詢問，以 ` M[row][col]` 鎖定目標字元，並在 `while(same)` 內逐步將半徑 `r` 遞增。透過雙層 `for` 迴圈點點到位地掃描 `row - r` 到 `row + r` 的正方形區間，配合精準的雙重 `break` 機制，只要某一圈完全合格，邊長 `ans` 即可順利 $+2$。

```cpp
#include<iostream>
#include<vector>
using namespace std;
int main() {
	int t;
	cin >> t;
	while (t--) {
		int m, n, tt;
		cin >> m >> n >> tt;
		vector<vector<char>> M(m, vector<char>(n));
		for (int i = 0; i < m; i++) {
			for (int j = 0; j < n; j++) {
				cin >> M[i][j];
			}
		}
		cout << m << " " << n << " " << tt << "\n";
		while (tt--) {
			int row, col;
			cin >> row >> col;
			int target = M[row][col];
			int ans = 1;
			int r = 1;
			bool same = true;
			while (same) {
				if (row - r < 0 || row + r >= m || col - r < 0 || col + r >= n) {
					break;
				}
				for (int i = row - r; i <= row + r; i++) {
					for (int j = col - r; j <= col + r; j++) {
						if (M[i][j] != target) {
							same = false;
							break; //只能跳一個迴圈
						}
					}
					if (!same) break; //再跳一個迴圈
				}
				if (same) {
					ans += 2;
					r++;
				}
			}	
			cout << ans << "\n";
		}
	}
	return 0;
}
```
