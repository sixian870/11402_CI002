# UVa 490 - Rotating Sentences


## 題目簡述

將輸入的數行文字往順時針方向旋轉 90 度。也就是說，原本由左到右、由上到下的句子，要輸出成由上到下、由右到左。<br>
輸入最多不會超過 100 列，每列最多不超過 100 個字元。<br>
最後一列輸入必須垂直輸出在最左邊一行，輸入的第一列則垂直輸出在最右邊一行，若某列字串長度不足時，必須在該位置補上空白字元以維持對齊。
```
00|10|20|30    02|01|00
01|11|21    -> 12|11|10
02|12|22       22|21|20
                 |  |30
```

**Sample Input**：

  **Rene Decartes once said** <br>
  **"I think, therefore I am."**

**Sample Output**：

  **"R**<br>
  **Ie** <br>
  **_n** <br>

## 程式碼

1.  利用字串陣列 s 來依序讀取並儲存每一行文字，同時紀錄最長字串的長度 maxLen。
2.  外層迴圈以最長長度控制行數，內層迴圈則由最後一行往第一行反向讀取，若當前位置超出了該字串的長度，則輸出一個空白字元 cout << " "。

```cpp
// 00|10|20    02|01|00
// 01|11|21 -> 12|11|10
// 02|12|22    22|21|20

#include<bits/stdc++.h>
using namespace std;
int main(){
	ios::sync_with_stdio(false);
	cin.tie(0);
	
	string s[105];
	int row=0;
	int maxLen=0;
	
	while(getline(cin,s[row])){
		if(s[row].length()>maxLen){
			maxLen=s[row].length();
		}
		row++;
	}
	for(int j=0;j<maxLen;j++){
		for(int i=row-1;i>=0;i--){
			if(j<s[i].length()){
				cout<<s[i][j];
			}
			else{
				cout<<" ";
			}
		}
		cout<<endl;
	}
	return 0;
}
```
