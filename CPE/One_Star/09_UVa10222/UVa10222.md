# UVa 10222 - Decode the Mad man


## 題目簡述

解碼：密文中的每一個字元，其實際代表的字母是在標準 QWERTY 鍵盤上「向左移兩格」的字元。（例如：輸入 e 實際上是 q；輸入 d 實際上是 a）。<br>
請將輸入的密文全部還原成明文。

**Sample Input**：

  **k[r dyt I[o**  $\rightarrow$  輸入包含大小寫英文字母、鍵盤符號與空白的密文字串。

**Sample Output**：

  **how are you**  $\rightarrow$ 依據左移兩格規則解碼後的明文，字母皆以小寫輸出。


## 程式碼

1. 利用 cin.get() 逐一讀取包含空白的字元。
2. 透過 tolower() 將字元轉為小寫後，使用 string::find() 在預先建好的鍵盤字串中找出位置。
3. 若找到，則輸出位置減 2 的字元；若找不到（如空白字元），則原樣輸出。

字串
```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	//ios::sync_with_stdio(false);
	//cin.tie(0);
	string s="1234567890-=qwertyuiop[]\\asdfghjkl;'zxcvbnm,./";
	char text;
	while(cin.get(text)){
		text=tolower(text);//轉小寫
		int position=s.find(text);//回傳text在字串 s中的位置
		if(position!=string::npos){
			cout<<s[position-2];
		}
		else{
			cout<<text;
		}
	}
	return 0;
}
```
