# UVa 10235 - Simply Emirp


## 題目簡述

給定數個正整數 $N$（ $1 < N < 1,000,000$ ），判斷 $N$ 屬於以下哪一種身份：
1. **`not prime`**： $N$ 不是質數。
2. **`prime`**： $N$ 是質數，但是把它倒過來寫之後不是質數；或者倒過來寫的數值跟原本一模一樣（例如 `11`）。
3. **`emirp`**： $N$ 是質數，且倒過來寫之後變成了另一個「不同的質數」（例如 `17` 倒過來是 `71`）。

**Sample Input**：

  **17** $\rightarrow$ 本身是質數，反轉後是 71 也是質數，且兩者不相等。<br>
  **18**<br>
  **19** $\rightarrow$ 本身是質數，反轉後是 91（ $7 \times 13 = 91$ ）不是質數。<br>
  **179**<br>
  **199**

**Sample Output**：

  **17 is emirp.** <br>
  **18 is not prime.** <br>
  **19 is prime.** <br>
  **179 is emirp.** <br>
  **199 is emirp.**


## 程式碼

1. 建立 `isPrime` 函式，利用迴圈檢查整除性以判斷數字是否為質數。
2. 建立 `reverse_n` 函式，利用 `% 10` 取尾數、`* 10` 往前推進位來將整數進行反轉。
3. 讀入 $N$ 後先進行第一關過濾：若非質數直接輸出 `not prime`；若為質數則取得反轉數 `r`，並進一步比對 `n != r` 且 `isPrime(r)` 是否同時成立，區分出 `emirp` 與 `prime` 。

```cpp
#include<iostream>
using namespace std;
bool isPrime(int n) {
	if (n <= 1) return false;
	for (int i = 2; i < n; i++) {
		if (n % i == 0) {
			return false;
		}
	}
	return true;
}
int reverse_n(int n) {
	int r = 0;
	while (n != 0) {
		r = ((r * 10) + (n % 10)); //r += ((r * 10) + (n % 10));
		n /= 10;
	}
	return r;
}
int main() {
	int n;
	while (cin >> n) {
		if (!isPrime(n)) {
			cout << n << " is not prime.\n";
		}
		else {
			int r = reverse_n(n);
			if (n != r && isPrime(r)) {
				cout << n << " is emirp.\n";
			}
			else {
				cout << n << " is prime.\n";
			}
		}
	}
	return 0;
}
```
