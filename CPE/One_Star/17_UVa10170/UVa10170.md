# UVa 10170 - The Hotel with Infinite Rooms


## 題目簡述

有一間擁有無限房間的特殊旅店，旅行團會根據以下規則入住：
* 一個規模為 $S$ 的旅行團入住後會住滿 $S$ 天。當他們退房離開後，隔天立刻會有一個規模為 $S+1$ 的旅行團入住，並住滿 $S+1$ 天。依此類推，後續旅行團的規模與入住天數都會不斷加 1。

給定第一天入住的旅行團規模 $S$ 以及一個目標天數 $D$，請計算在第 $D$ 天時，住在旅店裡的旅行團人數是多少。

**Sample Input**：

  **1 6**    $\rightarrow$ $S$（初始人數）與 $D$（目標天數）。<br>
  **3 10** <br>
  **3 14**

**Sample Output**：

  **3**  $\rightarrow$  第 1 天住 1 人團（total=1）；第 2,3 天住 2 人團（total=3）；第 4,5,6 天住 3 人團（total=6 $\ge$ 6），故第 6 天為 3 人團。<br>
  **5** <br>
  **6**


## 程式碼

1.  利用內部 while(true) 迴圈將旅行團人數 s 持續累加至總天數 total。
2.  當 total 累計到大於或等於目標天數 d 時跳出迴圈，並印出此時的旅行團人數 s。
> 要用 `long long`

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	long long s,d; //要記得注意測資範圍 
	while(cin>>s>>d){//1 6
		long long total=0;
		while(true){
			total+=s;//1 3 6
			if(total>=d){//6
				break;
			}
			s++;//2 3 4
		}
		cout<<s<<endl;
	}
	return 0;
}
```
