# UVa 11461 - Square Numbers


## 題目簡述

給定兩個正整數 $a$ 與 $b$，計算在閉區間 $[a, b]$ 之間總共有多少個**完全平方數（Square Numbers）**。<br>
完全平方數是指可以寫成某個整數的平方的數字（例如：1, 4, 9, 16, 25, 36... 等）。

**Sample Input**：

  **1 4** $\rightarrow$ 每行包含兩個正整數 $a$ 與 $b$（ $0 < a \le b \le 100000$ ）。<br>
  **1 10**<br>
  **0 0** $\rightarrow$ 當 $a = 0$ 且 $b = 0$ 時，程式結束。

**Sample Output**
  
  **2** $\rightarrow$ 1 ~ 4 之間的完全平方數有 1, 4，共 2 個。<br>
  **3** $\rightarrow$ 1 ~ 10 之間的完全平方數有 1, 4, 9，共 3 個。


## 程式碼

1___a_______b 所求區間為 [a,b] = (1 到 b 的數量) - (1 到 a 之前的數量) <br>
設 $a = 36, b = 98.01$ <br>
$\sqrt{a-1} = 5.91$, $\sqrt{b} = 9.9$ <br>
$9 - 5 = 4$ <br>
$A: 6, 7, 8, 9$

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	long long a,b;
	int countA=0,countB=0;
	while(cin>>a>>b&&(a!=0||b!=0)){
		countA=floor(sqrt(a-1));
		countB=floor(sqrt(b));
		cout<<countB-countA<<endl; 
	}
	return 0;
}
```
