# UVa 11321 - Sort! Sort!! and Sort!!!


## 題目簡述

給定 $N$ 個整數以及一個除數 $M$，請將這 $N$ 個整數依照特定的規則進行排序。<br>
核心排序優先級如下：
1. **餘數大小（升序）**：優先依照每個數字除以 $M$ 的**餘數**由小到大排序（即 $X \pmod M$ 的值）。
2. **奇偶數對決（奇數在前）**：若兩個數字除以 $M$ 的餘數相同，則**奇數**必須排在**偶數**前面。
3. **同為奇數（降序）**：若兩個數字的餘數相同且**都是奇數**，則**數值較大**的奇數排在前面。
4. **同為偶數（升序）**：若兩個數字的餘數相同且**都是偶數**，則**數值較小**的偶數排在前面。

> - **負數取餘數**：在 C++ 中，負數取餘數會得到負的結果（例如 `-5 % 3 = -2`）。題目要求的餘數排序必須直接使用 C++ 內建的 `%` 運算結果（包含負數餘數）。
> - **負奇數判斷**：因為負奇數取餘數會得到 `-1`，所以判斷奇數時不能只寫 `n % 2 == 1`，必須使用 `abs(n % 2) == 1` 或 `n % 2 != 0` 才能保證正負奇數都判斷正確。

## 程式碼

1.  實作自訂比較函式 `cmp` 來決定 `sort` 的行為。
2.  首先計算兩數除以 $M$ 的餘數，若不同則直接以餘數大小做升序排列。
3.  若餘數相同，則利用 `isOdd` 函式（透過 `abs(n % 2) == 1` 安全處理負數）區分奇偶狀態：一奇一偶時由奇數領先；同為奇數時採 `a > b` 降序排列；同為偶數時採 `a < b` 升序排列。

```cpp
#include<bits/stdc++.h>
using namespace std;
int N,M;
bool isOdd(int n){
	return abs(n%2)==1;
}
bool cmp(int a,int b){
	int A=a%M;
	int B=b%M;
	if(A!=B){
		return A<B;
	}
	bool aOdd=isOdd(a);
	bool bOdd=isOdd(b);
	if(aOdd&&!bOdd){
		return true;
	}
	if(!aOdd&&bOdd){
		return false;
	}
	if(aOdd&&bOdd){
		return a>b;
	}
	if(!aOdd&&!bOdd){
		return a<b;
	}
}
int main(){
	while(cin>>N>>M&&(N!=0||M!=0)){
		vector<int> nums(N);
		for(int i=0;i<N;i++){
			cin>>nums[i];
		}
		sort(nums.begin(),nums.end(),cmp);
		cout<<N<<" "<<M<<endl;
		for(int j=0;j<N;j++){
			cout<<nums[j]<<endl;
		}
	}
	cout<<"0 0"<<endl;
	return 0;
}
```
