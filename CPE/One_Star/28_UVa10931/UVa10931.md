# UVa 10931 - Parity


## 題目簡述

給定一個正整數 $I$，求出它在二進位表示法（Binary representation）下的型態，並統計其二進位中共有幾個 `1` 。

**Sample Input**：

  **1** $\rightarrow$ 測資 1 $I$（ $1 \le I \le 2147483647$ ）。<br>
  **2**<br>
  **10**<br>
  **21**<br>
  **0** $\rightarrow$ 輸入 0 ，程式結束。

**Sample Output**：

  **The parity of 1 is 1 (mod 2).** $\rightarrow$ $1$ 的二進位為 `1`，內含 1 個 `1`。<br>
  **The parity of 10 is 1 (mod 2).** $\rightarrow$ $2$ 的二進位為 `10`，內含 1 個 `1`。<br>
  **The parity of 1010 is 2 (mod 2).** $\rightarrow$ $10$ 的二進位為 `1010`，內含 2 個 `1`。<br>
  **The parity of 10101 is 3 (mod 2).** $\rightarrow$ $21$ 的二進位為 `10101`，內含 3 個 `1`。


## 程式碼

1.  利用 `while` 迴圈將整數不斷除以 2，依序取得二進位的各個數位並存入字串中，同時統計 `1` 的個數。
2.  由於字元是從低位元開始取得，最後需使用 `reverse` 將字串反轉回正確的二進位順序。

> 字串初始宣告為一個空格 `string s=" ";`，反轉後空格會移到最後，剛好用來隔開後面的 `is` 字串，不用再加一個。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	long long n;
	while(cin>>n&&n!=0){
		long long count=0;
		string s=" ";
		while(n>0){
			if(n%2==1){
				count++;
				s+="1";
			}
			else if(n%2==0){
				s+="0";
			}
			n=n/2;
		}
		reverse(s.begin(),s.end());
		cout<<"The parity of "<<s<<"is "<<count<<" (mod 2)."<<endl;
	}
	return 0;
}
```
