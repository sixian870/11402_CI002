# UVa 10057 - A mid-summer night's dream


## 題目簡述

給定 $n$ 個正整數，找到一個整數 $A$，使得所有輸入的數字與 $A$ 的「絕對距離總和」為最小（即 $\sum |X_i - A|$ 最小）。<br>
請依序輸出三個由空格隔開的整數：
1. 滿足條件的**最小可能整數 $A$**，也就是最小的中位數 A -> 排序後的 X(n-1/2)。
2. 輸入的數字當中，有**多少個數字**可以讓絕對距離總和達到最小，也就是輸入資料中符合中位數區間的數字個數。
3. 總共有**多少個不同的整數**可以讓絕對距離總和達到最小，也就是共有幾種可能的整數 A 可以讓距離最小 -> X(n/2) - X(n-1/2) + 1

> 要讓所有點到 $A$ 的距離總和最短， $A$ 必須落在中位數的位置：
> - 當 $n$ 為奇數時：中位數只有一個，即排序後的 `arr[(n-1)/2]`。此時滿足條件的整數 $A$ 只有這唯一一個，因此第三個答案必為 1。
> - 當 $n$ 為偶數時：中位數會是一個區間，落在 `arr[(n-1)/2]`（設為 `mid1`）與 `arr[n/2]`（設為 `mid2`）之間的所有整數都可以讓距離總和最小。因此最小的 $A$ 是 `mid1`，而可選的整數總共有 `mid2 - mid1 + 1` 個。

**Sample Input**：

  **2** $\rightarrow$ 第一組測資有 2 個數字。<br>
  **10**<br>
  **10**<br>
  **4** $\rightarrow$ 第二組測資有 4 個數字。<br>
  **1**<br>
  **2**<br>
  **2**<br>
  **4**

**Sample Output**：

  **10 2 1** $\rightarrow$ 中位數為 10；輸入中有 2 個數字等於 10；符合條件的整數只有 10 這 1 個。<br>
  **2 2 1** $\rightarrow$ `mid1=2`, `mid2=2`。最小中位數為 2；輸入中有 2 個數字符合（兩個 2）；可能整數有 $2-2+1=1$ 個。


## 程式碼

1.  將所有輸入的數字存入 `vector` 後進行從小到大排序，並定出中位數區間的左端點 `mid1` 與右端點 `mid2`。
2.  接著遍歷整個陣列，統計輸入資料中與 `mid1` 或 `mid2` 相等的元素個數 `count`。
3.  最後依序印出 `mid1`、符合的元素個數、以及區間內所有可能的整數個數（`mid2 - mid1 + 1`）。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int n;
	while(cin>>n){
		vector<int> arr(n); 
		for(int i=0;i<n;i++){
			cin>>arr[i];
		}
		sort(arr.begin(),arr.end());
		int mid1=arr[(n-1)/2];
		int mid2=arr[n/2];
		int count=0;
		for(int j=0;j<n;j++){
			if(arr[j]==mid1||arr[j]==mid2){
				count++;
			}
		}
		cout<<mid1<<" "<<count<<" "<<mid2-mid1+1<<endl;
	}
	return 0;
}
```
