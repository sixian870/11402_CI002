# UVa 10929 - You can say 11


## 題目簡述

判斷一個非常大的正整數是否為 11 的倍數。<br>
> 11倍數:|奇數位數字和 -偶數位數字之和| % 11 = 0

**Sample Input**：

  **112233**  $\rightarrow$ 待計算之可能高達 1000 位的正整數。<br>
  **112234** <br>
  **0**  $\rightarrow$ 當讀到 0 時，程式停止。

**Sample Output**：

  **112233 is a multiple of 11.**     $\rightarrow$ 如果是 11 的倍數，輸出此格式。<br>
  **112234 is not a multiple of 11.**  $\rightarrow$ 如果不是 11 的倍數，需加上 not。


## 程式碼

將大數當作字串讀取，利用迴圈遍歷每一個字元。將字元轉換為整數 `- '0'` 後，依據索引值的奇偶性分別累加，最後判斷兩者之差的絕對值是否能被 11 整除。
> 1000 位數不能用 long long要用 string
cpp
```
#include<bits/stdc++.h>
using namespace std;
int main(){
	string num;
	while(cin>>num&&num!="0"){
		int odd=0;
		int even=0;
		for(int i=0;i<num.length();i++){
			int a=num[i]-'0'; //char->int
			if(i%2==0){
				odd+=a;
			}
			if(i%2==1){
				even+=a;
			}
		}
		if(abs(odd-even)%11==0){
			cout<<num<<" is a multiple of 11."<<endl;
		}
		else{
			cout<<num<<" is not a multiple of 11."<<endl;
		}
	}
	return 0;
}
```
