# UVa 10812 - Beat the Spread!


## 題目簡述

在超級盃美式足球賽的賭盤中，人們常常會打賭兩隊最後分數的「總和」是多少，或是兩隊分數「差的絕對值」是多少。<br>
給定這兩個數值：總和 $s$ 與分差 $d$，推算出這兩支隊伍的實際分數各是多少。<br>
已知分數必須為**非負整數**，且輸出時先印出較高的分數，如果找不到任何一組非負整數符合條件，則輸出 `impossible`。

**Sample Input**：

  **2** $\rightarrow$ 測試資料的總組數 $t$。<br>
  **40 20** $\rightarrow$ 每行包含兩個非負整數 $s$（總和）與 $d$（分差）。<br>
  **20 40**

**Sample Output**：

  **30 10** $\rightarrow$ 解出兩隊分數為 30 與 10，先印出大數再印出小數。<br>
  **impossible** $\rightarrow$ 總和少於分差，不可能成立。


## 程式碼

設兩隊分數分別為 $x$ 與 $y$（且 $x \ge y$）。 <br>
依題意可列出聯立方程式：<br>
$x + y = s$ <br>
$x - y = d$ <br>
兩式相加可得 $x = \frac{s + d}{2}$，兩式相減可得 $y = \frac{s - d}{2}$。 <br>

**不合法（impossible）的判斷條件：**
1. 總和 $s$ 小於分差 $d$（會導致小分數 $y$ 變成負數）。
2. $(s + d)$ 或 $(s - d)$ 無法被 2 整除（會導致分數不是整數）。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int t,s,d;
	int x,y;
	cin>>t;
	while(t--){
		cin>>s>>d;
		if(s<d||(s+d)%2!=0){ //(s+-d)%2!=0確保 x,y為整數，確保 s>d就會 x>y，若 s<d則不可能成立 
			cout<<"impossible"<<endl;
		}
		else{
			x=(s+d)/2;
			y=(s-d)/2;
			cout<<x<<" "<<y<<endl;
		}
	}
	return 0;
}
```
