# UVa 10783 - Odd Sum


## 題目簡述

給定一個閉區間 $[a, b]$，計算並輸出該區間內（包含 $a$ 與 $b$）所有**奇數（Odd numbers）的總和**。<br>

**Sample Input**：

  **2**  $\rightarrow$ 測資組數 $t$。<br>
  **1**  $\rightarrow$ 第一組測資的起始數 $a$。<br>
  **5**  $\rightarrow$ 第一組測資的結尾數 $b$（區間為 1 ~ 5）。<br>
  **3**  $\rightarrow$ 第二組測資的起始數 $a$。<br>
  **5**  $\rightarrow$ 第二組測資的結尾數 $b$（區間為 3 ~ 5）。

**Sample Output**：

  **Case 1: 9** $\rightarrow$ $1 + 3 + 5 = 9$。<br>
  **Case 2: 8** $\rightarrow$ $3 + 5 = 8$。


## 程式碼

1.  每組測資的起點 $a$ 與終點 $b$ 後，利用一個 `for` 迴圈從 $a$ 巡訪到 $b$。
2.  在迴圈內部以 `if(j % 2 == 1)` 判斷當前數字是否為奇數，若是奇數則累加至 `sum` 。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int t,a,b;
	cin>>t;
	for(int i=1;i<=t;i++){
		cin>>a>>b;
		int sum=0;
		for(int j=a;j<=b;j++){
			if(j%2==1){
				sum+=j;
			}
		}
		cout<<"Case "<<i<<": "<<sum<<endl; //注意加空格 
	}
	return 0;
}
