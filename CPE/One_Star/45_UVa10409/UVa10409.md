# UVa 10409 - Die Game


## 題目簡述

想像桌上有一個標準的骰子，剛開始的初始狀態為：**頂面（top）為 1、底面（bottom）為 6、北面（north）為 2、南面（south）為 5、東面（east）為 4、西面（west）為 3**。<br>
接下來骰子會朝著「北（north）」、「南（south）」、「東（east）」、「西（west）」四個方向進行一系列的滾動。<br>
模擬滾動過程，並在所有指令結束後，輸出骰子 **頂面（top）** 的數字。

> 2 個對面相加為 7。

**Sample Input**：

  **1** $\rightarrow$ 第一組測資的滾動次數 $t$。<br>
  **north** $\rightarrow$ 滾動方向指令。<br>
  **3** $\rightarrow$ 第二組測資的滾動次數 $t$。<br>
  **north**<br>
  **east**<br>
  **south**<br>
  **0** $\rightarrow$ 輸入 0 ，程式結束。

**Sample Output**：

  **5** $\rightarrow$ 第一組只往北滾 1 次，原本南面的 5 翻到頂面，故輸出 5。<br>
  **1** $\rightarrow$ 第二組滾動三次後，頂面重新回到 1。


## 程式碼

1. 利用六個整數變數分別代表骰子的六個面，並在每組測資開頭初始化。
2. 透過字串讀取滾動指令（`north`、`south`、`east`、`west`），並利用一個暫存變數 `temp` 配合前後順序，將受影響的四個面進行數值交換。
3. 所有指令執行完畢後，直接輸出 `top` 變數的值。

```
top = 1, bottom = 6, north = 2, south = 5, east = 4, west = 3
North: north=top, top=south, south=bottom, bottom=north (n,t,s,b,n)
South: south=top, top=north, north=bottom, bottom=south (s,t,n,b,s)
East: east=top, top=west, west=bottom, bottom=east (e,t,w,b,e)
West: west=top, top=east, east=bottom, bottom=west (w,t,e,b,w)
```

```cpp
#include<iostream>
using namespace std;
int main() {
	int t;
	while (cin >> t && t != 0) {
		int top = 1, bottom = 6, north = 2, south = 5, east = 4, west = 3;
		while (t--) {
			string s;
			cin >> s;
			if (s == "north") {
				int temp = north;
				north = top; top = south; south = bottom; bottom = temp;
			}
			else if(s == "south") {
				int temp = south;
				south = top; top = north; north = bottom; bottom = temp;
			}
			else if (s == "east") {
				int temp = east;
				east = top; top = west; west = bottom; bottom = temp;
			}
			else if (s == "west") {
				int temp = west;
				west = top; top = east; east = bottom; bottom = temp;
			}
		}
		cout << top << "\n";
	}
	return 0;
}
```
