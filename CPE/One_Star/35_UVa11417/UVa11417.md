# UVa 11417 - GCD


## 題目簡述

給一個正整數 $N$，計算出所有滿足 $1 \le i < j \le N$ 的整數對 $(i, j)$，它們的**最大公因數（GCD）之總和**。

> 題目要求計算的總和公式如下：
> $$G = \sum_{i=1}^{N-1} \sum_{j=i+1}^N \text{GCD}(i, j)$$

**Sample Input**：

  **10** $\rightarrow$ 第一個正整數 $N$（ $1 < N < 501$ ）。<br>
  **100** <br>
  **500** <br>
  **0** $\rightarrow$ 輸入 $N = 0$ 時，程式結束。

**Sample Output**：

  **67** $\rightarrow$ 當 $N = 10$ 時，所有組合的 GCD 總和為 67。<br>
  **13015** $\rightarrow$ 當 $N = 100$ 時，所有組合的 GCD 總和為 13015。<br>
  **442011**


## 程式碼

1. 利用輾轉相除法（Euclidean algorithm）實作遞迴的 `gcd` 函式
2. 在 `main` 函式中，利用雙層迴圈完全模擬題目給定的數學公式：外層 `i` 從 1 跑到 `n-1`，內層 `j` 從 `i+1` 跑到 `n`。
3. 依序將每一對 `(i, j)` 的最大公因數加總至 `long long` 型態的變數 `g` 中，最後輸出結果。

```cpp
#include<iostream>
using namespace std;
int gcd(int a,int b){
	if(b==0){
		return a;
	}
	return gcd(b,a%b);
}
int main(){
	int n;
	while(cin>>n&&n!=0){
		long long g=0;
		for(int i=1;i<n;i++){
			for(int j=i+1;j<=n;j++){
				g+=gcd(i,j);
			}
		}
		cout<<g<<endl;
	}
	return 0;
}
```
