# UVa 12019 - Doom's Day Algorithm


## 題目簡述

給定 2011 年的某一個日期（月份 $m$ 與日期 $d$），推算出那一天是星期幾。<br>
已知 2011 年不是閏年（2 月只有 28 天），且該年的 1 月 1 日是星期六。

**Sample Input**：

  **8**  $\rightarrow$ 測資數量。<br>
  **1 6**  $\rightarrow$ M D。<br>
  **2 28** <br>
  **4 5** <br>
  **5 26** <br>
  **8 1** <br>
  **11 1** <br>
  **12 25** <br>
  **12 31**

**Sample Output**：

  **Thursday** <br>
  **Monday** <br>
  **Tuesday** <br>
  **Thursday** <br>
  **Monday** <br>
  **Tuesday** <br>
  **Sunday** <br>
  **Saturday** <br>


## 程式碼


用一個陣列建立 1 到 12 月每個月的天數，並建立一個從「星期六」開始排序的星期字串陣列，因為第一天是禮拜六。<br>
計算出該日期是 2011 年的「第幾天」後，將總天數減 1 再對 7 取餘數，就能直接對應出正確的星期。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int t,m,d;
	string week[]={"Saturday","Sunday","Monday","Tuesday","Wednesday","Thursday","Friday"};
	int month[]={0,31,28,31,30,31,30,31,31,30,31,30,31}; //注意 index從 0開始 
	cin>>t;
	while(t--){
		cin>>m>>d;
		int total=0;
		for(int i=1;i<m;i++){ //if m=2,i=1,total=31 
			total+=month[i];
		}
		total+=d;
		cout<<week[(total-1)%7]<<endl;
	}
	return 0;
} 
```
