# UVa 10071 - Back to High School Physics


## 題目簡述

一個質點具有某個初速度與固定的加速度。<br>
已知它在時間 $t$ 內所達到的速度為 $v$，請問在兩倍的時間（即 $2t$）過後，該質點所移動的**總位移**是多少？

**Sample Input**：

  **0 0** $\rightarrow$ 每行包含兩個整數，分別代表時間 $t$（ $0 \le t \le 200$ ）與速度 $v$（ $-100 \le v \le 100$ ）。<br>
  **5 12**

**Sample Output**：

  **0**  $\rightarrow$ 當 $t=0, v=0$ 時，位移為 $2 \times 0 \times 0 = 0$。<br>
  **120**  $\rightarrow$ 當 $t=5, v=12$ 時，位移為 $2 \times 12 \times 5 = 120$。


## 程式碼

等加速度運動公式，在初速度為 0 的情況下：
* 時間 $t$ 時的速度： $v = a \times t \rightarrow a = \frac{v}{t}$
* 時間 $2t$ 時的位移： $X = \frac{1}{2} \times a \times (2t)^2 = \frac{1}{2} \times a \times 4t^2 = 2 \times a \times t^2$

將 $a = \frac{v}{t}$ 代入位移公式，可得 $X = 2 \times (\frac{v}{t}) \times t^2 = 2vt$。<br>
因此，不論加速度是多少，最終的位移量剛好就是 $2 \times v \times t$。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int t,v;
	while(cin>>t>>v){
		cout<<2*v*t<<endl;
	}
	return 0;
}
```
