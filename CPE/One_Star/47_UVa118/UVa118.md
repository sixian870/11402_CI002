# UVa 118 - Mutant Flatworld Explorers


## 題目簡述

在一個給定的二維格子地圖上（左下角固定為 $(0,0)$，右上角座標由輸入決定），有多台機器人依據指令序列進行移動。<br>
指令包含：`R`（順時針轉 90 度）、`L`（逆時針轉 90 度）以及 `F`（向前移動一格）。<br>
如果機器人在移動過程中超出了地圖邊界，它就會掉落懸崖而損壞（狀態變為 `LOST`），並在它生前最後一個合法的格子邊緣留下「死亡氣味」。<br>
後續的機器人若移動到相同的格子，且企圖朝著擁有死亡氣味的方向移動時，將會安全地無視該次的 `F` 指令，並留在原地繼續執行後續指令。

**Sample Input**：

  **5 3** $\rightarrow$ 地圖右上角座標為 (5, 3)。<br>
  **1 1 E** $\rightarrow$ 第一台機器人初始位置 (1, 1)，面向東方。<br>
  **RFRFRFRF** $\rightarrow$ 第一台機器人的移動指令。<br>
  **3 2 N** $\rightarrow$ 第二台機器人初始位置 (3, 2)，面向北方。<br>
  **FRRFLLFFRRFLL**<br>
  **0 3 W** $\rightarrow$ 不斷輸入該地圖測資。<br>
  **LLFFFLFLFL**

**Sample Output**：

  **1 1 E** $\rightarrow$ 第一台機器人最後安全停在 (1, 1) 面向東方。<br>
  **3 3 N LOST** $\rightarrow$ 第二台機器人在 (3, 3) 往北移動時摔死，留下死亡氣味。<br>
  **2 3 S**


## 程式碼

```
03 13 23 33 43 53
02 12 22 32 42 52
01 11 21 31 41 51
00 10 20 30 40 50 
  N
W   E      *E->S->W->N
  S
E+F:x++
S+F:y--
W+F:x--
N+F:y++
```

1. （`E` 東、`S` 南、`W` 西、`N` 北）陣列對應 `dx`、`dy`。
2. 右轉 `R` 需要 `(idx + 1) % 4`；左轉 `L` 則可藉由 `(idx + 3) % 4` 避開負數取餘數。
3. 題目輸入的 `col` 與 `row` 是地圖右上角的最大座標，因為座標從 0 開始，合法的活動範圍包含 `col` 和 `row` 本身，因此建立二維動態陣列時，大小必須開為 `row + 1` 與 `col + 1` 。
4. 當預測下一步出界時，先檢查目前格子的氣味紀錄 `M[x][y]` 是否為 `true`。若有氣味則執行 `continue` 留在原地；若無氣味則踩上地雷，將該格設為 `true`，標記 `lost = true` 並立刻跳出指令迴圈。

```cpp
#include<iostream>
#include<vector>
using namespace std;
int main() {
	int col, row;
	cin >> col >> row;
	vector<vector<bool>> M(row + 1, vector<bool>(col + 1, false));
	int x, y;
	char d;
	while (cin >> x >> y >> d) {
		char dir[4] = { 'E','S','W','N' };
		int dx[4] = { 1,0,-1,0 };
		int dy[4] = { 0,-1,0,1 };
		string cmd;
		cin >> cmd;
		int idx;
		for (int i = 0; i < 4; i++) {
			if (dir[i] == d) {
				idx = i;
				break;
			}
		}
		bool lost = false;
		for (char c : cmd) {
			if (c == 'R') {
				idx = (idx + 1) % 4;//避免超索引範圍 index:0~3
			}
			else if (c == 'L') {
				idx = (idx + 3) % 4;//避免-1造成負數
			}
			else if (c == 'F') {
				if (x + dx[idx] > col || x + dx[idx] <0 || y + dy[idx]>row || y + dy[idx] < 0) {
					if (M[x][y] == true) {
						continue;
					}
					else {
						M[x][y] = true;
						lost = true;
						break;
					}
				}
				else {
					x += dx[idx];
					y += dy[idx];
				}
			}
		}
		if (lost) {
			cout << x << " " << y << " " << dir[idx] << " LOST\n";
		}
		else {
			cout << x << " " << y << " " << dir[idx] << "\n";
		}
	}
	return 0;
}
```
