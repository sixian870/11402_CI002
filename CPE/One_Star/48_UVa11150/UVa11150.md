# UVa 11150 - Cola


## 題目簡述

若買了 $N$ 瓶可樂，而商店有一個優惠活動：每 3 個空可樂瓶可以免費換 1 瓶全新的可樂。<br>
可以向朋友「借空瓶」，條件是在喝完所有可樂後，湊得出足夠的空瓶還給朋友。<br>
計算在最聰明的交換策略下（包含跟朋友借空瓶），你最多總共可以喝到幾瓶可樂？

> 每次拿 3 個空瓶去換 1 瓶新可樂，喝完之後又會產生 1 個空瓶。這意味著：**實質上只消耗了 2 個空瓶，就淨賺了 1 瓶可樂的內容物**！
> 因為題目允許跟朋友借空瓶（只要最後還得清），這代表我們可以把手頭上的空瓶壓榨到極致。
> 因此，除了原本的 $N$ 瓶可樂，剩下的空瓶每 2 個就能再換 1 瓶。
> 最終公式： $N + \lfloor N/2 \rfloor$

**Sample Input**：

  **8** $\rightarrow$ 一開始擁有的可樂數量 $N$（ $1 \le N \le 200$ ）。<br>

**Sample Output**：

  **12** $\rightarrow$ 初始 8 瓶，依公式 $8 + (8 / 2) = 12$。<br>


## 程式碼

公式： $N + \lfloor N/2 \rfloor$

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int n;
	while(cin>>n){
		cout<<n+(n/2)<<endl;
	}
	return 0;
}
```
