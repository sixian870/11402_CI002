# UVa 11349 - Symmetric Matrix


## 題目簡述

給定一個 $n \times n$ 的方陣，請判斷它是否為「對稱矩陣」。<br>
這裡的對稱定義是**中心對稱**：也就是矩陣旋轉 180 度之後，其對應位置的數值依然完全相同。
```
5 1 3
2 0 2
3 1 5
```
此外，題目特別規定**矩陣中的所有元素都必須為非負整數（ $\ge 0$ ）**，如果矩陣內包含任何負數，即使位置完全對稱，也必須判定為不對稱。

**Sample Input**：

  **2** $\rightarrow$ 測資組數 $t$。<br>
  **N = 3** $\rightarrow$ 第一組矩陣大小 $n$。<br>
  **5 1 3** $\rightarrow$  $n \times n$ 個整數。<br>
  **2 0 2**<br>
  **3 1 5**<br>
  **N = 3**<br>
  **5 1 3**<br>
  **2 0 2**<br>
  **0 1 5**

**Sample Output**：

  **Test #1: Symmetric.** <br>
  **Test #2: Non-symmetric.**


## 程式碼

1. 每組測資開頭的矩陣大小格式為 `N = 3`，用 `char a, b; cin >> a >> b >> n` 可以把 `N` 與 `=` 讀取並忽略。
2. 由於矩陣元素的數值範圍可能很大，陣列型態必須使用 `long long` 儲存以防止溢位。
3. 在第一個迴圈讀取矩陣時，若發現負數，將標記變數設為不對稱（`isS = false`）即可，**不能提早 break 或 continue**，必須讓迴圈完整讀完該組測資的所有數字，否則會影響到下一筆測資。

> 所有的位置必須滿足 $M_{i,j} = M_{n-1-i, n-1-j}$。

```cpp
/*UVa11349
* 5 1 3      00 01 02
* 2 0 2 ->   10 11 12
* 3 1 5      20 21 22
* 00=22
* 01=21
* 02=20
* 10=12
*/
#include<iostream>
#include<vector>
using namespace std;
int main() {
	int t;
	int count = 1;
	cin >> t;
	while (t--) {
		char a, b;
		int n;
		bool isS = true;
		cin >> a >> b >> n;
		cout << "Test #" << count++;
		vector<vector<long long>> M(n, vector<long long>(n));//n*n//ij很大 要用 long long
		for (int i = 0; i < n; i++) {
			for (int j = 0; j < n; j++) {
				cin >> M[i][j];
				if (M[i][j] < 0) {
					//cout << ": Non-symmetric.\n";
					//continue;
					isS = false;
				}
			}
		}
		for (int i = 0; i < n; i++) { //0 1 2
			for (int j = 0; j < n; j++) {
				if (M[i][j] != M[n - 1 - i][n - 1 - j]) { //00=22 01=21 02=20
					isS = false;
					break;
				}
			}
		}
		if (isS) {
			cout << ": Symmetric.\n";
		}
		else if (!isS) {
			cout << ": Non-symmetric.\n";
		}
	}
	return 0;
}
```
