# UVa 10035 - Primary Arithmetic


## 題目簡述

模擬加法過程，計算兩個整數相加時總共會產生多少次「進位」操作。<br>
給定兩個小於 10 位數的正整數，不斷進行相加並計算進位次數。<br>
輸出這兩個數字相加時總共進位的次數。

**Sample Input**：

  **123 456**		$\rightarrow$ 每一行包含兩個待相加的正整數。<br>
  **555 555** <br>
  **123 594** <br>
  **0 0**		$\rightarrow$ 當讀取到兩個 0 時代表結束。

**Sample Output**：

  **No carry operation.**		$\rightarrow$ 如果進位次數為 0，輸出 No carry operation。<br>
  **3 carry operations.**		$\rightarrow$ 如果進位次數大於 1，operation 後面必須加上 s。<br>
  **1 carry operation.**		$\rightarrow$ 如果進位次數剛好為 1，維持單數不加 s。


## 程式碼

分別 %10 相加，確認是否大於等於十，是的話需要紀錄進位 +1 且與下一位相加。<br>
> 要注意輸出的單複數 

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int a,b;//123 456
	while(cin>>a>>b&&(a!=0||b!=0)){
		int count=0;
		int c=0;
		while(a!=0||b!=0){
			int digit_a,digit_b;

			digit_a=a%10;//3 2
			a=a/10;//12 1

			digit_b=b%10;//6 5
			b=b/10;//45 4

			if((digit_a+digit_b+c)>=10){//9 7
				count++;//0 0
				c=1;
			}
			else{
				c=0;
			}
		}
		if(count==0){
			cout<<"No carry operation."<<endl;
		}
		else{
			if(count==1){
				cout<<count<<" carry operation."<<endl;
			}
			else{
				cout<<count<<" carry operations."<<endl;
			}
		}
	}
	return 0;
}
```
