# UVa 299 - Train Swapping


## 題目簡述

有一個長度為 $N$ 的車廂序列（編號為 1 到 $N$），若只能透過**交換相鄰兩個車廂**的方式來將車廂依編號從小到大（1, 2, 3...）重新排列好。<br>
請問最少需要進行多少次相鄰車廂的交換，才能將所有車廂排列正確。

**Sample Input**：

  **3** $\rightarrow$ 測資組數 $t$。<br>
  **3** $\rightarrow$ 第一組車廂長度 $N$。<br>
  **1 3 2** $\rightarrow$ 車廂目前的排列順序。<br>
  **4** $\rightarrow$ 第二組車廂長度 $N$。<br>
  **4 3 2 1**<br>
  **2**<br>
  **2 1**

**Sample Output**：

  **Optimal train swapping takes 1 swaps.** $\rightarrow$ (3, 2) 交換 1 次即可完成排序。<br>
  **Optimal train swapping takes 6 swaps.** <br>
  **Optimal train swapping takes 1 swaps.**

## 程式碼

利用泡沫排序法（Bubble Sort）進行模擬。<br>
1.  透過兩層巢狀迴圈遍歷陣列，只要發現前一項車廂編號大於後一項（`train[k] > train[k+1]`），就呼叫 `swap` 將兩者位置對調，並讓計數器 `count` 加 1。
2. 當所有迴圈跑完、陣列完全升序排列後，累積的 `count` 即為最少交換次數。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int t;
	cin>>t;
	while(t--){
		int count=0;
		int n;
		cin>>n;
		vector<int> train(n);
		for(int i=0;i<n;i++){
			cin>>train[i];
		}
		for(int j=0;j<n-1;j++){
			for(int k=0;k<n-1;k++){
				if(train[k]>train[k+1]){
					swap(train[k],train[k+1]);
					count++;
				}
			}
		}
		cout<<"Optimal train swapping takes "<<count<<" swaps."<<endl;
	}
	return 0;
}
```
