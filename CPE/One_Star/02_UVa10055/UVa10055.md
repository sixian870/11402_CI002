# UVa 10055 - Hashmat the Brave Warrior


## 題目簡述

在與敵人開戰前先計算自己軍隊與敵方軍隊的「人數差異」，以此來決定是否要進行戰鬥。<br>
給定兩個數字，分別代表兩對的軍隊數量。<br>
請計算並輸出這兩個數字的絕對差值。

**Sample Input**：

  **10 12**		$\rightarrow$ 每一行包含兩個正整數，分別代表 Hashmat 與敵方的士兵數量。<br>
  **10 14**<br>
  **100 200**

**Sample Output**：

  **2**		$\rightarrow$ 輸出兩軍人數的絕對差值，每一筆測資的結果輸出佔獨立的一行。<br>
  **4**<br>
  **100**


## 程式碼

直接讀取兩個數字，並利用 abs() 函式計算相減後的絕對值，因為數字可能很大，要用 long long 宣告。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	long long a,b;
	while(cin>>a>>b){
		cout<<abs(a-b)<<endl;
	}
	return 0;
}
```
