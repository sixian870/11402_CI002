# UVa 10093 - An Easy Problem!


## 題目簡述

給定一個字串代表某個未知進位制（ $2 \le N \le 62$ ）下的正整數，找出最小的進位制 $N$，使得該數字在 $N$ 進位下的數值可以被 $(N-1)$ 整除。<br>
字元與數值的對應規則為：
* `0`~`9` 代表 $0 \sim 9$
* `A`~`Z` 代表 $10 \sim 35$
* `a`~`z` 代表 $36 \sim 61$

如果找不到符合條件的進位制，則輸出 `such number is impossible!`。

**Sample Input**：

  **3** $\rightarrow$ 輸入字串可能包含正負號或空白。<br>
  **5**<br>
  **A**

**Sample Output**：

  **4** $\rightarrow$ 數字 3 最小為 4 進位，且 $3 \pmod{4-1} == 0$。<br>
  **6** $\rightarrow$ 數字 5 最小為 6 進位，且 $5 \pmod{6-1} == 0$。<br>
  **11** $\rightarrow$ 'A' 代表 10，最小為 11 進位，且 $10 \pmod{11-1} == 0$。


## 程式碼

一個 $N$ 進位的數字若能被 $(N-1)$ 整除，則其「所有數位（digits）的數值總和」也必然能被 $(N-1)$ 整除，因此直接累加所有字元數值即可。
進位制 $N$ 的下限為「出現過的最大字元數值 + 1」，且題目規定進位制至少從 2 開始。
1. 利用 getline 逐行讀取輸入字串，並透過迴圈將每個字元轉換為對應的數值。
2. 在轉換過程中，同時統計所有數位的總和 sum 以及出現過的最大值 max（由最大值 max + 1 決定該數字的最小可能進位制下限）。
3. 利用 for 迴圈從進位下限開始一路上推測試到 62 進位，只要符合 sum % (i - 1) == 0 的整除規律，就代表找到了最小的合法進位制，隨即印出結果並結束該輪。

```cpp
#include<iostream>
#include<string>
using namespace std;
int main() {
	string s;
	while (getline(cin, s)) {
		int sum = 0;
		int t = -1;
		int max = 1; //min=2
		for (int i = 0; i < s.length(); i++) {
			if (s[i] >= '0' && s[i] <= '9') {
				t = s[i] - '0';
			}
			else if (s[i] >= 'A' && s[i] <= 'Z') {
				t = s[i] - 'A' + 10;
			}
			else if (s[i] >= 'a' && s[i] <= 'z') {
				t = s[i] - 'a' + 36;
			}
			if (t != -1) { // L o h  r  
				sum += t;
				if (t > max) {
					max = t;
				}
			}
		}
		bool flag = false;
		for (int i = max + 1; i < 63; i++) {
			if (sum % (i - 1) == 0) {
				cout << i << "\n";
				flag = true;
				break;
			}
		}
		if (!flag) {
			cout << "such number is impossible!\n";
		}
	}
	return 0;
}
```
