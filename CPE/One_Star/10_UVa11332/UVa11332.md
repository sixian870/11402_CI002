# UVa 11332 - Summing Digits


## 題目簡述

給定一個正整數 $n$，定義 $f(n)$ 為 $n$ 的各個位數總和。<br>
如果 $f(n)$ 計算出來的結果只有一位數，那麼這就是最終答案；如果大於等於 10（超過一位數），則必須將結果再次代入 $f(n)$ 計算，不斷重複這個步驟，直到結果縮減為單一數字為止。

**Sample Input**：

  **2**    $\rightarrow$  第一個 $n$。<br>
  **11**    $\rightarrow$  第二個 $n$。<br>
  **47**<br>
  **0**    $\rightarrow$  輸入 0 結束。

**Sample Output**：

  **2**    $\rightarrow$ $f(2) = 2$ <br>
  **2**    $\rightarrow$ $f(11) = 1 + 1 = 2$ <br>
  **2**    $\rightarrow$ $f(47) = 4 + 7 = 11$  $\rightarrow$ $f(11) = 1 + 1 = 2$


## 程式碼

1. 撰寫一個副程式 f()，利用 % 10 取出個位數並累加，再利用 / 10 消去個位數，以此來計算各位數的總和。
2. 在主程式中，只要 $n \ge 10$（即不是單一數字），就利用 while 迴圈不斷呼叫 f(n) 更新 $n$ 的值，直到縮減至一位數才印出結果。

```cpp
#include<bits/stdc++.h>
using namespace std;
long long f(long long n){
	int sum=0;
	while(n>0){
		sum=sum+n%10;
		n=n/10;
	}
	return sum;
}
int main(){
	long long n;
	while(cin>>n&&n!=0){
		while(n>=10){
			n=f(n);
		}
		cout<<n<<endl;
	}
	return 0;
}
```
