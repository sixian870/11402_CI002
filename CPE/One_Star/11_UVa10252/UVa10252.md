# UVa 10252 - Common Permutation

## 題目簡述

給定兩個由小寫英文字母組成的字串 $a$ 和 $b$。<br>
你的任務是找出這兩個字串「共同擁有」的字母，並將這些共同字母按照英文字母（a\~z）順序排列後輸出。<br>
若某個字母在兩字串中都有重複出現，則它在結果中輸出的次數，為其在兩個字串中出現次數的較小值。

**Sample Input**：

**pretty**  $\rightarrow$ 第一組的字串 a。<br>
**women**   $\rightarrow$ 第一組的字串 b。<br>
**walking** $\rightarrow$ 第二組的字串 a。<br>
**down**		$\rightarrow$ 第二組的字串 b。

**Sample Output**：

**e**  $\rightarrow$ pretty 和 women 共同擁有一個字母 e。<br>
**nw**  $\rightarrow$ walking 和 down 共同擁有 n 和 w，必須按字母順序輸出。


## 程式碼

1. 利用兩個大小為 26 的整數陣列 count1 與 count2，分別紀錄這對字串中各個小寫字母出現的次數。
2. 	使用 getline 確保能正確讀取可能包含空白的成對字串，並透過 c - 'a' 將字母轉換為陣列 0~25 的索引。
3.	最後遍歷陣列，取兩個字串相同字母次數的較小值（min），並印出對應數量的字元。
> int 轉 char: `char('a'+i)`

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	string v1,v2;
	while(getline(cin,v1)&&getline(cin,v2)){ //因為字串成對 
		int count1[26]={0}; //全部設為 0 
		int count2[26]={0};
		for(char c:v1){ //把字串 s1裡的字元依序取出輪流丟給 c變數處理
			if(c>='a'&&c<='z'){ //'a'=97 
				count1[c-'a']++; //count['a'-'a']=count[0],count['b'-'a']=count[1]
			}  
		}
		for(char c:v2){
			if(c>='a'&&c<='z'){
				count2[c-'a']++;
			}  
		}
		for(int i=0;i<26;i++){ //count[0]='a',count[25]='z'
			int t=min(count1[i],count2[i]);
			for(int j=0;j<t;j++){ //輸出最小次數
				cout<<char('a'+i);//'a'+0=a,'a'+1=b
			}
		}
		cout<<endl;
	}
	return 0;
} 
```
