# UVa 11063 - B2-Sequence


## 題目簡述

給定一個長度為 $N$ 的整數數列，請判斷它是否滿足「B2 數列」的定義：
1. **數列皆大於等於 1 且嚴格遞增**：即 $1 \le B_1 < B_2 < B_3 < \dots < B_n$。
2. **任兩數之和皆不重複**：數列中任意兩個數字相加（ **包含自己加自己**），產生的所有總和結果都必須是唯一的。

每一組測試資料輸出結束後，不論是否為最後一組，**都必須多輸出一行空白行**。

**Sample Input**：

  **4** $\rightarrow$ 數列長度 $N$。<br>
  **1 2 4 8** $\rightarrow$ 數列內容。<br>
  **4**<br>
  **3 7 10 14**

**Sample Output**：

  **Case #1: It is a B2-Sequence.** <br>
  <br>
  **Case #2: It is not a B2-Sequence.** <br>
  <br> $\rightarrow$ 每組輸出後都要有一個空行。<br>


## 程式碼

1.  在讀取時就檢查「是否 $\ge 1$」與「是否嚴格遞增」；若合格則進一步利用雙層迴圈將所有兩數之和（含自己加自己）丟進 `sum` 陣列中。<br>
2.  最後將 `sum` 排序，並檢查是否有相鄰元素相等（即總和重複），即可判定是否為 B2 數列。

```cpp
#include<iostream>
#include<vector>
#include<algorithm>
using namespace std;
int main() {
	int n;
	int count = 1;
	while (cin >> n) {
		bool isB2 = true;
		vector<int> a(n);
		for (int i = 0; i < n; i++) {
			cin >> a[i];
			if (i == 0) {
				if (a[0] <= 0) {
					isB2 = false;
				}
			}
			else if (i > 0) {
				if (a[i] <= a[i - 1]) {
					isB2 = false;
				}
			}
		}
		cout << "Case #" << count++ << ": ";
		if (isB2) {
			vector<int> sum;
			for (int i = 0; i < n; i++) { //0 00 01 02 1 11 12 2 22
				for (int j = i ; j < n; j++) {
					sum.push_back(a[i] + a[j]);
				}
			}
			sort(sum.begin(), sum.end());
			for (int i = 1; i < sum.size(); i++) {
				if (sum[i] == sum[i - 1]) {
					isB2 = false;
					break;
				}
			}
		}
		if (isB2) {
			cout << "It is a B2-Sequence.\n";
		}
		else {
			cout << "It is not a B2-Sequence.\n";
		}
		cout << "\n";
	}
	return 0;
}
```
