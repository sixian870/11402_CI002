# UVa 10101 - Bangla Numbers


## 題目簡述

將給定的巨大數字轉換為孟加拉語的數字表示法。

對應的單位與數值如下：
  * kuti = 10000000 （一千萬）
  * lakh = 100000 （十萬）
  * hajar = 1000 （一千）
  * shata = 100 （一百）

**Sample Input**：

  **23764**		$\rightarrow$ 每一行包含一個非負整數。<br>
  **45897458973958**

**Sample Output**：

  **___1. 23 hajar 7 shata 64**		$\rightarrow$ 先靠右對齊佔 4 格印出測資編號 (setw(4)）再加上 `.` 。<br>
  **___2. 45 lakh 89 hajar 74 shata 58 kuti 97 lakh 39 hajar 5 shata 88**		$\rightarrow$ 接著印出孟加拉數字表示法，單位間以空白隔開。


## 程式碼

利用遞迴方式，由大到小檢查數字是否超過 kuti、lakh、hajar、shata 等單位，若超過則先處理商數（再次呼叫 solve），再印出單位，最後將餘數繼續往下傳遞處理。
> 若 Input:0 $\rightarrow$ Output:0

```cpp
#include<bits/stdc++.h>
using namespace std;
long long unit[]={10000000,100000,1000,100};
string name[]={"kuti","lakh","hajar","shata"};
void solve(long long n){
	for(int i=0;i<4;i++){
		if(n>=unit[i]){ //1234567890
			solve(n/unit[i]); //123
			cout<<" "<<name[i];
			n%=unit[i];
		}
	}
	if(n>0){
		cout<<" "<<n;
	}
}

int main(){
	long long n;
	int t=1;
	while(cin>>n){
		cout<<setw(4)<<t++<<".";
		if(n==0){
			cout<<" 0";
		}
		else{
			solve(n);
		}
		cout<<endl;
	}
	return 0;
}
```
