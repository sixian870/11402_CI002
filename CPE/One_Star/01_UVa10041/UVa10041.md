# UVa 10041 - Vito's family

## 題目簡述

Vito 想要找一間房子，使得他家到所有親戚家的距離總和為最小。<br>
給定 r 個親戚家的門牌號碼，兩家之間的距離定義為兩者門牌號碼的絕對差值。<br>
請計算出 Vito 的新家到所有親戚家的最小總距離。

**Sample Input**：

  **2**        $\rightarrow$ 測資數量。<br>
  **2 2 4**    $\rightarrow$ 第一個整數 r 代表親戚的總人數（0 < r < 500），接著有 r 個正整數，表各個門牌號碼（ 0 ~ 30000 ）。<br>
  **3 2 4 6**

**Sample Output**：

  **2**        $\rightarrow$ 輸出 Vito 新家到所有親戚家的最小距離總和，每一筆測資的結果輸出佔獨立的一行。<br>
  **4**

**題目連結**：[UVa10041](./UVa10041.pdf)


## 程式碼

將所有親戚的門牌號碼從小到大排序後，取中位數（Median）為 Vito 的新家位置，再與所有親戚家取差的絕對值加總。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int t;
	cin>>t;
	while(t--){
		int n;
		cin>>n;
		vector<int> arr(n);
		for(int i=0;i<n;i++){
			cin>>arr[i];
		}
		sort(arr.begin(),arr.end());
		int mid=arr[n/2]; //無條件捨去
		int total=0;
		for(int j=0;j<n;j++){
			total+=abs(arr[j]-mid);
		}
		cout<<total<<endl;
	}
}
