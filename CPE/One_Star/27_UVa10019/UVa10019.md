# UVa 10019 - Funny Encryption Method


## 題目簡述

給定一個正整數 $M$，請依據以下兩種不同的進位制解讀方式，計算出它轉成二進位後 `1` 的個數：
1. **$b_1$**：將 $M$ 當作一般的**十進位**數字，並計算其轉換成二進位後含有幾個 `1`。
2. **$b_2$**：將 $M$ 當作**十六進位**數字，並計算其每一位數位（digits）各自轉換成 4 bits 二進位後，全部共有幾個 `1`。

**Sample Input**：

  **3** $\rightarrow$ 測資數量 $t$。<br>
  **265** $\rightarrow$ 第一個正整數 $M$（ $M \le 9999$ ）。<br>
  **111**<br>
  **1234**

**Sample Output**：

  **3 5** $\rightarrow$ $265_{10} = 100001001_2$ 共 3 個 1； $265_{16} \rightarrow 2(0010), 6(0110), 5(0101)$ 共 5 個 1。<br>
  **6 3**<br>
  **5 5** $\rightarrow$ 每組輸出包含 $b_1$ 與 $b_2$，中間以一個空白隔開，各佔獨立一行。


## 程式碼

針對 $b_1$ 直接傳入原數值計算；針對 $b_2$ 則透過除以 10 取餘數的方式，逐一拆解出各個數位，個別計算 `1` 的個數後進行總和累加。

```
input M
output b1,b2
b1:M(十進位)->二進位,統計1
M=1234,b1=10011010010,1的個數=5
b2:M(16進位)->10進位->二進位,統計1
M=1234
1=0001
2=0010
3=0011
4=0100
b2=0001 0010 0011 0100,1的個數=5
```
> 利用 `__builtin_popcount()` 內建函式可以直接將十進位轉成二進位並計算一的個數。
```cpp
#include<iostream>
#include<algorithm>
using namespace std;
int count(int n) {
	return __builtin_popcount(n);
}
int main() {
	int t;
	cin >> t;
	while (t--) {
		int m;
		cin >> m;
		int b1 = count(m);
		int b2 = 0;
		while (m > 0) {
			int digit = m % 10;
			b2 += count(digit);
			m /= 10;
		}
		cout << b1 << " " << b2 << "\n";
	}
	return 0;
}
```
