# UVa 10056 - What is the Probability?


## 題目簡述

有 $t$ 組測試資料，每組測資給定 $N$ 個玩家輪流進行某個獨立事件，第一個成功達成特定結果的人就獲勝。<br>
已知每個人單次成功的機率為 $p$（則失敗率為 $q = 1-p$）。<br>
遊戲會依玩家 $1, 2, \dots, N, 1, 2, \dots$ 的順序一直輪流下去，直到有人獲勝為止。<br>
請計算出第 $I$ 個玩家獲勝的總機率。

**Sample Input**：

  **2**  $\rightarrow$ 測資數量。<br>
  **2 0.166666 1**  $\rightarrow$  分別代表：總人數 $N$、單次成功率 $p$、目標第 $I$ 個玩家。<br>
  **2 0.166666 2**

**Sample Output**：

  **0.5455**  $\rightarrow$ 輸出第 $I$ 個玩家獲勝的總機率，四捨五入至小數點後 4 位。<br>
  **0.4545**


## 程式碼

1.  總機率為 $\frac{p \times q^{I-1}}{1-q^N}$
2.  先處理 $p = 0$ 的特例以防分母為 0（1 - pow(q, n) 變成 0）；其餘情況則計算出首項與公比後相除。
3.  利用 fixed 和 setprecision(4) 控制輸出精度。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int t;
	cin>>t;
	while(t--){
		int n,i;
		double p,q,a,b,c;
		cin>>n>>p>>i;
		if(p==0){
			cout<<0.0000<<endl;
		}
		else{
			q=1-p;
			a=p*pow(q,i-1);
			b=1-pow(q,n);
			c=a/b;
			cout<<fixed<<setprecision(4)<<c<<endl;
		}
	}
	return 0;
}
```
