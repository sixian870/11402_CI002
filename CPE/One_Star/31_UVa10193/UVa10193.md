# UVa 10193 - All You Need Is Love


## 題目簡述

給定兩組二進位字串 $S_1$ 與 $S_2$，問是否能找到另一個長度大於 1 的二進位字串 $L$（代表「愛」），使得 $S_1$ 和 $S_2$ 都能夠完全透過不斷減去 $L$ 來扣到 0。<br>
如果能找到這個代表愛的字串 $L$，請印出 `All you need is love!`；如果找不到，則印出 `Love is not all you need!`。

> 一個數字可以被另一個數字不斷扣除直到歸零，代表後者是前者的因數。<br>
> 因此，若 $S_1$ 和 $S_2$ 都能被 $L$ 扣到 0，代表 $L$ 是兩者的公因數。<br>
> 題目要求 $L$ 的長度必須大於 1（意即 $L$ 的十進位數值不能是 1），這代表**兩數轉換成十進位後，它們的最大公因數（GCD）必須大於 1**。

**Sample Input**：

  **5** $\rightarrow$ 測資組數 $t$。<br>
  **11011** $\rightarrow$ 第一組的 $S_1$（十進位為 27）。<br>
  **11000** $\rightarrow$ 第一組的 $S_2$（十進位為 24）。<br>
  **11011** $\rightarrow$ 第二組的 $S_1$（十進位為 27）。<br>
  **11001** $\rightarrow$ 第二組的 $S_2$（十進位為 25）。<br>
  **111111**<br>
  **100**<br>
  **1000000000**<br>
  **110**<br>
  **1010**<br>
  **100**

**Sample Output**：

  **Pair #1: All you need is love!** $\rightarrow$ $\text{GCD}(27, 24) = 3 > 1$，有大於 1 的公因數，故有解。<br>
  **Pair #2: Love is not all you need!** $\rightarrow$ $\text{GCD}(27, 25) = 1 = 1$，沒有大於 1 的公因數，故無解。<br>
  **Pair #3: Love is not all you need!** <br>
  **Pair #4: All you need is love!** <br>
  **Pair #5: All you need is love!**


## 程式碼

1.  先建立 `gcd` 函式。
2.  讀入二進位字串後，由右往左（權重最小）轉十進位整數 `n1` 與 `n2`。
3.  最後利用 `gcd(n1, n2) == 1` 來判定，若最大公因數大於 1 則代表有解。

```cpp
#include<iostream>
#include<string>
#include<cmath>
using namespace std;
int gcd(int a, int b) {
	if (b == 0) return a;
	return gcd(b, a % b);
}
int main() {
	int t;
	cin >> t;
	int count = 1;
	while (t--) {
		string s1, s2;
		int n1 = 0, n2 = 0;
		cin >> s1 >> s2;
		int p1 = 0;
		for (int i = s1.size() - 1; i >= 0; i--) { // size()=3 i=2,1,0 -> s1[2],s1[1],s1[0]
			n1 += (s1[i] - '0') * pow(2, p1);
			p1++;
		}
		int p2 = 0;
		for (int i = s2.size() - 1; i >= 0; i--) {
			n2 += (s2[i] - '0') * pow(2, p2);
			p2++;
		}
		cout << "Pair #" << count++ << ": ";
		if (gcd(n1, n2) == 1) {
			cout << "Love is not all you need!\n";
		}
		else {
			cout << "All you need is love!\n";
		}
	}
	return 0;
}
```
