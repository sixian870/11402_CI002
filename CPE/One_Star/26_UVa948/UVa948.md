# UVa 948 - Fibonaccimal Base


## 題目簡述

任何正整數都可以唯一分解成數個「不連續」的費氏數（Fibonacci numbers）之和（即齊肯多夫定理）。<br>
本題要求將一個十進位的正整數，轉換成 **「費氏進位制（Fibonaccimal Base）」** 的二進位字串型態。<br>
費氏進位制從右到左每一位的權重分別是 $1, 2, 3, 5, 8, 13, 21, \dots$（由標準費氏數列的 $F_2$ 開始）。

> 轉換出來的二進位字串中，**絕對不能出現連續的 `1`**（例如 `110` 是不合法的）。只要採用由大到小的貪婪法進行扣除，就能天然避開連續 `1` 的問題。

**Sample Input**：

  **10** $\rightarrow$ 測資數量 $t$。<br>
  **1** $\rightarrow$ 接下來有 $t$ 行，每行包含一個正整數且 $< 100,000,000$ 。<br>
  **2**<br>
  **3**<br>
  **4**<br>
  **5**<br>
  **6**<br>
  **7**<br>
  **8**<br>
  **9**<br>
  **10**

**Sample Output**：

  **1 = 1 (fib)** $\rightarrow$ `十進位數 = 費氏進位數 (fib)`。<br>
  **2 = 10 (fib)** <br>
  **3 = 100 (fib)** <br>
  **4 = 101 (fib)** $\rightarrow$ $4 = 3 + 1$，對應權重 3 和 1 的位置放 `1`。<br>
  **5 = 1000 (fib)** <br>
  **6 = 1001 (fib)** <br>
  **7 = 1010 (fib)** <br>
  **8 = 10000 (fib)** <br>
  **9 = 10001 (fib)** <br>
  **10 = 10010 (fib)**


## 程式碼

1. 確定 $fib$ 數列上限，因為輸入 $n < 100,000,000$ ，利用下面程式碼取得 $fib[40]=102334155$ 大於 $100,000,000$ 的最小值，所以 index 上限為 39。

  ```cpp
  #include<iostream>
  #include<vector>
  using namespace std;
  int main() {
  	vector<long long> fib;
  	fib.push_back(0);
  	fib.push_back(1);
  	for (int i = 2; i < 50; i++) {
  		fib.push_back(fib[i - 1] + fib[i - 2]);
  	}
  	for (int i = 2; i < 50; i++) {
  		cout << i << "=" << fib[i] << "\n";
  	}
  }
  ```
2. 建立長度為 40 的 $fib$ 數列， `fib(40)` 表建立一個大小為 40 且填滿 0 的陣列，所以不能用 `push_back()`。
3. 每筆測資輸入時，先透過倒著窮舉的 `for` 迴圈，尋找第一個小於等於 `n` 的費氏數作為起始進位點 `idx`。
4. 隨後由大到小以貪婪法嘗試扣除：若當前數值夠扣則輸出 `1` 並減去該費氏數，否則輸出 `0`，直到扣至權重為 1（`i > 1`）為止。


```cpp
#include<iostream>
#include<vector>
using namespace std;
int main() {
	vector<long long> fib(40);//index=0~39,填 0,不能用 push_back()
	fib[0] = 0;
	fib[1] = 1;
	for (int i = 2; i < 40; i++) {
		fib[i] = (fib[i - 1] + fib[i - 2]);
	}
	int t;
	cin >> t;
	while (t--) {
		int n;
		cin >> n;
		int idx;
		for (int i = 39; i > 1; i--) {
			if (fib[i] <= n) {
				idx = i;
				break;
			}
		}
		cout << n << " = ";
		for (int i = idx; i > 1; i--) {
			if (n >= fib[i]) {
				cout << "1";
				n -= fib[i];
			}
			else {
				cout << "0";
			}
		}
		cout << " (fib)\n";
	}
	return 0;
}
```
