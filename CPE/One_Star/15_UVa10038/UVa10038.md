# UVa 10038 - Jolly Jumpers


## 題目簡述

輸入一個長度為 $n$ 的整數序列（ $n > 0$ ），如果相鄰兩數之差的絕對值，剛好包含了 $1$ 到 $n-1$ 的所有整數（不限順序），那麼這個序列就被稱為「Jolly Jumper」。
```
4 1,4,2,3
4=n
|1-4|=3
|4-2|=2
|2-3|=1
{1,2,3}=1~n-1 -> Jolly
```

**Sample Input**：

  **4 1 4 2 3**  $\rightarrow$ 第一個整數代表序列長度 $n$ ，後面接著 $n$ 個整數。<br>
  **5 1 4 2 -1 6**

**Sample Output**：

  **Jolly**  $\rightarrow$ 相鄰絕對差值為 3, 2, 1，剛好包含 1 到 3，故輸出 Jolly。<br>
  **Not jolly**    $\rightarrow$ 相鄰絕對差值為 3, 2, 3, 7，未完整包含 1 到 4，故輸出 Not jolly。。


## 程式碼

1.  動態宣告大小為 n 的 vector 來儲存輸入序列。
2.  用大小為 n-1 的 vector 儲存相鄰元素的絕對差值。
3.  將差值陣列排序後，利用迴圈檢查其內的所有數值是否與依序遞增的 $1 \sim n-1$ 完全吻合。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int n;
	
	while(cin>>n){ //4
		//cin>>n後再宣告 
		vector<int>arr(n);
		vector<int>b(n-1);
		//cin>>1,4,2,3
		for(int i=0;i<n;i++){
			cin>>arr[i]; //a[0]=1,a[1]=4,a[2]=2,a[3]=3
		}
		for(int j=0;j<n-1;j++){
			b[j]=abs(arr[j]-arr[j+1]);
		}
		sort(b.begin(),b.end()); //放迴圈外 
		
		bool isJolly=true;
		for(int k=0;k<n-1;k++){
			if(b[k]!=(k+1)){
				isJolly=false;
				break;
			}
		}
		if(isJolly){
			cout<<"Jolly"<<endl;
		}
		else{
			cout<<"Not jolly"<<endl;
		}
	}
	return 0;
}
```
