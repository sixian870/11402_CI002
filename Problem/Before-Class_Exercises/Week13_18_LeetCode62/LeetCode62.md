# LeetCode 62 - Unique Paths


## 題目簡述

一個機器人位於一個 $m \times n$ 網格的左上角（起始點在下圖中標記為「Start」）。<br>
機器人每次只能**向下**或者**向右**移動一步。機器人試圖達到網格的右下角（在下圖中標記為「Finish」）。<br>
請問從左上角到右下角，總共有多少條**不同的路徑**？

## 程式碼

1. **核心思考方向**：因為機器人只能「向下」或「向右」移動，這意味著要到達任何一個格子 $(i, j)$，只有兩種可能的前一步：
   - 從上方格子 $(i-1, j)$ 向下走一步。
   - 從左方格子 $(i, j-1)$ 向右走一步。

2. **狀態轉移方程式**：<br>
   依據加法原理，到達 $(i, j)$ 的相異路徑總數，必然等於到達其上方格子與左方格子的路徑數總和。我們可以定義一個二維陣列 `dp[i][j]` 代表到達該格子的方法數：
   $$\text{dp}[i][j] = \text{dp}[i-1][j] + \text{dp}[i][j-1]$$

3. **基地條件（Base Case）初始化**：<br>
   對於最上面那一列（`i = 0`）以及最左邊那一欄（`j = 0`），機器人只能一路向右或一路向下走，不可能有其他方向過來。因此，首列與首欄的每一格路徑數一律初始化為 `1`。

4. **空間優化技巧（滾動陣列）**：<br>
   仔細觀察狀態轉移，`dp[i][j]` 只依賴「同欄上一列」與「同列左一欄」的值。這代表我們不需要開一個巨大的 $m \times n$ 二維陣列，只需要維護**一維陣列（長度為 $n$）**，隨著列數不斷向下覆蓋更新（`dp[j] += dp[j-1]`）即可。這能將空間複雜度從 $O(M \times N)$ 直接壓縮至極致的 $O(N)$！
   
```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<int> dp(n, 1);
        
        // 從第 1 列開始，逐列向下動態更新（第 0 列已經在初始化時填滿 1 了）
        for (int i = 1; i < m; i++) {
            // 每列從第 1 欄開始更新（第 0 欄永遠只能從上面走下來，方法數維持 1 不變）
            for (int j = 1; j < n; j++) {
                // 未更新的 dp[j] 代表上方格子，dp[j-1] 代表左方格子
                dp[j] += dp[j - 1];
            }
        }
        // 最終陣列的最後一格即為右下角的相異總路徑數
        return dp[n - 1];
    }
};
```
