# LeetCode 70 - Climbing Stairs


## 題目簡述

假設你正在爬樓梯。需要 `n` 階你才能到達樓頂。<br>
每次你都可以爬 `1` 階或 `2` 階。請問你有多少種不同的方法可以爬到樓頂？

**Sample Input & Output**：

* **Example 1 :**
  * **Input :** `n = 2`
  * **Output :** `2`
  * **解釋 :** 有兩種方法可以爬到樓頂：
    1. 1 階 + 1 階
    2. 2 階

* **Example 2 :**
  * **Input :** `n = 3`
  * **Output :** `3`
  * **解釋 :** 有三種方法可以爬到樓頂：
    1. 1 階 + 1 階 + 1 階
    2. 1 階 + 2 階
    3. 2 階 + 1 階


## 程式碼

1. **核心思考方向（倒推法）**：要到達第 `n` 階，你的最後一步只有兩種可能：
   - 從第 `n - 1` 階往上爬 `1` 階。
   - 從第 `n - 2` 階往上爬 `2` 階。

2. **狀態轉移方程式**：<br>
   依據加法原理，到達第 `n` 階的方法總數，必然等於到達第 `n - 1` 階的方法數加上到達第 `n - 2` 階的方法數。這完全符合 **費氏數列（Fibonacci Sequence）** 的規律：
   $$\text{dp}[i] = \text{dp}[i-1] + \text{dp}[i-2]$$

3. **基地條件（Base Case）初始化**：
   - 到達第 1 階只有 1 種方法（走 1 步）。
   - 到達第 2 階有 2 種方法（走兩次 1 步，或直接走一個 2 步）。

4. **空間優化技巧（滾動變數）**：<br>
   雖然我們可以用一個長度為 `n + 1` 的陣列來存儲所有中間結果，但仔細觀察轉移方程式會發現，計算 `dp[i]` 時，我們**只關心前面的兩項**（`i - 1` 和 `i - 2`）。
   因此，我們完全不需要開陣列，只需要用兩個變數 `prev1` 和 `prev2` 像滾動齒輪一樣動態向前覆蓋（滾動陣列思想），就能將額外的空間複雜度降至極致的 $O(1)$！

```cpp
class Solution {
public:
    int climbStairs(int n) {
        // 若 n 為 1 或 2，直接回傳對應的階數
        if (n <= 2) {
            return n;
        }
        int prev2 = 1; // 代表 dp[i - 2]，初始化為第 1 階的方法數 (1)
        int prev1 = 2; // 代表 dp[i - 1]，初始化為第 2 階的方法數 (2)
        int curr = 0;  // 代表當前 dp[i] 的方法數
        
        // 透過動態規劃從第 3 階一路推導到第 n 階
        for (int i = 3; i <= n; i++) {
            curr = prev1 + prev2; // 當前階層方法數 = 前一階方法數 + 前兩階方法數
            prev2 = prev1; // 原本的前一階，變成下一輪的前兩階
            prev1 = curr;  // 原本的當前階，變成下一輪的前一階
        }
        return curr;
    }
};
```
