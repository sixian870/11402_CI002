# LeetCode 950 - Reveal Cards in Increasing Order


## 題目簡述

牌組中有一疊卡牌，每張牌上都有一個唯一的整數。你可以按以下順序桌面上翻開卡牌：
1. 從牌組頂端拿走一張牌，並將牠在桌面上翻開（顯示出來）。
2. 如果牌組中還剩下卡牌，把當前牌組頂端的下一張牌**移到牌組的底部**。
3. 重複步驟 1 和 2，直到所有的卡牌都已被翻開。

現在給定一個初始的卡牌陣列 `deck`。請你設計一個牌組的初始排列順序，使得當我們按照上述規則翻牌時，桌面上顯示的卡牌數字剛好是 **嚴格遞增（從小到大）** 的。

**Sample Input & Output**：

* **Example 1 :**
  * **Input :** `deck = [17,13,11,2,3,5,7]`
  * **Output :** `[2,13,3,11,5,17,7]`
  * **解釋 :** 
    * 初始為 `[2,13,3,11,5,17,7]`
    * 翻 2，剩 `[13,3,11,5,17,7]`，把 13 移到尾端 $\rightarrow$ `[3,11,5,17,7,13]`
    * 翻 3，剩 `[11,5,17,7,13]`，把 11 移到尾端 $\rightarrow$ `[5,17,7,13,11]`
    * 依此類推，翻開的順序剛好是 `[2,3,5,7,11,13,17]`，完美符合遞增。

* **Example 2 :**
  * **Input :** `deck = [1,1000]`
  * **Output :** `[1,1000]`


## 程式碼

1. **正向思考的困境**：如果我們想直接猜測答案的第一張、第二張牌應該放什麼，因為牌組會不斷地輪轉、插隊，正面模擬會變得極度混亂。

2. **神奇的逆向還原法**：
   - 既然我們希望最後被「翻開」的卡牌順序是由小到大（例如 `2, 3, 5, 7, 11`），那不如**把翻牌的過程完全倒過來做**！
   - 正向翻牌是：**「翻開一張」 $\rightarrow$ 「把頂端牌移到最底下」**。
   - 逆向還原就是：**「把最底下的牌移回頂端」 $\rightarrow$ 「從桌面上把牌收回頂端」**。

3. **利用 Deque 完美逆向還原**：
   - 先將原始牌組 `deck` **從大到小排序**（因為逆向還原要從最後一張大牌開始收回來）。
   - 使用 `std::deque` 模擬這疊牌。當我們要放入一張新的卡牌 `card` 時：
   - 如果 `deque` 裡面已經有牌，先將目前 `deque` 尾端的牌拔出來，插回 `deque` 的最前端（逆向模擬把底部的牌移回頂端）。
   - 接著，將目前從 `deck` 拿出的大牌推進 `deque` 的最前端（逆向模擬把翻開的牌收回頂端）。
   - 如此重複直到所有牌收完，`deque` 裡的順序就是題目要求的初始完美排法！

4. **時間與空間複雜度**：排序消耗 $O(N \log N)$，逆向還原消耗 $O(N)$。整體時間複雜度為 $O(N \log N)$，額外空間複雜度為 $O(N)$。

```cpp
class Solution {
public:
    vector<int> deckRevealedIncreasing(vector<int>& deck) {
        // 步驟 1：將卡牌由大到小（降序）排序，因為逆向還原要從最大張開始往回收
        sort(deck.rbegin(), deck.rend());
        
        deque<int> dq;
        
        // 步驟 2：逆向模擬還原過程
        for (int card : deck) {
            // 如果當前 deque 內已經有牌，必須先將最底部的牌移回頂端
            if (!dq.empty()) {
                int last_card = dq.back();
                dq.pop_back();
                dq.push_front(last_card);
            }
            // 將當前較小的牌收回至牌組頂端
            dq.push_front(card);
        }
        
        // 步驟 3：將 deque 內的完美排序複製回 vector 回傳
        return vector<int>(dq.begin(), dq.end());
    }
};
```
