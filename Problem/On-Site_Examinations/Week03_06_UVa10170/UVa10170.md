# UVa 10170 - The Hotel with Infinite Rooms

## 題目簡述

有一間擁有無限房間的特殊旅店，旅行團會根據以下規則入住：
* 一個規模為 $S$ 的旅行團入住後會住滿 $S$ 天。當他們退房離開後，隔天立刻會有一個規模為 $S+1$ 的旅行團入住，並住滿 $S+1$ 天。依此類推，後續旅行團的規模與入住天數都會不斷加 1。

給定第一天入住的旅行團規模 $S$ 以及一個目標天數 $D$，請計算在第 $D$ 天時，住在旅店裡的旅行團人數是多少。

**Sample Input**：

  **1 6** $\rightarrow$ $S$（初始人數）與 $D$（目標天數）。<br>
  **3 10** <br>
  **3 14**

**Sample Output**：

  **3** $\rightarrow$ 第 1 天住 1 人團（累計 1 天）；第 2, 3 天住 2 人團（累計 3 天）；第 4, 5, 6 天住 3 人團（累計 6 天 $\ge 6$），故第 6 天時為 3 人團。<br>
  **5** <br>
  **6**


## 解題思路與考點分析

### 核心觀念：等差級數求和
這道題目的本質是要求出一個最小的整數 $N$（其中 $N \ge S$），使得從 $S$ 累加到 $N$ 的總天數大於或等於 $D$：
$$\sum_{i=S}^{N} i = S + (S+1) + (S+2) + \dots + N \ge D$$

利用等差級數求和公式，總天數可以表示為：
$$\text{Total Days} = \frac{(S + N) \times (N - S + 1)}{2} \ge D$$

### 演算法步驟
1. 讀取初始團人數 $S$ 與目標天數 $D$。
2. **線性模擬**：利用迴圈讓 `total` 不斷累加當前的旅行團人數 $S$。每累加一次，天數邊界就會推進。當 `total >= d` 時，當前的 $S$ 即為答案；若未超過，則將 $S$ 加 1（代表下一團入住）繼續累加。
3. **數學公式優化**：將上述等差級數公式展開為一元二次方程式，利用公式解 $\frac{-b + \sqrt{b^2 - 4ac}}{2a}$ 直接無條件進位求得 $N$。


## 複雜度分析

| 評比面向 | 線性模擬法 | 數學公式解 |
| :--- | :--- | :--- |
| **時間複雜度** | $\mathcal{O}(\sqrt{D})$<br>由於每次累加的數值遞增，總和達到 $D$ 所需的步數約為 $\sqrt{2D}$ 次，面對本題的大測資仍可過關。 | $\mathcal{O}(1)$<br>完全不需要迴圈，僅需經過一次開根號與浮點數運算，效能達到理論極限。 |
| **空間複雜度** | $\mathcal{O}(1)$<br>僅需少數變數儲存狀態，未佔用額外記憶體。 | $\mathcal{O}(1)$<br>完全不佔用多餘空間。 |


## 邊界條件與潛在陷阱

1. **資料型態溢位陷阱 (Integer Overflow)**：
   題目規範 $D$ 最大可達到 $10^{15}$。標準的 32 位元有號整數（`int`）上限僅約 $2 \times 10^9$。如果在累加天數 `total` 或在處理 `d` 時使用 `int`，程式會立刻發生整數溢位進而陷入無窮迴圈（Time Limit Exceeded）。**因此，變數 $S, D$ 以及計數器 `total` 必須全數宣告為 `long long`**。
2. **$D$ 剛好等於等差級數和的臨界點**：
   例如 Sample 1 中 $S=1, D=6$，當 $N=3$ 時總和剛好是 $1+2+3=6$。此時 `total >= d`（$6 \ge 6$）成立，迴圈正確拆除並輸出 3。條件必須使用 `>=` 而非 `>`。


## 程式碼實作

### 線性模擬法

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 提升標準 I/O 串流效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    long long s, d;
    // 持續讀入測資直到檔案結束 (EOF)
    while (cin >> s >> d) {
        long long total = 0;
        while (true) {
            total += s;  // 累加入住天數
            if (total >= d) {
                break;   // 累計天數已涵蓋或超過目標天數，終止
            }
            s++;         // 切換至下一個規模加 1 的旅行團
        }
        cout << s << "\n"; // 輸出當前旅行團的人數
    }
    return 0;
}
```


## 進階優化思考

1. **數學解法（ $\mathcal{O}(1)$ 公式解）**
  我們將級數公式變形：
  $$\frac{(S+N)(N-S+1)}{2} \ge D \implies N^2 + N + (S - S^2 - 2D) \ge 0$$
  將其視為 $N^2 + N + C = 0$ 的一元二次方程式（其中 $C = S - S^2 - 2D$），利用公式解求出方程式的實數根，並使用 ceil() 無條件進位，就能直接得到最小符合條件的整數 $N$。

3. **二分搜尋法（Binary Search, $\mathcal{O}(\log(\text{bound}))$）**
   我們也可以對答案 $N$ 的可能範圍進行二分搜尋。已知 $N$ 的下界為 $S$，上界可估計為 $S + \sqrt{2D}$。在每次二分搜尋中，直接套用 $O(1)$ 的等差級數求和公式來驗證當前的中點（mid）是否大於等於 $D$，進而快速收斂邊界。

   **二分搜尋優化程式碼片段：**
    ```cpp
    long long low = s, high = s + 200000000LL; // 估算安全上界
    long long ans = high;

    while (low <= high) {
        long long mid = low + (high - low) / 2;
        // 計算從 s 累加到 mid 的總天數
        long long total_days = (s + mid) * (mid - s + 1) / 2;
    
        if (total_days >= d) {
            ans = mid;       // 此人數可行，記錄答案
            high = mid - 1;  // 試圖尋找更小的人數
        } else {
            low = mid + 1;   // 天數不足，必須增加人數
        }
    }
    cout << ans << "\n";
    ```
