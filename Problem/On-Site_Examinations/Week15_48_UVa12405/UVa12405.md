# UVa 12405 - Scarecrow

## 題目簡述

有一片大小為 $N$ 的一維農田，由兩種地塊組成：
* 字元 `.` 代表肥沃的土地，需要受到稻草人（Scarecrow）的保護。
* 字元 `#` 代表貧瘠的土地，不需要受到稻草人的保護。

每個稻草人都具有固定的覆蓋範圍：當把一個稻草人放置在位置 $i$ 時，它能同時保護三個連續的位置，即 $[i-1, i, i+1]$。<br>
請計算出在最聰明的分配策略下，最少需要放置多少個稻草人，才能確保所有肥沃的土地（`.`）都受到保護？

**Sample Input**：

  **3** $\rightarrow$ 測試資料組數 $T$。<br>
  **3** $\rightarrow$ 第一組農田大小 $N = 3$。<br>
  **...** $\rightarrow$ 農田地塊分布。<br>
  **11** $\rightarrow$ 第二組農田大小 $N = 11$。<br>
  **...##...#..**

**Sample Output**：

  **Case 1: 1** $\rightarrow$ 放置一個稻草人在中間即可覆蓋 3 個相連的 `.`。<br>
  **Case 2: 3**


## 解題思路與貪婪策略

### 核心觀念：單向線性的局部最優解（Greedy Algorithm）
這道題目的本質是**一維線性的區間覆蓋與貪婪演算法應用**。

為了讓總稻草人數量維持最少，從左到右掃描農田時，必須遵循以下貪婪決策：
1. **忽略非必要目標**：當遇到不需保護的貧瘠土地（`#`）時，不需浪費資源，直接將指標向右遞增 1：`i++`。
2. **極大化覆蓋範圍（最優放置點）**：當首次遇到需要保護的肥沃土地 `field[i] == '.'` 時，為了讓這個稻草人能發揮最大效益，我們**絕對不會**把稻草人放在 `i-1`，因為這樣只會浪費空間給左邊已經處理好的安全區。
   * **最佳解**：直接將稻草人放在 `i+1` 的位置。根據其保護範圍 $[(i+1)-1, i+1, (i+1)+1]$，這個稻草人會同時完美覆蓋 `i`、`i+1` 與 `i+2` 這三個連續地塊。

3. **跨步跳躍**：因為放置一個稻草人後，接下來的 `i`、`i+1`、`i+2` 這三個位置無論原本是 `.` 還是 `#`，都已經被這個稻草人全數強制接管保護。因此，可以放心地讓迴圈指標直接向右彈跳 3 格：`i += 3`，提早排除重複計算。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(N)$ <br>
  其中 $N$ 為農田的長度。在單層 `for` 迴圈中，雖然遇到 `.` 時會執行 `i += 3` 進行大幅度跳躍，但指標 `i` 始終保持嚴格單調遞增，整條農田從頭到尾剛好只會被精確掃描一次。因此，單組測資的時間複雜度為完美的線性時間 $\mathcal{O}(N)$。題目限制 $N \le 100$，可在微秒內瞬間執行完畢。
* **空間複雜度**： $\mathcal{O}(1)$ <br>
  除了讀入必要的 `string field` 外，僅使用固定數量的純量變數（`t`, `case_num`, `n`, `scarecrows`, `i`）進行迭代模擬，並未配置任何額外的動態資料結構或記憶體緩衝區。


## 邊界條件與潛在陷阱

1. **尾端溢出安全防禦（Out-of-Bounds 防禦）**：
   當在農田的尾端（例如倒數第一或第二個格子）遇到 `.` 時，我們依然會強制執行 `i += 3`。
   * **原程式碼分析**：原程式碼的迴圈控制條件為 `i < n`。當 `i += 3` 超出 $N$ 之後，迴圈會在下一輪判斷時因為 `i >= n` 而安全煞車退出。這完美避免了常規陣列存取越界（Out of Bounds）的地雷。
2. **農田長度不足 3 的臨界Case**：
   若農田只有 1 到 2 格且皆為 `.`，在第 0 格遇到 `.` 時，`scarecrows++` 隨即 `i += 3` 彈出迴圈。最終輸出 1，邏輯完全正確，因為無論如何都至少需要 1 個稻草人。
3. **空行與換行符的輸入對齊**：
   由於使用 `cin >> field` 讀取字串，它會自動忽略領頭的任何換行或空格。因此不需要在 `cin >> n` 後方手動插入 `cin.ignore()`，輸入流能保持完美的自適應單字對齊。


## 程式碼實作

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);

    int t;
    if (cin >> t) {
        for (int case_num = 1; case_num <= t; case_num++) {
            int n;
            cin >> n;

            string field;
            cin >> field; // 讀入農田的一維地塊配置字串

            int scarecrows = 0;
            // 靈活控制步長的 for 迴圈，結尾不設固定遞增項
            for (int i = 0; i < n; ) {
                // 貪婪核心：一旦遇到未受保護的肥沃土地 '.'
                if (field[i] == '.') {
                    scarecrows++; // 於 i+1 處配置稻草人，計數器加 1
                    i += 3;       // 該稻草人會自動覆蓋 i, i+1, i+2，游標安全向右跨越 3 格
                }
                // 遇到貧瘠土地 '#'，直接向右檢視下一格
                else {
                    i++;
                }
            }
            cout << "Case " << case_num << ": " << scarecrows << "\n";
        }
    }
    return 0;
}
```


## 進階優化思考
原做法利用不固定步長的 `for` 迴圈進行線性躍進，在時間與空間複雜度上都已經達到了理論的最優解。但如果從硬體指令與程式碼結構的精簡度（Code Elegance）來審視，這題存在一個完全免除分支判斷（`if-else`）、更加流式（Streaming）的優化重構手段。

**狀態標記滾動清除法（State-Decay 策略）**

* **原理**：我們不需要用變數 `i` 去小心翼翼地跳格子。可以用一個整數變數 `protected_until` 記錄目前受保護的有效邊界座標。

* **做法**：維持一個標準且常規的 for (int i = 0; i < n; i++) 迴圈。每當遇到 field[i] == '.' 時，先檢查 i 是否已經大於或等於 protected_until：

  * 若是，代表當前格暴露在安全網之外。此時必須在此處立刻追加一個稻草人，並將安全網邊界向右推進：`protected_until = i + 3;`。
  * 若不是，代表當前格仍處在上一隻稻草人的輻射範圍內，直接忽略。
 
* **效能改善**：此重構版本將代碼壓縮成了標準的一層線性平鋪掃描，完全省去了在迴圈內部手動控管指標 `i` 增加量的繁瑣細節。由於消除了非對稱的指標突變，這能極大地幫助編譯器進行更激進的迴圈展開（Loop Unrolling）與向量化優化，是在工業級效能調優中非常實用的代碼強健性優化範式。

**優化程式碼實作片段：**
```cpp
int scarecrows = 0;
int protected_until = 0; // 記錄安全防護網能覆蓋到的最小邊界

for (int i = 0; i < n; i++) {
    // 只有當前格子是 '.' 且它超出了現有防護網的覆蓋範圍時，才需要新裝稻草人
    if (field[i] == '.' && i >= protected_until) {
        scarecrows++;
        protected_until = i + 3; // 更新保護天花板
    }
}
cout << "Case " << case_num << ": " << scarecrows << "\n";
```
