# UVa 11063 - B2-Sequence

## 題目簡述

給定一個包含 $N$ 個正整數的序列 $A = \{a_1, a_2, \dots, a_N\}$ 。若要稱此序列為一個 **B2-Sequence**，必須同時嚴格滿足以下兩項條件：
1. **嚴格遞增且大於零**： $1 \le a_1 < a_2 < a_3 < \dots < a_N$。
2. **任兩數之和皆不重複**：在序列中任意挑選兩個元素（這兩個元素可以相同，即 $i \le j$ ）相加，所有可能產生的組合和（ $a_i + a_j$ ）在數值上都必須是唯一的，不可重複出現。

請寫一個程式判斷給定的序列是否為 B2-Sequence。每一組測試資料的輸出之間必須以一個空行（Blank line）隔開。

**Sample Input**：

  **4** $\rightarrow$ 第一組序列長度 $N$。<br>
  **1 2 4 8** $\rightarrow$ 第一組序列內容。<br>
  **4** $\rightarrow$ 第二組序列長度 $N$。<br>
  **3 7 10 14**

**Sample Output**：

  **Case #1: It is a B2-Sequence.** $\rightarrow$ 任兩數和：2,3,5,9,4,6,10,8,12,16，皆無重複。<br>
  <br> $\rightarrow$ **注意：每組 Case 的輸出之間必須精確夾帶一個空行。**<br>
  **Case #2: It is not a B2-Sequence.** $\rightarrow$ 因為 $3 + 14 = 17$ 且 $7 + 10 = 17$，兩數和重複。


## 解題思路與多重條件驗證

### 核心觀念：序列條件篩選與兩數和去重
這道題目的本質是**基礎數列模擬（Simulation）與雜湊/排序去重驗證**。
在演算法設計上，可將整個驗證流程拆解為兩個核心階段：

1. **第一階段：基本序列合法性檢查**
   在透過迴圈讀入資料的同時，即時進行邊界與遞增防禦：
   * 第一個元素 $a_0$ 必須滿足 $a_0 \ge 1$（即大於 0）。
   * 後續的元素 $a_i$ 必須嚴格大於前一個元素 $a_{i-1}$（即 $a_i > a_{i-1}$ ）。
   若在讀取階段就違反上述規則，則可直接將 `isB2` 標記設為 `false`。

2. **第二階段：組合和唯一性檢查**
   若序列滿足第一階段，則利用雙層 `for` 迴圈枚舉所有可能的兩數相加組合。為了避免重複列舉相同的無序對，內層迴圈的起點 `j` 應從 `i` 開始（即 $i \le j$ ），將所有產生的和推入一個名為 `sum` 的 `vector` 陣列中。
   * **去重判斷**：將 `sum` 陣列進行從小到大的升序排序（`sort`）。排序後，相同的數值必然會相鄰。隨後遍歷 `sum` 陣列，只要發現 `sum[i] == sum[i-1]`，即代表有不同的組合產生了相同的和，宣告該序列不是 B2-Sequence。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(N^2 \log N)$
  雙層迴圈枚舉兩數之和，總共會產生 $\frac{N(N+1)}{2}$ 個和。隨後對這些和進行排序，若和的總個數為 $M$（其中 $M \approx \mathcal{O}(N^2)$），排序耗時為 $\mathcal{O}(M \log M) = \mathcal{O}(N^2 \log(N^2)) = \mathcal{O}(N^2 \log N)$。題目規範 $N \le 100$，最大運算量約為 $10000 \times 7 \approx 7 \times 10^4$ 次，可在幾毫秒內瞬間執行完畢。

* **空間複雜度**： $\mathcal{O}(N^2)$
  需要建立一個 `sum` 陣列來儲存所有兩數相加的和，空間大小與組合數呈二次方正比。當 $N = 100$ 時，`sum` 最大長度約為 5050，耗費記憶體極小。


## 邊界條件與潛在陷阱

1. **嚴格大於零的定義（ $a_1 \ge 1$ ）**：
   題目敘述規定 $A$ 是一個正整數序列。如果輸入包含 `0`（例如 `0 1 2 3`），雖然它滿足嚴格遞增，但因為 `0` 不是正整數，它**不符合 B2-Sequence 的定義**。原程式碼中的 `if (a[0] <= 0) isB2 = false;` 成功杜絕了此盲點。

2. **每組 Case 間的換行格式控制**：
   題目要求「每個 Case 的輸出之間必須有一個空行」。這代表**最後一組 Case 的輸出末尾也必須精確帶有兩個換行符（即最後一個答案印完後還要多留一個空行）**。原程式碼在每組 Case 的尾端都執行了 `cout << "\n";`（搭配前一行 `cout << "...\n"` 構成雙換行），完美符合 UVa 的評測格式要求。

3. **單一元素的兩數相加**：
   題目說明「任兩數之和」，這兩數可以是同一個元素（例如 $a_0 + a_0$）。因此內層迴圈必須是 `for (int j = i; ...)`，如果漏掉自己加自己的組合（把 `j = i` 誤寫成 `j = i + 1`），會漏掉某些極端重複的邊界測資。


## 程式碼實作

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n;
    int count = 1; // 用於紀錄當前的 Case 編號
    
    // 持續讀入序列長度 n，直到檔案結束 (EOF)
    while (cin >> n) {
        bool isB2 = true;
        vector<int> a(n);
        
        // 讀取數列並在第一階段即時驗證基本合法性
        for (int i = 0; i < n; i++) {
            cin >> a[i];
            if (i == 0) {
                // 條件一補強：第一個元素必須大於 0 (即為正整數)
                if (a[0] <= 0) {
                    isB2 = false;
                }
            }
            else {
                // 條件一補強：必須保持嚴格遞增
                if (a[i] <= a[i - 1]) {
                    isB2 = false;
                }
            }
        }
        
        // 輸出 Case 開頭格式
        cout << "Case #" << count++ << ": ";
        
        // 第二階段：驗證兩數之和唯一性
        if (isB2) {
            vector<int> sum;
            // 枚舉所有可能的兩數相加組合（包含本身相加，故 j 從 i 開始）
            for (int i = 0; i < n; i++) {
                for (int j = i; j < n; j++) {
                    sum.push_back(a[i] + a[j]);
                }
            }
            
            // 透過排序將相同的元素聚集在一起
            sort(sum.begin(), sum.end());
            
            // 檢查是否有相鄰的兩數和完全相等
            for (int i = 1; i < (int)sum.size(); i++) {
                if (sum[i] == sum[i - 1]) {
                    isB2 = false; // 偵測到重複的和，宣告失敗
                    break;
                }
            }
        }
        
        // 依據最終狀態輸出結論
        if (isB2) {
            cout << "It is a B2-Sequence.\n";
        }
        else {
            cout << "It is not a B2-Sequence.\n";
        }
        
        // 核心格式：每組測試資料結束後都必須補上一個空行
        cout << "\n";
    }
    return 0;
}
```


## 進階優化思考

原做法在產生所有兩數和後，進行了一次全局排序（ $\mathcal{O}(M \log M)$ ），其效率在題目限制下已非常優秀。但如果追求更直觀且可能在相異和極多時達到提早結束的邏輯，可以使用另一種資工系核心容器。

**使用布林標記陣列或雜湊表（布林陣列 / `std::unordered_set` ）**

* **原理**：題目給定 $N \le 100$ 且數列嚴格遞增。如果測資保證了數字的最大上限（假設 $a_i \le 10000$），那麼最大的兩數之和不超過 $20000$。

* **做法**：此時可以宣告一個大小為 20005 的布林標記陣列 bool visited[20005] = {false};。在雙層迴圈枚舉兩數和 current_sum = a[i] + a[j] 時：

  * 若 visited[current_sum] 已為 true，代表此和在之前已被其他組合產生過，直接將 isB2 設為 false 並當場中斷所有迴圈。

  * 若為 false，則將其標記為 true。

* **效能改善**：這樣做可以省去最後的排序步驟，將時間複雜度進一步優化到最佳的 $\mathcal{O}(N^2)$。且一遇到重複便能立刻跳出，在面對非 B2-Sequence 的錯誤測資時，執行效率能大幅領先。若數列最大值極大，則可將布林陣列改為 std::unordered_set<int> 雜湊集合，同樣能在平均 $\mathcal{O}(1)$ 時間內做到即時去重檢查。
