# UVa 10252 - Common Permutation

## 題目簡述

給定兩個由小寫英文字母組成的字串 $a$ 與 $b$。<br>
請找出一個最長的字串 $x$，使得 $x$ 經過某種重新排列（Permutation）後，可以同時成為 $a$ 的子序列（Subsequence）與 $b$ 的子序列。<br>
**若有多個符合條件的字串 $x$，請輸出字典順序（Alphabetical order）最小、也就是依 `a` 到 `z` 升序排列的那個字串。**

**Sample Input**：

  **pretty** $\rightarrow$ 第一組第一個字串 $a$。<br>
  **women** $\rightarrow$ 第一組第二個字串 $b$。<br>
  **walking** $\rightarrow$ 第二組第一個字串 $a$。<br>
  **down** $\rightarrow$ 第二組第二個字串 $b$。

**Sample Output**：

  **e** $\rightarrow$ "pretty" 與 "women" 共同擁有的字母只有 'e'。<br>
  **nw** $\rightarrow$ "walking" 與 "down" 共同擁有 'n' 與 'w'，按字典順序由小到大輸出 "nw"。


## 解題思路與字母頻率統計

### 核心觀念：交集元素計數與自動有序輸出（Histogram / Counting Sort）
這道題目的本質是**集合的交集元素提取（Multi-set Intersection）與計數排序思維**。
題目要求輸出共同擁有的最長子序列，且必須依照「字典順序」由小到大排列。這意味著**原始字串中字母的相對位置完全不重要**，我們唯一關心的是「每個字母在兩個字串中各自出現了幾次」。

1. **直方圖統計（Histogram）**：
   因為只有 26 個小寫英文字母，可以使用兩個大小為 26 的整數陣列 `count1` 與 `count2` 分別當作兩個字串的字母頻率直方圖。利用基底偏移公式 `c - 'a'`，可在 $\mathcal{O}(1)$ 時間內將字母映射至索引 0 到 25。
2. **取交集極小值（Intersection Minimization）**：
   對於同一個字母（例如 `'o'`），若它在字串 $a$ 中出現了 3 次，在字串 $b$ 中出現了 1 次，那麼在同時滿足兩者的最長共同元素中，該字母最多隻能出現 $\min(3, 1) = 1$ 次。
3. **字典序有序輸出**：
   因為陣列索引 0 到 25 天然對應了 `'a'` 到 `'z'` 的升序字典順序。我們只需依序從 `i = 0` 遍歷到 `25`，計算當前字母的共同交集次數 `t = min(count1[i], count2[i])`，並利用內層迴圈連續輸出 `t` 次該字母。這種「依索引順序輸出」的策略天然保證了結果完全符合字典順序，不需要再進行任何高昂的排序（Sort）運算。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(A + B + \Sigma)$
  其中 $A$ 為字串 $a$ 的長度，$B$ 為字串 $b$ 的長度，$\Sigma$ 為字母表的大小（固定為 26）。統計兩字串頻率各需走訪一次，耗時 $\mathcal{O}(A + B)$。後續的輸出階段只需遍歷一次大小為 26 的陣列，內層輸出次數上限為 $\min(A, B)$。因此，整體的執行時間與字串長度呈完全的線性正比，屬於最優的時間複雜度。
* **空間複雜度**： $\mathcal{O}(\Sigma)$
  只需要兩個大小固定為 26 的整數陣列 `count1` 與 `count2`。不論輸入的字串有多長，記憶體空間始終維持在 52 個整數的極小體積，空間複雜度為完美的固定常數 $\mathcal{O}(1)$。


## 邊界條件與潛在陷阱

1. **完全空字串或空白行的讀取防禦（`getline` 的核心關鍵）**：
   這是本題最經典的 Presentation Error (PE) 或 Wrong Answer (WA) 陷阱。題目明確指出輸入字串可能為**空字串（長度為 0 的空白行）**。若無腦使用 `cin >> v1 >> v2` 讀取，輸入流會直接跳過所有的空白行與換行符，去強行抓取下一個有內容的單字，這會造成資料配對完全錯位並引發雪崩。**必須嚴格使用 `getline(cin, v1)` 逐行讀入完整行，即使讀到空行也必須正確處理並輸出一個換行**。
2. **完全沒有共同字母**：
   若兩字串毫無交集（例如 `abc` 與 `xyz`），所有 `min` 計算結果皆為 0，內層輸出迴圈不執行，程式會正確輸出一個完全乾淨的換行符 `\n`。
3. **成對讀取的流控制**：
   主迴圈使用 `while (getline(cin, v1) && getline(cin, v2))` 可以保證每次都能成對抽離出兩行字串，在遇到 EOF 時能安全且精確地結束。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    string v1, v2;
    // 使用 getline 逐行讀取，確保能正確捕捉並處理長度為 0 的空行
    while (getline(cin, v1) && getline(cin, v2)) {
        
        int count1[26] = {0}; // 初始化字串一的字母頻率直方圖
        int count2[26] = {0}; // 初始化字串二的字母頻率直方圖
        
        // 統計字串一中的小寫字母頻率
        for (char c : v1) {
            if (c >= 'a' && c <= 'z') {
                count1[c - 'a']++; // 利用 ASCII 相減換算 0-25 索引
            }  
        }
        
        // 統計字串二中的小寫字母頻率
        for (char c : v2) {
            if (c >= 'a' && c <= 'z') {
                count2[c - 'a']++;
            }  
        }
        
        // 依索引 0 (a) 到 25 (z) 的天然字典順序走訪
        for (int i = 0; i < 26; i++) {
            // 貪婪交集：取兩字串中該字母出現次數的極小值
            int t = min(count1[i], count2[i]);
            
            // 將共同擁有的字母連續印出 t 次
            for (int j = 0; j < t; j++) {
                cout << (char)('a' + i); // 強制轉型回對應的 ASCII 字元
            }
        }
        cout << "\n"; // 每組測資比對完畢後輸出換行
    }
    return 0;
}
```


## 進階優化思考

若追求將程式碼的可讀性與標準庫（STL）深度整合，存在另一種精簡且優雅的架構。

**利用 std::string 與 std::set_intersection 進行集合求交集**

C++ 標準庫中的 <algorithm> 庫內建了一個高效的集合運算工具 std::set_intersection，它能在線性時間內自動求出兩個已排序序列的交集元素。

**優化程式碼實作片段：**
```cpp
while (getline(cin, v1) && getline(cin, v2)) {
    // 預處理：將兩個字串直接進行升序排序 (使其具備集合單調性)
    sort(v1.begin(), v1.end());
    sort(v2.begin(), v2.end());
    
    string result = "";
    // 利用內建黑科技，在線性時間內自動提取出字典序排序好的公共元素
    set_intersection(v1.begin(), v1.end(), 
                     v2.begin(), v2.end(), 
                     back_inserter(result));
                     
    cout << result << "\n";
}
```
* **效能與結構對比**：此做法雖然包含了 `sort` 的 $\mathcal{O}(N \log N)$ 排序開銷，相較於原做法的純線性統計略慢了一點點，但它完全消除了手動維護 `count1` 、`count2` 陣列與索引代數相加減的繁瑣步驟。程式碼行數大幅縮減，且大幅提高了語意表達的清晰度。
