# UVa 10783 - Odd Sum

## 題目簡述

給定一個閉區間 $[a, b]$，計算並輸出該區間內（包含 $a$ 與 $b$）所有**奇數（Odd numbers）的總和**。

**Sample Input**：

  **2** $\rightarrow$ 測資組數 $t$。<br>
  **1** $\rightarrow$ 第一組測資的起始數 $a$。<br>
  **5** $\rightarrow$ 第一組測資的結尾數 $b$（區間為 [1, 5]）。<br>
  **3** $\rightarrow$ 第二組測資的起始數 $a$。<br>
  **5** $\rightarrow$ 第二組測資的結尾數 $b$（區間為 [3, 5]）。

**Sample Output**：

  **Case 1: 9** $\rightarrow$ 在 [1, 5] 區間內的奇數為 1, 3, 5，總和為 $1 + 3 + 5 = 9$。<br>
  **Case 2: 8** $\rightarrow$ 在 [3, 5] 區間內的奇數為 3, 5，總和為 $3 + 5 = 8$。


## 解題思路與考點分析

### 暴力模擬法（迴圈走訪）
最直觀的方法是使用 `for` 迴圈從 $a$ 到 $b$ 逐一檢查每個整數。如果 `j % 2 != 0`（即為奇數），就將它累加到 `sum` 變數中。這個方法的思維簡單，在題目給定的資料範圍內足以通過。

## 複雜度分析

| 評比面向 | 暴力模擬法 | 數學公式法 (優化) |
| :--- | :--- | :--- |
| **時間複雜度** | $\mathcal{O}(b - a)$<br>時間取決於區間長度，隨著範圍變大，迴圈次數會線性增加。 | $\mathcal{O}(1)$<br>無論區間多大，都只需要進行幾次簡單的四則運算，效率極高。 |
| **空間複雜度** | $\mathcal{O}(1)$<br>僅需固定數量的純量變數，未佔用額外記憶體。 | $\mathcal{O}(1)$<br>不需開闢任何陣列，空間開銷為固定常數。 |


## 邊界條件與潛在陷阱 (Edge & Corner Cases)

1. **負數取餘數陷阱（C++ `%` 的行為）**：
   原程式碼使用 `j % 2 == 1` 判斷奇數。雖然這題題目規範 $a, b$ 為正整數（ $0 \le a \le b \le 100$ ），但這是一個非常重要的資工壞習慣。在 C++ 中，如果 $j$ 是負奇數（例如 $-3$），`-3 % 2` 的結果會是 `-1` 而不是 `1`。
   * **好習慣寫法**：應寫成 `j % 2 != 0` 或 `j & 1`（利用位元運算檢查最後一個 bit 是否為 1），這兩種寫法不論正負數都能完美通用。
2. **輸出格式規範**：
   題目要求輸出格式為 `Case X: Y`，注意 `Case` 與 `X:` 之間、以及冒號 `:` 與答案 `Y` 之間都有一個半形空格，若漏掉會被判為 Presentation Error (PE) 或 Wrong Answer (WA)。


## 程式碼實作
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 提升標準 I/O 效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int t, a, b;
    if (cin >> t) {
        for (int i = 1; i <= t; i++) {
            cin >> a >> b;
            int sum = 0;
            for (int j = a; j <= b; j++) {
                // 使用 != 0 可以同時相容正奇數(1)與負奇數(-1)的狀況，是更安全的防錯寫法
                if (j % 2 != 0) {
                    sum += j;
                }
            }
            cout << "Case " << i << ": " << sum << "\n"; // 使用 \n 提升效能
        }
    }
    return 0;
}
```


## 進階優化思考

**數學公式法（等差級數求和）**
區間內的奇數序列本質上是一個**公差 $d = 2$ 的等差級數**。我們不需要透過迴圈逐一累加，可以直接利用小學學過的「梯形公式（等差級數求和公式）」在 $\mathcal{O}(1)$ 常數時間內算出來：
$$\text{Sum} = \frac{(\text{首項} + \text{末項}) \times \text{項數}}{2}$$

1. **尋找首項（第一個奇數 $a_{\text{odd}}$）**：
   如果 $a$ 是偶數，那區間內的第一個奇數就是 $a + 1$；若 $a$ 本身是奇數，則首項就是 $a$。
2. **尋找末項（最後一個奇數 $b_{\text{odd}}$）**：
   如果 $b$ 是偶數，那區間內的最後一個奇數就是 $b - 1$；若 $b$ 本身是奇數，則末項就是 $b$。
3. **計算項數 $n$**：
   公式為： $n = \frac{b_{\text{odd}} - a_{\text{odd}}}{2} + 1$ 。
4. **直接套用公式**即可得到答案，完全不需執行迴圈。

**優化思路實作程式碼：**
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int t, a, b;
    if (cin >> t) {
        for (int i = 1; i <= t; i++) {
            cin >> a >> b;
            
            // 尋找區間內的第一個奇數 (首項)
            int start_odd = (a % 2 == 0) ? a + 1 : a;
            // 尋找區間內的最後一個奇數 (末項)
            int end_odd = (b % 2 == 0) ? b - 1 : b;
            
            int sum = 0;
            // 確保調整後的區間依然合法（排除 start_odd > end_odd 的無奇數情況）
            if (start_odd <= end_odd) {
                int n = (end_odd - start_odd) / 2 + 1; // 計算奇數項數
                sum = (start_odd + end_odd) * n / 2;   // 梯形公式求和
            }
            
            cout << "Case " << i << ": " << sum << "\n";
        }
    }
    return 0;
}
```
