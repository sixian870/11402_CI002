# UVa 11349 - Symmetric Matrix

## 題目簡述

給定一個大小為 $N \times N$ 的方陣，請判斷該矩陣是否為 **「中心對稱矩陣（Symmetric Matrix）」**。<br>
根據題目特殊的對稱定義，一個矩陣要符合對稱，必須同時滿足以下兩個核心條件：
1. **元素皆為非負數**：矩陣內的所有元素值都必須大於或等於 0（$\ge 0$）。若包含任何負數，則直接視為不對稱。
2. **中心點對稱**：以矩陣的幾何幾何中心點為基準，旋轉 180 度後元素必須完全重合。也就是對於任意座標 $(i, j)$，其對應的對稱位置元素必須相等，公式定義為：
$$M[i][j] == M[N - 1 - i][N - 1 - j]$$

**Sample Input**：

  **2** $\rightarrow$ 測試資料組數 $T$。<br>
  **N = 3** $\rightarrow$ 第一組方陣大小 $N = 3$（格式包含字元 `'N'`, `'='`）。<br>
  **1 2 3** $\rightarrow$ 矩陣實體內容。<br>
  **2 3 2**<br>
  **3 2 1**<br>
  **N = 2** $\rightarrow$ 第二組方陣大小 $N = 2$。<br>
  **5 6**<br>
  **-1 5** $\rightarrow$ 包含負數，不符定義。

**Sample Output**：

  **Test #1: Symmetric.** $\rightarrow$ 幾何中心旋轉 180 度重合且全為非負數。<br>
  **Test #2: Non-symmetric.** $\rightarrow$ 包含負數 `-1`，宣告不對稱。


## 解題思路與矩陣幾何對稱性

### 核心觀念：二維陣列中心映射與邊界防禦
這道題目的本質是**二維矩陣的幾何座標映射與合法性邊界檢查**。

1. **特殊輸入流抽離**：
   每組測資的邊長輸入格式為 `N = 3`。在 C++ 中，可以透過 `cin >> a >> b >> n;`（其中 `a` 和 `b` 為 `char` 型態），直接將字元 `'N'` 與 `'='` 從輸入流中吃掉，並將核心數字精確解析至整數變數 `n` 中。
2. **非負數即時檢查**：
   在雙層迴圈讀入矩陣元素的同時，可進行即時防禦。一旦發現 `M[i][j] < 0`，代表直接違反了題目的非負數約束條件，應立即將標記 `isS` 設定為 `false`。
3. **180 度中心對稱映射公式**：
   在一個 0-indexed 的 $N \times N$ 二維方陣中，座標 $(i, j)$ 繞幾何中心旋轉 180 度後的鏡像對稱座標必為 $(N - 1 - i, N - 1 - j)$。我們只需再次遍歷方陣，比對兩者是否相等。只要有一組不相等，即可提早結束（`break`）判定。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(N^2)$
  不論是讀入數據還是後續的對稱性檢查，都需要完整遍歷一次大小為 $N \times N$ 的方陣。因此單組測資的總比對次數與格子總數呈線性正比，即 $\mathcal{O}(N^2)$。題目規範 $N \le 100$，最大運算量約為 $100 \times 100 = 10,000$ 次，可在 1 毫秒內極速通關。
* **空間複雜度**： $\mathcal{O}(N^2)$
  需要動態配置一個大小為 $N \times N$ 的二維動態陣列 `vector<vector<long long>> M` 來儲存方陣數據。當 $N = 100$ 時，記憶體開銷低於 80 KB，空間效能配置極佳。


## 邊界條件與潛在陷阱

1. **整數型態溢位地雷（大數防禦）**：
   這題隱藏了一個極具殺傷力的數值地雷。雖然題目表明 $N \le 100$，但方陣內儲存的實體元素數值最大可達到 $2^{51}$ 甚至更高。如果無腦宣告為標準 32 位元有號整數（`int`），數據在讀入時就會直接發生**整數溢位（Integer Overflow）**，導致大正數被誤判為負數，引發邏輯崩潰。**因此，二維動態陣列的資料型態必須嚴格指定為 `long long`。**
2. **負數出現時的讀取流完整性**：
   原程式碼在一開始讀到負數時，雖然將 `isS = false`，但**並未直接使用 `break` 或 `continue` 中斷讀取**。這個設計非常關鍵且正確！因為 UVa 是流式測資，就算前面的格子已經不對稱，也必須強迫讓迴圈把整張地圖接下來的數字全部讀完，否則輸入流會發生嚴重錯位，導致後續所有 Test Case 全部邏輯雪崩。
3. **輸出格式的 Case 編號控制**：
   輸出的字串格式為 `Test #X: Symmetric.` 或 `Test #X: Non-symmetric.`。冒號 `:` 的前方沒有空格，後方則精確夾帶一個空格，這點在實作輸出時必須嚴格注意。


## 程式碼實作

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int t;
    int count = 1; // 用於紀錄當前的 Test Case 編號
    
    if (cin >> t) {
        while (t--) {
            char a, b;
            int n;
            bool isS = true;
            
            // 核心解析：吃掉多餘的 'N' 與 '=' 字元，並讀入方陣大小 n
            cin >> a >> b >> n;
            
            // 核心防禦：由於元素最大可達 2^51，必須宣告為 long long 避免溢位
            vector<vector<long long>> M(n, vector<long long>(n));
            
            // 讀取矩陣並在第一階段即時進行非負數驗證
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    cin >> M[i][j];
                    if (M[i][j] < 0) {
                        isS = false; // 偵測到負數，直接宣告不對稱
                    }
                }
            }
            
            // 標頭輸出格式
            cout << "Test #" << count++;
            
            // 第二階段：驗證 180 度中心點對稱性
            if (isS) {
                for (int i = 0; i < n; i++) {
                    for (int j = 0; j < n; j++) {
                        // 核心映射公式：比對當前格與 180 度翻轉鏡像格是否相等
                        if (M[i][j] != M[n - 1 - i][n - 1 - j]) {
                            isS = false;
                            break; // 偵測到相異，跳出內層迴圈
                        }
                    }
                    if (!isS) break; // 徹底跳出外層對稱檢查
                }
            }
            
            // 依據最終判定結果輸出結論
            if (isS) {
                cout << ": Symmetric.\n";
            }
            else {
                cout << ": Non-symmetric.\n";
            }
        }
    }
    return 0;
}
```


## 進階優化思考

原做法分成「讀取階段」與「比對階段」兩個獨立區塊，在架構上清晰明瞭。但在進階資工優化思維中，存在著一種能省去第二個雙層迴圈，並將空間複雜度直接壓縮到理論極限 $\mathcal{O}(1)$ 的極速流式解法。

**一體化在線比對與零矩陣記憶體優化（On-the-fly Scan, $\mathcal{O}(1)$ 空間）**

* **原理**：由於座標的中心點鏡像具有對稱性，當我們讀到地圖的後半段（例如 $i \ge N/2$）時，它要比對的前半段座標在記憶體中其實早已讀入完畢。

* **做法**：如果不想開闢海量的二維變數空間，我們其實只需要開闢一個一維的 `vector<long long>` 來當作滾動緩衝區（或者是只記錄前半段的資料）。甚至在已知數據規模很小時，依然採用一維陣列去平鋪二維空間 `M[i * n + j]` ，能大幅減少 vector 套 vector 的指標跳躍成本。

* **最優中斷**：雖然在遇到負數或相異時無法直接 break（為了維持輸入流對齊），但可以用一個旗標將後續的算術比對全部屏蔽掉，只讓 cin 執行純粹的數值讀取（Data Flushing）。這能省去後半段大量無謂的對稱檢查，在面對錯誤或不對稱的巨大矩陣時，能帶來最純粹的常數時間效能調優。
