# UVa 11559 - Event Planning

## 題目簡述

有一群共 $N$ 個人計畫去旅行，且預算上限為 $B$ 元。現在有 $H$ 家飯店可供選擇，旅行共計畫停留 $W$ 週。<br>
每家飯店有其固定的每人每週住宿費用 $P$。同時，每家飯店會給出這 $W$ 週內，每週剩餘的床位數量。<br>
請判斷在滿足以下兩項條件的前提下，這群人最少需要花費多少住宿總費用？
1. **床位足夠**：選擇的那一週，該飯店的剩餘床位數必須大於或等於人數 $N$。
2. **預算充足**：總花費（ $P \times N$ ）必須小於或等於預算 $B$。

若沒有任何一家飯店與週次能同時滿足上述條件，則輸出特定提示訊息。

**Sample Input**：

  **3 1000 2 3** $\rightarrow$ 人數 $N=3$、預算 $B=1000$、飯店數 $H=2$、週數 $W=3$。<br>
  **200** $\rightarrow$ 第一家飯店每人每週費用 $P = 200$。<br>
  **0 2 2** $\rightarrow$ 第一家飯店這 3 週各自剩餘的床位數。<br>
  **300** $\rightarrow$ 第二家飯店每人每週費用 $P = 300$。<br>
  **27 3 20** $\rightarrow$ 第二家飯店這 3 週各自剩餘的床位數。<br>
  **5 2000 2 4** $\rightarrow$ 人數 $N=5$ 、預算 $B=2000$ 、飯店數 $H=2$ 、週數 $W=4$ 。<br>
  **300** $\rightarrow$ 第一家飯店每人每週費用 $P = 300$。<br>
  **4 3 0 4** $\rightarrow$ 第一家飯店這 4 週各自剩餘的床位數。<br>
  **450** $\rightarrow$ 第二家飯店每人每週費用 $P = 450$。<br>
  **7 8 0 13** $\rightarrow$ 第二家飯店這 4 週各自剩餘的床位數。
  
  

**Sample Output**：

  **900** $\rightarrow$ 第一家飯店床位皆小於 3（不符）；第二家飯店第 1, 2, 3 週床位足夠，總花費 $300 \times 3 = 900 \le 1000$，故輸出最便宜的花費 900。<br>
  **stay home** $\rightarrow$ 第一家飯店床位皆小於 5（不符）；第二家飯店第 1, 2, 4 週床位足夠，總花費 $450 \times 5 = 2250 \ge 2000$，故輸出 `stay home` 。<br>


## 解題思路與多重條件篩選

### 核心觀念：極值尋找與流式條件過濾（Greedy Filtering）
這道題目的本質是**極值搜尋與二維資料的條件過濾模擬**。
因為需要尋找的是「最小」總花費，所以可以採用貪婪的滾動更新策略：

1. **極值初始化**：將目前找到的最小花費 `min_cost` 初始化為一個不可能達到的高值（例如 `B + 1`），這樣任何小於或等於預算 $B$ 的合法花費都能在後續順利將其覆蓋。
2. **多維資料讀取與即時過濾**：
   * 外層迴圈跑 $H$ 次，每次代表一家飯店，先讀入該飯店的每人房價 $P$。
   * **提早優化（選擇性）**：如果該飯店的基本總花費 $P \times N$ 本身就已經超過了總預算 $B$，雖然仍必須把後續的 $W$ 個床位資料讀完以維持輸入流正確，但後續的床位比對就可以直接忽略。
   * 內層迴圈跑 $W$ 次，讀入每週的空床數 $a$。只要發現某週的 `a >= N`（床位夠），且該飯店的總費用 `P * N < min_cost`（比目前紀錄的還要便宜），就立刻更新最優解：`min_cost = p * N`。
3. **最終判定**：所有飯店資料掃描完畢後，若 `min_cost` 依然大於 $B$，代表沒有任何方案符合規格，輸出 `stay home`；反之則輸出最小費用 `min_cost`。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(H \times W)$
  其中 $H$ 為飯店總數，$W$ 為週數。程式碼內使用了標準的雙層巢狀迴圈，外層走訪所有飯店，內層走訪所有週次，矩陣中的每個床位資料都剛好被讀取並比對一次。在題目給定的最大規模下（$H \le 18, W \le 13$），單組測資迴圈執行上限不超過 254 次，時間複雜度為極低的線性時間。
* **空間複雜度**： $\mathcal{O}(1)$
  本題完全不需要開闢陣列來儲存飯店房價或每週床位。透過邊讀取、邊即時進行 `if` 條件過濾與更新極值的策略，僅需要少數幾個純量整數變數（`N`, `B`, `H`, `W`, `p`, `a`）即可搞定，空間開銷為完美的固定常數。


## 邊界條件與潛在陷阱

1. **預算邊界防禦（ $Cost \le B$ ）**：
   原程式碼中初始化設為 `int min = B + 1;`，隨後在比對時寫成 `p * N < min`。最後輸出判斷為 `if (min <= B)`。這個邏輯非常漂亮，能完美兼顧「總花費剛好等於總預算 $B$」的極端臨界情況。
2. **多組測資讀取**：
   題目並未指明共有幾組測資，必須使用 `while (cin >> N >> B >> H >> W)` 來持續監聽輸入流，直到檔案結束。
3. **無解時的字串格式**：
   無解時必須精確輸出特定字串 `stay home`，注意全小寫且中間包含一個空格，若寫成首字母大寫（`Stay home`）會被直接判 Wrong Answer (WA)。


## 程式碼實作

以下為優化了變數命名（避免使用 C++ 內建關鍵字 `min` 作為變數名）並加上標準 I/O 加速的正確實作版本：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 提升標準 I/O 串流效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n, b, h, w;
    // 連續讀入人數、預算、飯店數、週數，直到 EOF 終止
    while (cin >> n >> b >> h >> w) {
        
        // 將最優花費初始化為預算 + 1 (即不可能的上限)
        int min_cost = b + 1; 
        
        // 走訪 H 家飯店
        for (int i = 0; i < h; i++) {
            int p; // 該飯店每人每週價格
            cin >> p;
            
            // 走訪 W 週的床位狀態
            for (int j = 0; j < w; j++) {
                int a; // 該週剩餘床位
                cin >> a;
                
                // 核心過濾：床位必須足夠，且當前總花費必須比歷史紀錄的更便宜
                if (a >= n && p * n < min_cost) {
                    min_cost = p * n; // 更新最小總花費
                }
            }
        }
        
        // 最終判定：若最小花費仍在預算內則輸出，否則宣告放棄旅行
        if (min_cost <= b) {
            cout << min_cost << "\n";
        } else {
            cout << "stay home\n";
        }
    }
    return 0;
}
```


## 進階優化思考

雖然目前的 $\mathcal{O}(H \times W)$ 已經快到無法再快，但從軟體工程與防錯設計（Robustness）的角度出發，程式碼結構還有一個優化改進點。

**內層迴圈提早中斷**

在目前的實作中，一旦某個飯店讀入的價格 $P$ 乘以人數 $N$ 已經大於預算 $B$（即 p * n > b），或者 p * n >= min_cost（已經不可能成為最優解），那麼該飯店接下來這 $W$ 週的床位到底夠不夠，其實對最終答案已經毫無影響。

然而，因為 UVa 的測資是連續流式輸入，我們絕對不能直接使用 break 彈出內層迴圈，否則後面殘留的床位數字會被下一家飯店的 cin >> p 錯誤地讀入，進而引發整條測資鏈的邏輯雪崩。

**安全提早中斷策略：**
如果想減少無謂的 if 幾何比較，可以使用一個布林旗標，在確定該飯店沒救時，雖然依舊讓迴圈跑完以「吃乾淨輸入流」，但直接跳過內部的核心比較邏輯。

```cpp
for (int i = 0; i < h; i++) {
    int p;
    cin >> p;
    bool skip_hotel = (p * n >= min_cost); // 若價格已經不具競爭力，則標記跳過
    
    for (int j = 0; j < w; j++) {
        int a;
        cin >> a;
        if (!skip_hotel && a >= n) {
            min_cost = p * n;
            skip_hotel = true; // 該飯店已找到最優解，此飯店剩餘週次可直接跳過
        }
    }
}
```
