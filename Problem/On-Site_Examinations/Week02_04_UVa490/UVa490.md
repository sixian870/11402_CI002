# UVa 490 - Rotating Sentences


## 題目簡述

將輸入的數行文字往順時針方向旋轉 90 度。也就是說，原本由左到右、由上到下的句子，要輸出成由上到下、由右到左。<br>
輸入最多不會超過 100 列，每列最多不超過 100 個字元。<br>
最後一列輸入必須垂直輸出在最左邊一行，輸入的第一列則垂直輸出在最右邊一行，若某列字串長度不足時，必須在該位置補上空白字元以維持對齊。

**空間對應示意圖**
```
00|10|20|30    02|01|00
01|11|21    -> 12|11|10
02|12|22       22|21|20
                 |  |30
```

**Sample Input**：

  **Rene Decartes once said** <br>
  **"I think, therefore I am."**

## 解題思路與矩陣旋轉原理

### 核心觀念：二維矩陣座標轉換
這道題目的本質是**非對稱矩陣（Non-square Matrix）的旋轉模擬**。<br>
假設我們將讀入的文本看成一個二維字元陣列 $\text{Matrix}[i][j]$ ，其中 $i$ 代表行數（Row）， $j$ 代表列數（Column/字元位置）。

根據題目「順時針旋轉 90 度」且「最後一行翻轉至最左側」的要求：
* 新矩陣的 **橫向列數（全新 Row）** 長度，會取決於舊矩陣所有字串中的 **最大長度 `maxLen`**。
* 在輸出新矩陣的第 $j$ 行時，我們必須**由下往上（從最後一行到第一行）**去讀取舊矩陣字串的第 $j$ 個字元。
* 轉換映射公式： $\text{NewMatrix}[j][\text{row} - 1 - i] = \text{OldMatrix}[i][j]$

### 演算法步驟
1. 使用 `getline(cin, s[row])` 逐行讀取文本。
2. 在讀取過程中，動態更新全域最長字串長度 `maxLen = max(maxLen, s[row].length())`。
3. 外層迴圈控制新矩陣的行數，從 $j = 0$ 走訪到 `maxLen - 1`。
4. 內層迴圈反向走訪每一行，從 $i = \text{row} - 1$ 遞減到 $0$：
   * 若當前索引 $j$ 小於該行字串長度 `s[i].length()`，則直接輸出字元 `s[i][j]`。
   * 若 $j$ 超出該字串長度，代表該位置為「空缺」，此時必須**強迫輸出一個空白字元 `" "`** 以維持矩陣方正。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(\text{row} \times \text{maxLen})$
  其中 $\text{row}$ 為輸入的總行數，$\text{maxLen}$ 為最長句子的字元數。矩陣中的每一個格子（包含有字元的格子與需要補空白的格子）都剛好被走訪並輸出一次，因此時間複雜度為線性時間。
* **空間複雜度**： $\mathcal{O}(\text{row} \times \text{maxLen})$
  需要開闢一個能夠容納所有字串的陣列空間。題目給定最多 100 列、每列最多 100 字元，因此使用 `string s[105]` 佔用的記憶體極小（約數 KB），空間複雜度完全在安全範圍內。


## 邊界條件與潛在陷阱 (Edge & Corner Cases)

1. **短字串夾在長字串中間的「置空陷阱」**：
   如果第一行很長、第二行很短、第三行也很長。當我們處理到高索引的 $j$ 時，第二行由於長度不足會進到 `else` 區塊補空白。如果不補空白，後面第三行的字元就會往左錯位，導致整個圖形歪掉。
2. **句尾空白的保留**：
   因為題目要求補空白維持對齊，所以即便某個短字串的右側全部都是空白，在旋轉後，這些空白會變成新矩陣的某一行。原程式碼中的雙重迴圈邏輯可以確保在矩陣範圍內的空缺都會確實填入 `" "`。
3. **測資範圍限制**：
   題目限制最多 100 列、每列最多 100 字元。宣告 `string s[105]` 或二維陣列時足夠涵蓋邊界即可，不需開過大。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    string s[105];
    int row = 0;
    int maxLen = 0;
    
    // 逐行讀取直到檔案結束 (EOF)
    while (getline(cin, s[row])) {
        // 紀錄最長字串的長度，作為旋轉後矩陣的新總行數
        if ((int)s[row].length() > maxLen) {
            maxLen = s[row].length();
        }
        row++;
    }
    
    // 外層迴圈控制縱向字元位置（原字串的 Column，新矩陣的 Row）
    for (int j = 0; j < maxLen; j++) {
        // 內層迴圈由最後一行往第一行反向讀取（原字串的 Row，新矩陣的 Column）
        for (int i = row - 1; i >= 0; i--) {
            // 若當前位置在該字串的有效長度內則輸出字元
            if (j < (int)s[i].length()) {
                cout << s[i][j];
            }
            // 若超出該字串長度，則必須補空白以維持旋轉矩陣的對齊
            else {
                cout << " ";
            }
        }
        cout << "\n"; // 每一行輸出完畢後換行（\n 效能優於 endl）
    }
    return 0;
}
```


## 進階優化思考

**向量陣列動態動態配置：**
改用 std::vector<string> 可以做到動態記憶體配置，即便未來題目測資規格放大到 1000 行以上，程式碼也完全不需要改動任何陣列大小，具備更高的強健性（Robustness）。

**優化思路實作片段：**
```cpp
vector<string> s;
string input_line;
int maxLen = 0;

while (getline(cin, input_line)) {
    maxLen = max(maxLen, (int)input_line.length());
    s.push_back(input_line);
}
int row = s.size();
```
