# UVa 11150 - Cola

## 題目簡述

若買了 $N$ 瓶可樂，商店有一個優惠活動：每 3 個空可樂瓶可以免費換 1 瓶全新的可樂。<br>
另外，可以向朋友「借空瓶」，條件是在喝完所有可樂後，必須湊得出足夠的空瓶還給朋友。<br>
請計算在最聰明的交換策略下（包含跟朋友借空瓶），最多總共可以喝到幾瓶可樂？

**Sample Input**：

  **8** $\rightarrow$ 一開始擁有的可樂數量 $N$（ $1 \le N \le 200$ ）。<br>
  **9**

**Sample Output**：

  **12** $\rightarrow$ 初始 8 瓶，依公式 $8 + \lfloor 8 / 2 \rfloor = 12$。<br>
  **13** $\rightarrow$ 初始 9 瓶，依公式 $9 + \lfloor 9 / 2 \rfloor = 13$。


## 解題思路與考點分析

### 核心觀念：空瓶回收轉換率
這道題目是經典的**邏輯思維與數學轉換題**。如果採用標準的「模擬法」，會需要寫一個 `while` 迴圈不斷處理「空瓶換新可樂、喝完變空瓶」的過程，並在最後剩餘 2 個空瓶時，手動模擬向朋友借 1 個空瓶、換 1 瓶喝完再還回去的邏輯。

然而，透過更深入的數學思維，可以將這個過程轉化為**常數時間的數學公式**：
1. 每拿 3 個空瓶去商店，換回 1 瓶新可樂（內含 1 個空瓶）。
2. 這代表**實質上只消耗了 $3 - 1 = 2$ 個空瓶，就淨賺了 1 瓶可樂的內容物**。
3. 因為題目允許跟朋友借空瓶（只要最後還得清），這意味著我們手頭上的空瓶可以被壓榨到完全不浪費。只要手上有 2 個空瓶，我們就能藉由向朋友借 1 個空瓶湊滿 3 個，換完喝掉後把產生的 1 個空瓶還給朋友。
4. 因此，除了原本買來的 $N$ 瓶可樂外，這 $N$ 個空瓶每 2 個就能為我們帶來 1 瓶新可樂。
5. 最終最優解公式即可化簡為：
$$\text{Total Cola} = N + \lfloor \frac{N}{2} \rfloor$$


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(1)$
  由於已經推導出直接解的數學公式，每組測資僅需執行一次基本的加法與整數除法，不需進行任何迴圈模擬，時間複雜度達到最理想的常數時間。
* **空間複雜度**： $\mathcal{O}(1)$
  僅使用一個整型變數 `n` 讀取輸入，沒有使用額外的記憶體或陣列結構，空間開銷為固定常數。


## 邊界條件與潛在陷阱 (Edge & Corner Cases)

1. **不可借空瓶的盲點（若不允許借空瓶）**：
   若不允許借空瓶，當最後剩下 2 個空瓶時，是無法向商店換可樂的。但本題因為允許「借了再還」，且每 2 個空瓶換 1 瓶喝完後的 1 個空瓶剛好可以拿去還給朋友，所以公式 $N + \lfloor N/2 \rfloor$ 對於所有滿足 $1 \le N \le 200$ 的正整數皆能完美一字不漏地成立。
2. **資料範圍與溢位評估**：
   題目表明 $N \le 200$，數值非常小。即使在多組測資連續輸入的情況下，直接輸出 `n + (n / 2)` 也完全不需要擔心整數溢位（Integer Overflow）的問題，使用標準 32 位元有號整數 `int` 即可。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n;
    // 持續讀入一開始擁有的可樂數 N，直到檔案結束 (EOF)
    while (cin >> n) {
        // 利用推導出的公式 N + N/2 直接在 O(1) 時間內輸出答案
        cout << n + (n / 2) << "\n";
    }
    return 0;
}
```


## 進階優化思考

1. **模擬法的對照實現**
   
    雖然公式解在效能上最優（ $\mathcal{O}(1)$ ），但在面試或演算法基礎訓練中，寫出常見的「直觀模擬法」也是必備技能。模擬法的邏輯為：只要手頭空瓶 empty >= 3，就持續進行兌換；最後當 empty == 2 時，代表可以借 1 瓶，因此總數可以再加 1。

    **模擬法程式碼片段：**
    ```cpp
    while (cin >> n) {
        int total = n;    // 總共喝到的可樂
        int empty = n;    // 當前手上的空瓶數
    
        while (empty >= 3) {
            int new_cola = empty / 3;
            total += new_cola;
            empty = (empty % 3) + new_cola;
        }
    
        // 剩 2 個空瓶時，可以跟朋友借 1 個湊滿 3 個，換完喝掉把空瓶還他
        if (empty == 2) {
            total += 1;
        }
        cout << total << "\n";
    }
    ```
    這個模擬法的時間複雜度為 $\mathcal{O}(\log_3 N)$，雖然比公式解慢，但可以更直觀地對應題目的物理情境。

2. **通用化擴充思考**（ $K$ 個空瓶換 1 瓶)
   
    如果題目將規則改為更通用的變體：「每 $K$ 個空瓶可以換一瓶全新的可樂」，那麼在允許借空瓶的聰明策略下，淨消耗的空瓶數會變成 $K - 1$ 個。延伸的通用公式則可以被推導為：

      $$\text{Total Cola} = N + \lfloor \frac{N}{K - 1} \rfloor$$
  
    這說明了透過數學抽象化，能夠將特定問題快速擴展到更通用的演算法模型中。
