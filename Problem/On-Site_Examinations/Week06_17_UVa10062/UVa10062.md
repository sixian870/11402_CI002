# UVa 10062 - Tell me the frequencies!

## 題目簡述

讀取數行文字，並統計每行文字中所有 ASCII 字元出現的次數（包含英文字母、數字、標點符號以及空格等）。<br>
最後的輸出必須依照字元出現的「次數」由小到大排列（升序）；若有字元出現的次數相同，則依據該字元的「ASCII 碼」由大到小排列（降序）輸出。<br>
**注意**：每組測試資料的輸出之間必須以一個空行（Blank line）隔開。

**Sample Input**：

  **AAABBBBC** $\rightarrow$ 第一組字串。<br>
  **123123** $\rightarrow$ 第二組字串。

**Sample Output**：

  **67 1** $\rightarrow$ 'C' 出現 1 次（ASCII 67）。<br>
  **65 3** $\rightarrow$ 'A' 出現 3 次（ASCII 65）。<br>
  **66 4** $\rightarrow$ 'B' 出現 4 次（ASCII 66）。<br>
  <br> $\rightarrow$ **核心注意：兩組輸出之間必須有一個空行。**
  **49 2** $\rightarrow$ '1' 出現 2 次（ASCII 49）。<br>
  **50 2** $\rightarrow$ '2' 出現 2 次（ASCII 50）。<br>
  **51 2** $\rightarrow$ '3' 出現 2 次（ASCII 51）。次數相同時，ASCII 碼大的排前面。


## 解題思路與多條件排序

### 核心觀念：全字元頻率統計與自訂結構體排序
這道題目的本質是**字元頻率統計與多條件反向排序**。與一般的字母統計題不同，本題需要統計所有的 ASCII 字元（共 256 種可能），且排序規則與常見的「次數由大到小」剛好相反。

1. **頻率統計**：由於 ASCII 碼的範圍為 0 到 255，可以使用一個大小為 256 的整數陣列 `arr1` 作為直方圖（Histogram）。字元可以直接作為陣列的索引，實現 $\mathcal{O}(1)$ 的計數。為了防止某些延伸 ASCII 碼（Extended ASCII）產生負數索引，轉入陣列時需強轉為 `(unsigned char)`。
2. **多條件排序邏輯**：
   * **主要條件**：次數少者優先（升序排列）。
   * **次要條件**：當次數完全相同時，字元 ASCII 碼大者優先（降序排列）。
   這在 C++ 中可以透過撰寫自訂比較函式 `cmp` 傳入 `std::sort` 來完美實現。

### 演算法步驟
1. 利用 `while(getline(cin, s))` 逐行讀入整行字串，直到檔案結束（EOF）。
2. **空行控制**：使用一個布林旗標 `firstline` 紀錄是否為第一組輸出。若不是第一組，則在印出當前答案前先輸出一個 `cout << "\n"`，以確保兩組輸出間精確夾帶一個空行。
3. 初始化大小為 256 的陣列並清零，遍歷字串累加字元頻率。
4. 將所有次數大於 0 的字元與次數，封裝進自訂結構體並推入 `vector<Data> arr2` 中。
5. 使用 `std::sort` 搭配自訂比較函式 `cmp` 進行排序。
6. 遍歷 `arr2` 並輸出每個字元的 ASCII 十進位碼與次數。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(S + A \log A)$
  其中 $S$ 為單行字串的長度，統計字元耗時 $\mathcal{O}(S)$。而 $A$ 為相異字元的總數量（最大不超過 256）。對最大大小為 256 的 `vector` 進行排序，耗時上限為極小的固定常數 $256 \log 256 \approx 2048$ 次。因此，整體的執行時間完全取決於字串長度，屬於最優的線性時間。
* **空間複雜度**： $\mathcal{O}(K)$
  其中 $K$ 為 ASCII 碼表大小（固定大小 256 靜態陣列與動態 `vector`）。未配置任何多餘的動態大結構，空間配置極其精簡且固定。


## 邊界條件與潛在陷阱

1. **最後一組測資結尾無空行（Presentation Error 地雷）**：
   
   題目要求「每組輸出之間」有空行，這代表**最後一組輸出的末尾不能有額外的空行**。 <br>
   **正確策略**：不要在每組結尾無腦輸出雙換行，而是改用「從第二組開始，在開頭幫前一組補換行」的邏輯（即程式碼中的 `if(!firstline) cout << "\n";`），即可完美相容。

2. **ASCII 負數越界**：
   在 C++ 中，標準 `char` 有可能是 signed（範圍 -128 到 127）。若輸入中包含延伸 ASCII 碼（128-255），直接當作陣列索引會變成負數，進而引發 Segment Fault 導致 RE（Runtime Error）。**因此在當作索引時，必須強制造型為 `(unsigned char)c`**。

3. **完全空白行輸入**：
   若某一行輸入為完全空白（長度為 0），`getline` 仍會讀入。此時 `arr2` 為空，程式不會印出任何內容，但「空行控制旗標」依然會正確作動，符合測資規格。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

// 定義資料結構，同時保存字元的 ASCII 碼與出現次數
struct Data {
    int ascii;
    int count;
};

// 自訂比較函式：實現題目要求的特殊雙條件排序
bool cmp(Data a, Data b) {
    if (a.count != b.count) {
        return a.count < b.count;  // 條件一：次數少的排在前面 (升序)
    }
    return a.ascii > b.ascii;      // 條件二：次數相同時，ASCII 碼大的排在前面 (降序)
}

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    string s;
    bool firstline = true; // 用於精確控制測資組之間的空行
    
    // 逐行讀取直到檔案結束 (EOF)
    while (getline(cin, s)) {
        // 核心：從第二組測資開始，在輸出前幫前一組補一個空行，確保最後一組後面不會有多餘空行
        if (!firstline) {
            cout << "\n";
        }
        firstline = false;
        
        int arr1[256] = {0}; // 用於統計 256 種 ASCII 字元的頻率直方圖
        for (char c : s) {
            // 核心：必須強轉為 unsigned char，防止延伸 ASCII 碼變成負數索引導致 RE
            arr1[(unsigned char)c]++;
        }
        
        vector<Data> arr2;
        for (int i = 0; i < 256; i++) {
            if (arr1[i] != 0) {
                arr2.push_back({i, arr1[i]}); // 將出現過的字元及其頻率推入 vector
            }
        }
        
        // 依據特殊規則排序
        sort(arr2.begin(), arr2.end(), cmp);
        
        // 輸出統計結果
        for (auto n : arr2) {
            cout << n.ascii << " " << n.count << "\n"; // 輸出 ASCII 十進位值與次數
        }
    }
    return 0;
}
```


## 進階優化思考

原做法將過濾後的資料倒進 vector 再排序，架構清晰明瞭。但在 C++ 中，如果想追求更極簡的程式碼結構，可以利用內建容器的特性。

**使用 std::vector 配合自訂 Lambda 排序**

不需要為了打包 ascii 與 count 而刻意在外部宣告 struct Data。我們可以直接使用 C++ 內建的 std::pair<int, int>（其中 first 為 ASCII 碼，second 為次數），並在 std::sort 中直接嵌入 Lambda 運算式 來定義排序行為。

**優化重構程式碼片段：**
```cpp
vector<pair<int, int>> arr2; // pair<ascii, count>
for (int i = 0; i < 256; i++) {
    if (arr1[i] > 0) arr2.push_back({i, arr1[i]});
}

// 使用 Lambda 運算式進行多條件排序
sort(arr2.begin(), arr2.end(), [](const pair<int, int>& a, const pair<int, int>& b) {
    if (a.second != b.second) return a.second < b.second; // 次數小優先
    return a.first > b.first;                             // ASCII 大優先
});
```
