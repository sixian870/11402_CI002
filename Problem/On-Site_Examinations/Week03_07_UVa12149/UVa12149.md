# UVa 12149 - Feynman

## 題目簡述

著名物理學家理查·費曼（Richard Feynman）小時候曾注意到一個規律：在一個由 $N \times N$ 個小正方形組成的棋盤網格中，總共包含的多個大小不等（從 $1 \times 1$ 到 $N \times N$）的正方形總個數，可以用特定的數學方式計算出來。<br>
本題要求給定正方形棋盤的邊長 $N$，計算該棋盤內總共包含多少個正方形。

**Sample Input**：

  **2** $\rightarrow$ 第一組測資，邊長 $N = 2$。<br>
  **1** $\rightarrow$ 第二組測資，邊長 $N = 1$。<br>
  **8** $\rightarrow$ 第三組測資，邊長 $N = 8$。<br>
  **0** $\rightarrow$ 當讀取到邊長為 0 時，代表輸入結束。

**Sample Output**：

  **5** $\rightarrow$ $1 \times 1$ 的正方形有 4 個，$2 \times 2$ 的正方形有 1 個，總計 $4 + 1 = 5$。<br>
  **1** $\rightarrow$ $1 \times 1$ 的正方形有 1 個，總計 1。<br>
  **204** $\rightarrow$ $N = 8$ 時的正方形總數為 204。


## 解題思路與數學原理

### 核心觀念：正方形個數計數（平方和公式）
在一張 $N \times N$ 的格線棋盤中，我們去列舉不同邊長 $k$（ $1 \le k \le N$ ）的正方形數量：
* 邊長為 $1 \times 1$ 的正方形數量為 $N \times N = N^2$ 個。
* 邊長為 $2 \times 2$ 的正方形數量為 $(N-1) \times (N-1) = (N-1)^2$ 個。
* 邊長為 $3 \times 3$ 的正方形數量為 $(N-2) \times (N-2) = (N-2)^2$ 個。
* 依此類推，直到邊長為 $N \times N$ 的正方形，其數量為 $1 \times 1 = 1^2$ 個。

因此，整個棋盤內包含的正方形總個數即為從 1 到 $N$ 的**連續正整數平方和**：
$$\text{Total Squares} = \sum_{i=1}^{N} i^2 = 1^2 + 2^2 + 3^2 + \dots + N^2$$

### 演算法步驟
1. 透過 `while(cin >> n && n != 0)` 讀取測資邊長 $N$，當 $N = 0$ 時離開程式。
2. 宣告累加變數 `sum = 0`。
3. 利用 `for` 迴圈從 $1$ 迭代至 $N$，在每輪迴圈中將 `i * i`（當前尺寸的正方形個數）累加至 `sum` 中。
4. 輸出最終計算出的 `sum` 值，並換行。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(N)$
  每組測資都需要執行一個執行 $N$ 次的單層迴圈來累加平方和。題目給定 $N$ 的最大範圍不超過 $100$，此暴力模擬解法的迴圈次數極少，可以在極短時間內（常數級別）通過測試。
* **空間複雜度**： $\mathcal{O}(1)$
  僅配置固定數量的純量整數變數（`n`, `sum`, `i`）進行數值儲存與運算，不需要開闢額外的陣列或記憶體空間。


## 邊界條件與潛在陷阱

1. **終止條件的正確處理**：
   題目規定以單一一個 $0$ 來代表輸入結束。在撰寫迴圈判斷時必須確實檢測 `n != 0`，避免將 $0$ 誤判為有效測資送入迴圈計算，否則會輸出錯誤的 `0`。
2. **數值溢位評估（Overflow Check）**：
   本題 $N \le 100$，當 $N = 100$ 時，其平方和最大值為：
   $$\sum_{i=1}^{100} i^2 = \frac{100 \times 101 \times 201}{6} = 338350$$
   由於 $338,350$ 遠小於有號 32 位元整數（`int`）的最大上限（約 $2 \times 10^9$），因此在運算與儲存過程中，使用標準 `int` 型態是絕對安全的，不需要使用到 `long long`。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 提升標準 I/O 串流效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n;
    // 當讀取到的 n 不為 0 時，持續進行處理
    while (cin >> n && n != 0) {
        int sum = 0;
        // 依序累加 1^2 + 2^2 + ... + n^2
        for (int i = 1; i <= n; i++) {
            sum += (i * i);
        }
        cout << sum << "\n"; // 線上解題建議以 \n 代替 endl 以最大化 I/O 速度
    }
    return 0;
}
```


## 進階優化思考
在原做法中使用了 for 迴圈來進行逐項累加（ $\mathcal{O}(N)$ ）。但在數學上，連續正整數的平方和存在一個非常有名的閉式公式（Closed-form Formula）。

**數學級數公式優化（ $\mathcal{O}(1)$ 常數時間）**
根據級數求和公式可以得知：
$$\sum_{i=1}^{N} i^2 = \frac{N(N + 1)(2N + 1)}{6}$$
如果改採此公式進行優化便能直接代入 $N$ 值求得答案，完全不需要任何迴圈走訪。

**公式優化程式碼片段：**
```cpp
while (cin >> n && n != 0) {
    // 直接套用公式，將時間複雜度降為 O(1)
    int sum = n * (n + 1) * (2 * n + 1) / 6;
    cout << sum << "\n";
}
```
