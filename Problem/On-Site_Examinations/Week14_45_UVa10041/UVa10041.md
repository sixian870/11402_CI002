# UVa 10041 - Vito's family

## 題目簡述

Vito 想要找一間房子，使得他家到所有親戚家的距離總和為最小。<br>
給定 r 個親戚家的門牌號碼，兩家之間的距離定義為兩者門牌號碼的絕對差值。<br>
請計算出 Vito 的新家到所有親戚家的最小總距離。

**Sample Input**：

  **2** $\rightarrow$ 測資數量。<br>
  **2 2 4** $\rightarrow$ 第一個整數 r 代表親戚的總人數（0 < r < 500），接著有 r 個正整數，表各個門牌號碼（ 0 ~ 30000 ）。<br>
  **3 2 4 6**

**Sample Output**：

  **2** $\rightarrow$ 輸出 Vito 新家到所有親戚家的最小距離總和，每一筆測資的結果輸出佔獨立的一行。<br>
  **4**


## 解題思路與數學證明

### 核心觀念：中位數（Median）
在一維空間中，若要尋找一個點 $x$，使得它到其他所有已知點 $x_i$ 的**絕對距離之和 $\sum |x_i - x|$ 最小**，這個點 $x$ 必須是這些已知點的**中位數**。

* **直觀證明**：
  假設現在有兩個親戚分別在 $A$ 點與 $B$ 點。Vito 的新家如果蓋在 $A$ 和 $B$ 之間（包含邊界），他到兩家的總距離剛好就是 $B - A$（定值）。但如果新家蓋在 $[A, B]$ 區間外面，總距離一定會大於 $B - A$。
  以此類推，當親戚數量更多時，我們需要由外而內「兩兩成對」鎖定區間，最終新家必須落在**最內層的交集區間**，也就是中位數的位置。

### 演算法步驟
1. 讀入所有親戚的門牌號碼並存入陣列。
2. 將陣列從小到大進行排序。
3. 取出中間位置的數值作為中位數（新家位置）。
4. 遍歷陣列，計算各點與中位數差的絕對值並累加，即為答案。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(r \log r)$
  主要效能瓶頸在於對 $r$ 個門牌號碼進行排序（C++ `sort` 核心為 Hybrid Sort，最差與平均皆為 $\mathcal{O}(r \log r)$）。後續計算總距離的遍歷僅需 $\mathcal{O}(r)$。
* **空間複雜度**： $\mathcal{O}(r)$
  需要使用一個大小為 $r$ 的 `vector` 陣列來儲存所有親戚的門牌位置。


## 邊界條件與潛在陷阱 (Edge & Corner Cases)

1. **$r = 1$ 的情況**：當只有一個親戚時，中位數就是該親戚家，總距離為 0。此程式碼中 `arr[1/2] = arr[0]`，`abs(arr[0]-arr[0]) = 0`，符合預期。
2. **親戚人數 $r$ 為偶數**：此時中位數會是一個區間（例如 $r=4$ 時，第 2 個與第 3 個數之間皆可）。本程式碼採用 `n / 2`（無條件捨去）會取到區間的右端點，在整數點上同樣能達到最小總距離，結果正確。
3. **重複的門牌號碼**：若多個親戚住在同一門牌，排序與中位數邏輯依然適用，不影響正確性。


## 程式碼實作

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    // 加速 I/O
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int t;
    cin >> t;
    while(t--){
        int n;
        cin >> n;
        vector<int> arr(n);
        for(int i = 0; i < n; i++){
            cin >> arr[i];
        }
        
        // 排序以尋找中位數
        sort(arr.begin(), arr.end());
        int mid = arr[n / 2]; 
        
        int total = 0;
        for(int j = 0; j < n; j++){
            total += abs(arr[j] - mid);
        }
        cout << total << "\n"; // 線上解題建議使用 \n 代替 endl 以提升效能
    }
    return 0;
}
```


## 進階優化思考 (Optimization)

在原解法中，我們為了找中位數而將整個陣列做了完整排序（$\mathcal{O}(r \log r)$）。但事實上，我們只需要知道中間那個位置的數是誰，其餘兩邊的數字有沒有排好順序並不重要。

**C++ 內建優化工具：nth_element()**
我們可以使用 std::nth_element，它採用快速選擇（Quick Select）演算法，可以在 平均 $\mathcal{O}(r)$ 的時間複雜度內，將第 $n/2$ 小的元素放到正確的位置上。

**優化思路實作片段：**
```cpp
// 取代原本的 sort(arr.begin(), arr.end());
auto mid_ptr = arr.begin() + n / 2;
nth_element(arr.begin(), mid_ptr, arr.end());
int mid = *mid_ptr;
```

改用此方法後，整體的算法時間複雜度能成功從 $\mathcal{O}(r \log r)$ 降至 $\mathcal{O}(r)$。
