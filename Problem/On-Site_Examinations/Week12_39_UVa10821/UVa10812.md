# UVa 10812 - Beat the Spread!

## 題目簡述

在超級盃橄欖球賽的賭盤中，給定兩個隊伍最終得分的**「總和 $S$（Sum）」**與**「相差絕對值 $D$（Difference）」**。<br>
請利用這兩個條件，計算出這兩支隊伍的具體得分分別是多少（先輸出高分，再輸出低分）。<br>
若給定的總和與差值在現實中是不可能存在的（無法組成兩個非負整數），則輸出 `impossible`。

**Sample Input**：

  **2** $\rightarrow$ 測試資料組數 $T$。<br>
  **40 20** $\rightarrow$ 第一組：總和 $S = 40$、差值 $D = 20$。<br>
  **20 40** $\rightarrow$ 第二組：總和 $S = 20$、差值 $D = 40$。

**Sample Output**：

  **30 10** $\rightarrow$ 兩隊分數為 30 與 10，滿足 $30+10=40$ 且 $30-10=20$。<br>
  **impossible** $\rightarrow$ 總和小於差值，在現實中不可能成立。


## 解題思路與二元一次聯立方程式

### 核心觀念：代數消去法與非負整數約束
這道題目的本質是**基礎二元一次聯立方程式的求解與邊界條件判定**。

設兩隊的得分分別為 $X$（高分隊）與 $Y$（低分隊），根據題目定義可以列出以下方程式：
1. $X + Y = S$
2. $X - Y = D$

將兩式相加可消去 $Y$，得到高分隊的得分公式：
$$2X = S + D \implies X = \frac{S + D}{2}$$

將兩式相減可消去 $X$，得到低分隊的得分公式：
$$2Y = S - D \implies Y = \frac{S - D}{2}$$

### 無解（impossible）的兩大核心防禦判定
在運動比賽中，分數具有兩大物理限制：**分數不能為負數**，且**分數必須是整數**。
1. **非負數約束（ $S \ge D$ ）**：
   因為低分隊的分數 $Y = (S - D) / 2$，如果輸入的總和 $S$ 小於差值 $D$（如 Sample 2 的 `20 40`），相減會得到負數（$Y = -10$），這在現實比賽中是不可能成立的。
2. **整數约束（ $(S + D) \pmod 2 == 0$）**：
   因為分數必須是整數，所以 $S + D$（或 $S - D$）相加減後的結果**必須是偶數**，才能被 2 整除。如果相加是奇數（例如 $S = 5, D = 2$，相加為 $7$），算出來的分數會包含小數點（ $3.5$ 分），這同樣是不合法的。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(1)$
  每組測資僅需執行一次簡單的邏輯判斷（`if`）與基礎算術加減除法，不含任何迴圈或遞迴結構，因此時間複雜度為絕對常數時間。
* **空間複雜度**： $\mathcal{O}(1)$
  僅使用固定數量的基本整型變數（`t`, `s`, `d`, `x`, `y`），未配置任何動態資料結構或陣列，空間開銷為常數。


## 邊界條件與潛在陷阱

1. **總和與差值相等（低分為 0 的邊界）**：
   若輸入為 `20 20`，代入公式得到 $X = 20, Y = 0$。因為 0 是合法的非負整數，此時程式應正確輸出 `20 0`。原程式碼中的 `s < d` 判定能完美相容 $S = D$ 的合法邊界。
2. **兩隊平手（差值為 0 的邊界）**：
   若輸入為 `40 0`（總和 40，差值 0），代入公式得到 $X = 20, Y = 20$。這代表兩隊平手，此結果完全合法，程式會正確輸出 `20 20`。
3. **資料型態評估**：
   雖然題目未明確指出 $S$ 和 $D$ 的最大上限，但以常規橄欖球賽得分與標準 32 位元有號整數（`int`）的最大容量（高達 $2 \times 10^9$）相比，直接使用 `int` 儲存變數與計算是非常安全的，不需擔心發生整數溢位（Integer Overflow）。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int t;
    if (cin >> t) {
        while (t--) {
            int s, d;
            int x, y;
            cin >> s >> d;
            
            // 核心判定：
            // 1. s < d 確保相減後 y 不會變成負數。
            // 2. (s + d) % 2 != 0 確保相加後能被 2 整除，分數不會出現小數。
            if (s < d || (s + d) % 2 != 0) { 
                cout << "impossible\n";
            }
            else {
                // 利用消去法公式直接在 O(1) 時間內求解
                x = (s + d) / 2;
                y = (s - d) / 2;
                cout << x << " " << y << "\n";
            }
        }
    }
    return 0;
}
```


## 進階優化思考

**位元運算與邏輯精簡**

在主迴圈的條件判定中，原做法使用了算術取模運算 `(s + d) % 2 != 0` 來檢查奇偶性。在計算機底層中，可以利用位元與運算（Bitwise AND）來加速奇偶判定。

* **優化原理**：一個整數如果是奇數，其二進位的最低位元（LSB）必然為 1。因此，(s + d) & 1 就能直接判定其是否為奇數。

* **進一步推導**：在數學上，兩個整數相加（$S + D$）與相減（$S - D$）的奇偶性是完全同步的。同時，在二進位中， `s ^ d` （異或運算）的最低位元也與加減法具備相同的奇偶性特徵。

**優化程式碼片段：**
```cpp
// 利用位元與運算 (& 1) 替代算術除法取模，效能更高
if (s < d || ((s + d) & 1)) {
    cout << "impossible\n";
} else {
    // x = (s + d) >> 1; // 亦可利用右移 1 位元替代除以 2
    // y = (s - d) >> 1;
}
```
