# UVa 10908 - Largest Square

## 題目簡述

給定一個 $M \times N$ 的字元網格，並提供 $Q$ 個詢問。<br>
每個詢問會給定一個網格內的中心點座標 $(\text{row}, \text{col})$。<br>
**求出以該點為中心，且正方形範圍內所有字元都與中心點字元完全相同的最大正方形「邊長」是多少？**

**Sample Input**：

  **1** $\rightarrow$ 測資組數 $T$。<br>
  **7 10 4** $\rightarrow$ 第一組網格列數 $M$、行數 $N$、詢問數 $Q$。<br>
  **abbbaaaaaa** $\rightarrow$ 網格內容。<br>
  **abbbaaaaaa**<br>
  **abbbaaaaaa**<br>
  **aaaaaaaaaa**<br>
  **aaaaaaaaaa**<br>
  **aaccaaaaaa**<br>
  **aaccaaaaaa**<br>
  **1 2** $\rightarrow$ 詢問的中心點座標 $(\text{row}, \text{col})$。<br>
  **2 4**<br>
  **4 6**<br>
  **5 2**

**Sample Output**：

  **7 10 4** $\rightarrow$ 每一組 Case 開始前，必須原封不動印出該組的 $M, N, Q$。<br>
  **3** $\rightarrow$ 以 (1, 2) 為中心的最大同字元正方形邊長為 3（即整個 $3 \times 3$ 區間皆為 `'b'`）。<br>
  **1**<br>
  **5**<br>
  **1**


## 解題思路與考點分析

### 核心觀念：正方形中心點擴張與邊界檢查
這道題目的本質是**二維陣列的範圍幾何模擬**。
因為題目規定給定的 $(\text{row}, \text{col})$ 必須是正方形的「唯一中心點」，這意味著合法的正方形邊長必然是奇數（即 $1, 3, 5, 7, \dots$）。

在演算法設計上，可以採用**由內向外逐圈擴張（Radius Expansion）**的貪婪策略：
1. **初始狀態**：邊長 `ans = 1`。中心點自己本身一定與自己相同，因此半徑從 `r = 1`（邊長為 3）開始嘗試往外擴張。
2. **邊界防禦**：每次企圖往外擴張半徑 `r` 時，必須先計算出該正方形的上下左右四個邊界：
   * 上界：`row - r`、下界：`row + r`
   * 左界：`col - r`、右界：`col + r`
   一旦發現任何一側超出網格範圍（小於 0 或大於等於 $M, N$），就代表無法再建立更寬的方陣，應立刻停止擴張。
3. **字元比對與連鎖中斷**：在範圍合法的前提下，利用雙層迴圈掃描整個範圍。若全數符合，則 `ans += 2` 並嘗試擴張下一圈（`r++`）；一旦發現任何一個字元與中心點不同，必須立刻設定旗標並利用**雙重 `break` 機制**徹底跳出多重迴圈，終止當前詢問的搜尋。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(T \times Q \times R^3)$
  其中 $T$ 為測資組數，$Q$ 為詢問數，$R$ 為最大可擴張的半徑（$R \le \min(M, N) / 2$）。在最差情況下，每一圈擴張都要重新掃描整個 $3 \times 3, 5 \times 5, \dots$ 的矩陣，其格子總數呈三次方量級增加。然而，由於題目規範 $M, N \le 100$ 且 $Q \le 20$，最大運算量約為 $20 \times 50^3 \approx 2.5 \times 10^6$，在 1 秒時限內暴力列舉綽綽有餘。
* **空間複雜度**： $\mathcal{O}(M \times N)$
  使用 `vector<vector<char>> M` 動態配置一個 $M \times N$ 的二維動態陣列。當 $M, N = 100$ 時，記憶體消耗僅約 10 KB，空間配置效率極高。


## 邊界條件與潛在陷阱

1. **原樣輸出格式要求**：
   題目有一項非常嚴格的格式規定：在輸出每組 Case 的詢問答案之前，**必須先將該組測資的原始參數 $M, N, Q$ 完整印出**。若漏掉這個步驟，會直接被判 Wrong Answer (WA)。
2. **多重迴圈中斷盲點（Branch Break）**：
   在 C++ 中，內層迴圈的 `break` 只能跳脫出當前的內層 `for` 迴圈。如果外層迴圈沒有補上 `if (!same) break;` 的判斷，程式會繼續掃描下一列，這不僅會造成嚴重的時間浪費，甚至可能因為後續又踩到邊界或錯誤狀態而導致邏輯崩潰。
3. **最大半徑限制**：
   當中心點剛好位於網格邊緣時（例如 $(0, 0)$），只要半徑 `r = 1`，邊界檢查就會立刻觸發 `break`，正確輸出 `1`。原程式碼中的範圍判斷式能完美兼容各種邊緣座標。


## 程式碼實作

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    // 提升標準 I/O 串流效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int t;
    if (cin >> t) {
        while (t--) {
            int m, n, tt;
            cin >> m >> n >> tt;
            
            // 使用動態陣列讀取字元地圖
            vector<vector<char>> M(m, vector<char>(n));
            for (int i = 0; i < m; i++) {
                for (int j = 0; j < n; j++) {
                    cin >> M[i][j];
                }
            }
            
            // 核心規範：每一組測試資料開始前，必須原封不動印出該組的 m, n, tt
            cout << m << " " << n << " " << tt << "\n";
            
            // 開始處理 Q 個詢問
            while (tt--) {
                int row, col;
                cin >> row >> col;
                
                char target = M[row][col]; // 鎖定中心點目標字元
                int ans = 1;               // 初始自身必定符合，邊長為 1
                int r = 1;                 // 從半徑 r = 1 開始向外嘗試擴張
                bool same = true;
                
                while (same) {
                    // 邊界防禦：若往外擴張的四個邊界超出網格，則終止擴張
                    if (row - r < 0 || row + r >= m || col - r < 0 || col + r >= n) {
                        break;
                    }
                    
                    // 雙層迴圈完整掃描當前半徑的正方形區間
                    for (int i = row - r; i <= row + r; i++) {
                        for (int j = col - r; j <= col + r; j++) {
                            if (M[i][j] != target) {
                                same = false;
                                break; // 只能跳脫內層迴圈
                            }
                        }
                        if (!same) break; // 核心：偵測到相異字元，立即跳脫外層迴圈
                    }
                    
                    // 若當前這一整圈完全合格，則更新邊長並繼續下一圈
                    if (same) {
                        ans += 2;
                        r++;
                    }
                }	
                cout << ans << "\n";
            }
        }
    }
    return 0;
}
```


##　進階優化思考
原做法每次增加半徑時，都會將整個內部的正方形區域「重複重新掃描」，這在複雜度上包含了大量冗餘計算。

1. **剝皮式外圈掃描（Shell Scan 優化）**

   因為我們能進到半徑 r，代表內部的 (r-1) 區域先前已經驗證過完全合法。因此，當前這輪我們只需要檢查最外圍的那一圈「邊框字元」即可。
  
  * **優化範圍**：只檢查 i = row - r 和 row + r 的橫線，以及 j = col - r 和 col + r 的直線。
  * **效能改善**：單次半徑檢查的時間複雜度從 $\mathcal{O}(R^2)$ 降到 $\mathcal{O}(R)$，總體複雜度優化至 $\mathcal{O}(T \times Q \times R^2)$。

2. **二維前綴和 / 二維 DP（高階演算法變體）**

   如果這題的詢問數 $Q$ 放大到 $10^5$ 量級，暴力法會直接 Time Limit Exceeded。

   * **二維前綴和（2D Prefix Sum）**：可以用 $\mathcal{O}(M \times N)$ 預處理出每個字元的前綴計數。在查詢時，利用 $\mathcal{O}(1)$ 的矩陣區域求和，配合二分搜尋半徑，可在 $\mathcal{O}(\log(\min(M, N)))$ 內回應單次詢問。
   * **二維動態規劃（2D DP）**：可建立四個方向的連續相同字元 DP 陣列，直接在預處理階段算出每個點能向外延伸的最大長度，將單次查詢直接壓低到 $\mathcal{O}(1)$ 常數時間。
