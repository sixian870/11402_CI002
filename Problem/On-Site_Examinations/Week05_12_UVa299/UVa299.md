# UVa 299 - Train Swapping

## 題目簡述

有一個長度為 $N$ 的車廂序列（編號為 1 到 $N$），若只能透過**交換相鄰兩個車廂**的方式來將車廂依編號從小到大（1, 2, 3...）重新排列好。<br>
請問最少需要進行多少次相鄰車廂的交換，才能將所有車廂排列正確。

**Sample Input**：

  **3** $\rightarrow$ 測資組數 $t$。<br>
  **3** $\rightarrow$ 第一組車廂長度 $N$。<br>
  **1 3 2** $\rightarrow$ 車廂目前的排列順序。<br>
  **4** $\rightarrow$ 第二組車廂長度 $N$。<br>
  **4 3 2 1**<br>
  **2**<br>
  **2 1**

**Sample Output**：

  **Optimal train swapping takes 1 swaps.** $\rightarrow$ (3, 2) 交換 1 次即可完成排序。<br>
  **Optimal train swapping takes 6 swaps.** <br>
  **Optimal train swapping takes 1 swaps.**


## 解題思路與演算法證明

### 核心觀念：逆序數對（Inversions）與泡沫排序法
這道題目的本質是要求出一個數列中的 **「逆序數對（Inversion Pair）」總數**。
在一個數列中，若存在一組索引 $(i, j)$ 滿足 $i < j$ 且 $\text{arr}[i] > \text{arr}[j]$，則稱這兩者為一個逆序對。

* **為什麼對應泡沫排序法？**
  泡沫排序法（Bubble Sort）的核心機制正是「比較相鄰元素，若前大於後則進行交換」。每一次相鄰元素的交換，都會且僅會消除數列中的「一個」逆序數對。因此，當整個數列被完整排序完畢（逆序對歸零）時，所累積的交換總次數，必然等於原始數列中逆序數對的總數，這也就是題目所求的「最少交換次數」。

### 演算法步驟
1. 讀取測資組數 $t$，進入主迴圈。
2. 針對每組測資，讀入車廂長度 $N$ 並以 `vector<int> train` 儲存其原始排列。
3. 初始化交換計數器 `count = 0`。
4. 使用雙層巢狀迴圈執行泡沫排序：
   * 內層迴圈比較相鄰的車廂 `train[k]` 與 `train[k+1]`。
   * 若發現前面車廂編號大於後面（`train[k] > train[k+1]`），則呼叫 `swap` 將兩者位置對調，並同步執行 `count++`。
5. 排序完成後，按照題目要求的嚴格格式輸出 `Optimal train swapping takes X swaps.`。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(N^2)$
  泡沫排序法不論數列初始狀態如何，雙層 `for` 迴圈皆會完整走訪。外層迴圈執行 $N-1$ 次，內層迴圈執行 $N-1$ 次，其總比較次數固定為 $(N-1)^2$。題目給定車廂長度 $N \le 50$，最大運算量約為 $50 \times 50 = 2500$ 次，對 CPU 而言耗時在微秒（ $\mu s$ ）級別，可瞬時通過。
* **空間複雜度**： $\mathcal{O}(N)$
  需要動態配置一個大小為 $N$ 的 `vector` 陣列來儲存車廂編號。由於 $N \le 50$，記憶體消耗為微不足道的常數級，空間效率極高。


## 邊界條件與潛在陷阱

1. **完全逆序的最壞情況（Worst Case）**：
   當輸入數列為完全降序（例如 `4 3 2 1`）時，逆序對數量達到最大值：
   $$\frac{N \times (N - 1)}{2} = \frac{4 \times 3}{2} = 6$$
   此時程式會觸發最高頻率的交換。由於 $N \le 50$，最大可能交換次數為 $\frac{50 \times 49}{2} = 1225$ 次，完全不會超出 32 位元有號整數（`int`）的範圍，故使用 `int count` 儲存答案非常安全。
2. **完全升序的最優情況（Best Case）**：
   當輸入本身就是正確排列（例如 `1 2 3`）時，內層 `if` 條件從不成立，`count` 保持為 0，最後正確輸出 `0 swaps.`。
3. **字串拼寫細節（String Accuracy）**：
   輸出的文字部分為固定格式 `Optimal train swapping takes X swaps.`，拼寫包含結尾的句點都必須完全一致。特別注意，不論 $X$ 是 0、1 還是多數，字尾一律保持為複數型的 **`swaps.`**（這點與某些要求單複數切換的題目不同，此題皆為複數）。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 提升標準 I/O 串流效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int t;
    if (cin >> t) {
        while (t--) {
            int count = 0;
            int n;
            cin >> n;
            
            vector<int> train(n);
            for (int i = 0; i < n; i++) {
                cin >> train[i];
            }
            
            // 執行泡沫排序法以模擬相鄰車廂交換
            for (int j = 0; j < n - 1; j++) {
                for (int k = 0; k < n - 1; k++) {
                    // 若前一項大於後一項，代表構成逆序數對，執行交換
                    if (train[k] > train[k + 1]) {
                        swap(train[k], train[k + 1]);
                        count++; // 紀錄交換次數
                    }
                }
            }
            
            // 嚴格依據題目規範格式輸出結果
            cout << "Optimal train swapping takes " << count << " swaps.\n";
        }
    }
    return 0;
}
```


## 進階優化思考

雖然本題 $N \le 50$ 使得 $\mathcal{O}(N^2)$ 的泡沫排序法能輕鬆應付，但在演算法領域中，求逆序數對總數有一個跨入高階資工思維的經典優化手段。

**分治法優化：合併排序法（Merge Sort, $\mathcal{O}(N \log N)$）**

如果未來題目將車廂數量 $N$ 放大到 $10^5$ 級別， $\mathcal{O}(N^2)$ 的算法便會直接超時。此時可以藉由合併排序法（Merge Sort）的分治（Divide and Conquer）特性來進行優化。在合併階段，當左半邊陣列的元素 $L[i]$ 大於右半邊陣列的元素 $R[j]$ 時，因為左半邊陣列已經是升序排列，這意味著從 $L[i]$ 到 $L[\text{mid}]$ 的所有元素，都與 $R[j]$ 構成了逆序對。此時我們可以透過常數計算一次累加：  <br>
  **$$\text{count} += (\text{mid} - i + 1)$$** <br>
藉由這個手法，我們可以在完成排序的過程中，順便在 $\mathcal{O}(N \log N)$ 的時間複雜度內精確算出逆序對總數，這是處理大數據規模時的核心優化策略。
