# UVa 10341 - Solve It

## 題目簡述

給定一個非線性方程式：
$$p \cdot e^{-x} + q \cdot \sin(x) + r \cdot \cos(x) + s \cdot \tan(x) + t \cdot x^2 + u = 0$$
其中已知係數 $p, q, r, s, t, u$ 皆為整數，且滿足 $0 \le p, r \le 20$ 與 $-20 \le q, s, t, u \le 0$。<br>
在未知數 $x$ 限制於閉區間 $[0, 1]$ 的前提下，求出該方程式的實數解 $x$。若在該區間內無解，則輸出特定提示訊息。

**Sample Input**：

  **0 0 0 0 -2 1** $\rightarrow$ 第一組係數 $p, q, r, s, t, u$。<br>
  **1 0 0 0 -1 -1**

**Sample Output**：

  **0.7071** $\rightarrow$ 代入公式求得之 $x$ 值，精確至小數點後四位。<br>
  **No solution** $\rightarrow$ 若在 $[0, 1]$ 區間內無實數解，則輸出此字串。


## 解題思路與數值分析

### 核心觀念：單調函數與實數二分搜尋法（Binary Search）
這道題目的本質是**數值分析（Numerical Analysis）中的非線性方程式求根問題**。

1. **單調性評估（Monotonicity）**：
   觀察方程式中的各個組成項，在 $x \in [0, 1]$ 區間內：
   * $e^{-x}$ 為嚴格遞減。
   * $\sin(x)$ 為遞增，但其係數 $q \le 0$，故 $q \cdot \sin(x)$ 為遞減。
   * $\cos(x)$ 為遞減，且其係數 $r \ge 0$，故 $r \cdot \cos(x)$ 為遞減。
   * $\tan(x)$ 為遞增，但其係數 $s \le 0$，故 $s \cdot \tan(x)$ 為遞減。
   * $x^2$ 為遞增，但其係數 $t \le 0$，故 $t \cdot x^2$ 為遞減。
   綜合以上，將整個方程式視為一個函數 $f(x)$，它在 $[0, 1]$ 區間內是一個**嚴格遞減函數**。

2. **勘根定理與無解判定**：
   因為 $f(x)$ 嚴格遞減，若在 $[0, 1]$ 區間內有解，則必定滿足 $f(0) \ge 0$ 且 $f(1) \le 0$。如果 $f(0) < 0$ 或 $f(1) > 0$，代表函數圖形與 $x$ 軸在該區間內絕無交點，可直接宣告 `No solution`。

3. **二分搜尋逼近**：
   由於函數具備單調性，可以利用二分搜尋法進行逼近：
   * 設搜尋邊界 `low = 0.0`, `high = 1.0`。
   * 取中點 `mid = (low + high) / 2.0`。
   * 若 $f(\text{mid}) > 0$，代表當前的 `mid` 位於解的左側（因為函數遞減，數值大代表 $x$ 還不夠大），因此必須往右收縮邊界：`low = mid`。
   * 若 $f(\text{mid}) < 0$，代表當前的 `mid` 位於解的右側，必須往左收縮邊界：`high = mid`。
   * **收斂控制**：由於是浮點數二分搜尋，與其使用 `while (high - low > 1e-9)` 可能因浮點數精度微幅震盪而超時，**直接使用固定次數（如 100 次）的 `for` 迴圈進行收斂**是競賽中最為強健且精確的做法（$2^{-100}$ 的精度遠遠超出雙精度浮點數的極限）。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(K)$
  其中 $K$ 為二分搜尋的迭代次數。由於實作中直接將迴圈次數固定為 $100$ 次，單次迭代內僅執行常數次數學函式（`exp`, `sin`, `cos`, `tan`），因此每組測資的時間複雜度為絕對常數時間 $\mathcal{O}(1)$ ，效率極高。
* **空間複雜度**： $\mathcal{O}(1)$
  僅使用數個 `double` 型態的變數儲存方程式係數與邊界狀態，未佔用任何額外記憶體。


## 邊界條件與潛在陷阱

1. **無解條件的極端判斷**：
   原判斷式寫為 `if (f(0) < 0 || f(1) > 0)`。由於浮點數計算存在極其微小的誤差，若恰好在端點有解（例如 $f(1) = 0$），有微小機率會因為浮點數誤差導致 $f(1)$ 算出來變成 `1e-16`。雖然此題測資較寬容，但若要做到最嚴謹的防禦，應寫為 `if (f(0) < -1e-9 || f(1) > 1e-9)`。
2. **輸出格式精確度控制**：
   題目要求精確到小數點後四位。若直接輸出 `mid`，尾端的 0 會被截斷。**必須搭配 `<iomanip>` 中的 `fixed` 與 `setprecision(4)` 鎖定輸出流格式**，確保輸出如 `0.7071` 或 `0.0000`。
3. **二分搜尋變數賦值盲點**：
   在更新邊界時，要注意移向的是 $x$ 的座標軸值（即 `mid` 變數本身），而非函數值 $f(\text{mid})$。原程式碼中的註解與邏輯完全正確。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

// 宣告全域變數存儲方程式係數
double p, q, r, s, t, u;

// 定義目標非線性函數 f(x)
double f(double x) {
    return p * exp(-x) + q * sin(x) + r * cos(x) + s * tan(x) + t * x * x + u;
} 

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    // 連續讀入六個係數直到檔案結束 (EOF)
    while (cin >> p >> q >> r >> s >> t >> u) {
        
        // 邊界防禦與勘根定理判定：若區間端點同號，則在 [0, 1] 內必無解
        if (f(0) < 0.0 || f(1) > 0.0) {
            cout << "No solution\n";
            continue; // 跳過本組測資後續的二分逼近計算
        }
        
        double low = 0.0, high = 1.0, mid;
        
        // 核心技巧：利用固定 100 次的迴圈進行二分逼近，避開無限震盪風險並確保極高精度
        for (int i = 0; i < 100; i++) {
            mid = (low + high) / 2.0;
            
            // 由於函數嚴格遞減，f(mid) > 0 代表 mid 還不夠大，解在 mid 的右側
            if (f(mid) > 0.0) {
                low = mid; 
            }
            // f(mid) < 0 代表 mid 太大了，解在 mid 的左側
            else {
                high = mid;
            }
        }
        
        // 使用 fixed 與 setprecision(4) 強制輸出至小數點後第四位
        cout << fixed << setprecision(4) << mid << "\n";
    }
    return 0;
}
```


## 進階優化思考

除了經典的二分搜尋法之外，數值分析中還有其他更進階、收斂速度更快的求根演算法。

1. **Newton-Raphson Method**

   牛頓法是一種利用函數切線來逼近實數根的高級工具。其遞迴式為： $$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

   為了實現牛頓法，需要對原方程式進行求導，算出其導函數 $f'(x)$： $$f'(x) = -p \cdot e^{-x} + q \cdot \cos(x) - r \cdot \sin(x) + s \cdot \sec^2(x) + 2t \cdot x$$

   * **優點**：牛頓法具有平方收斂（Quadratic Convergence）的特性，通常只需要迭代 4 到 5 次即可達到與二分法 100 次相同的精度。

   * **缺點**：若初始點選擇不當，在某些震盪劇烈的函數中可能會發散。在本題嚴格單調遞減的良好性質下，牛頓法能非常安全且極速地收斂。
   
3. **割線法**

   若不想手動進行複雜的微積分求導，可以使用割線法。它利用兩點間的割線斜率來模擬牛頓法的導數，收斂速度（黃金比例收斂速度 $\approx 1.618$ ）同樣遠快於二分搜尋法的線性收斂，是另一種工程上常用的數值逼近手段。
