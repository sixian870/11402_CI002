# UVa 10020 - Minimal coverage

## 題目簡述

給定一個目標閉區間 $[0, M]$（其中 $M$ 為正整數），以及若干個給定的線段區間 $[L_i, R_i]$。<br>
請從這些給定的線段中，挑選出**數量最少**的線段組合，使得這些線段的聯集能夠**完全覆蓋**目標區間 $[0, M]$。

**輸入結束標記**：當讀取到線段座標為 `0 0` 時，代表該組測試資料的線段輸入結束。
**格式規範**：每一組測試資料的輸出之間，必須精確以一個 **空行（Blank line）** 隔開。

**Sample Input**：

  **1** $\rightarrow$ 測試資料組數 $T$。<br>
  <br> $\rightarrow$ **組數後通常包含空行。**
  **1** $\rightarrow$ 目標區間上限 $M = 1$，意即要覆蓋 $[0, 1]$。<br>
  **-1 0** $\rightarrow$ 給定的線段清單。<br>
  **-5 -3**<br>
  **2 5**<br>
  **0 1**<br>
  **0 0** $\rightarrow$ 線段輸入結束標記。

**Sample Output**：

  **1** $\rightarrow$ 最少需要 1 條線段。<br>
  **0 1** $\rightarrow$ 輸出被挑選的線段座標。若無解則輸出 0。


## 解題思路與貪婪策略

### 核心觀念：標準線段覆蓋與最大右界貪婪擴展（Greedy Algorithm）
這道題目的本質是**經典的一維區間覆蓋（Interval Covering）問題**，通常採用貪婪演算法配合前置排序來求解。

為了用最少的線段延伸到目的地 $M$，每次面臨選擇時，都必須在「能銜接上當前安全區」的前提下，挑選**右界延伸最遠**的線段：



1. **左界排序標準化**：
   首先，將所有讀入的線段依據**左界（`l`）進行升序排序**。這樣做能確保隨後用單向指針掃描時，線段是從左到右規律出現的。
2. **安全區邊界迭代（`current_L`）**：
   維護一個代表目前已被完全覆蓋的右端點臨界值 `current_L`（初始值為 0）。只要 `current_L < M`，代表尚未抵達終點，需要繼續找下一條線段。
3. **銜接性檢查與貪婪擴展**：
   在所有左界小於或等於 `current_L` 的線段中（即 `segments[i].l <= current_L`，確保新線段能與已覆蓋的安全區**連續銜接，絕不留下中斷空隙**），找出**右界最大（`max_R`）**的那一條線段。
4. **狀態滾動更新**：
   * 若找到了最優線段（`best_idx != -1`），將其加入結果陣列 `result`，並將安全區右界推到新高度：`current_L = max_R`。
   * 若在某一輪中，沒有任何線段的左界能跨過或對齊 `current_L`（即 `best_idx == -1`），代表戰線斷裂，中間出現了永遠無法被覆蓋的真空地帶。此時直接判定無解（`break`）。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(N \log N)$ <br>
  其中 $N$ 為給定線段的總數量。演算法的效能瓶頸在於前期的 `std::sort` 排序階段，耗時 $\mathcal{O}(N \log N)$。後續的貪婪雙層 `while` 迴圈中，雖然有內外兩層，但指標 `i` 在整個過程中只會單調遞增一次，屬於標準的線性雙指標掃描，耗時僅為 $\mathcal{O}(N)$。總體時間複雜度在平攤後穩居 $\mathcal{O}(N \log N)$，可在幾毫秒內極速通過。
* **空間複雜度**： $\mathcal{O}(N)$ <br>
  需要動態配置 `std::vector<Segment> segments` 陣列來緩衝讀入的原始線段，以及 `result` 陣列來儲存最優解，空間開銷與線段總數呈線性正比。


## 邊界條件與潛在陷阱

1. **多組測資間的空行控制**：<br>
   題目要求「每組測資的輸出結果之間」必須有一個空行。
   * **優化策略**：原程式碼中採用了 `bool first_case = true;`。在第一組 Case 輸出時不加換行，從第二組 Case 開始才在「最上方」補上 `cout << "\n";`。這項置頂翻轉設計非常高明，它能確保最後一組輸出的尾端不會殘留多餘空行，完美規避了格式錯誤。
2. **完全無效線段的即時過濾**：<br>
   原程式碼在讀入時加入了一行特判 `if (r <= 0) continue;`。因為我們要覆蓋的是自 0 開始的向右正向區間，任何右界小於或等於 0 的線段（完全位於 y 軸左側）對於覆蓋 $[0, M]$ 沒有任何物理貢獻，在讀入時提早將其過濾丟棄能有效減小排序規模。
3. **無解時的輸出規範**：<br>
   若線段完全斷開，或者即便全部用上仍無法抵達 $M$（即 `success == false`），題目規定**此時必須精確輸出一行 `0`**。原程式碼的分支判定完全符合此標準。


## 程式碼實作

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 定義線段結構體
struct Segment {
    int l;
    int r;
};

// 自定義比較自定義比較函式：優先依據線段左界（l）進行升序排序
bool cmp(const Segment& a, const Segment& b) {
    return a.l < b.l;
}

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);

    int t;
    if (cin >> t) {
        bool first_case = true; // 格式控制標記

        while (t--) {
            int m;
            cin >> m; // 讀取當前目標閉區間上限 M
            
            vector<Segment> segments;
            int l, r;
            // 持續讀入線段，直到讀到 0 0 為止
            while (cin >> l >> r && (l != 0 || r != 0)) {
                if (r <= 0) continue; // 提早剪枝：右界小於等於 0 的線段對覆蓋 [0, M] 無實質貢獻
                segments.push_back({ l, r });
            }
            
            // 貪婪前置：依左界由小到大排序
            sort(segments.begin(), segments.end(), cmp);

            int current_L = 0; // 目前已被完全覆蓋的安全區右端點邊界
            int i = 0;         // 線段掃描指標
            vector<Segment> result; // 儲存被挑選的最優線段組合
            bool success = false;
            
            // 核心貪婪調度迴圈
            while (current_L < m) {
                int max_R = current_L; // 追蹤符合銜接條件中的最大右界延伸點
                int best_idx = -1;     // 紀錄當前階段最優的線段索引
                
                // 雙指標橫向流式掃描：找出所有左界能與當前安全區無縫銜接的線段
                while (i < (int)segments.size() && segments[i].l <= current_L) {
                    if (segments[i].r > max_R) {
                        max_R = segments[i].r; // 動態更新能推到最遠的右界
                        best_idx = i;
                    }
                    i++; // 指標單調向右，不走回頭路
                }
                
                // 邊界防禦：若找不到任何能銜接的線段，代表戰線發生斷裂，宣告無解
                if (best_idx == -1) {
                    break;
                }
                
                // 將當前階段最優線段納入答案，並更新安全區右界天花板
                result.push_back(segments[best_idx]);
                current_L = max_R;
                
                // 成功抵達終點，提前解鎖跳出
                if (current_L >= m) {
                    success = true;
                    break;
                }
            }
            
            // 格式化輸出控制：自第二組測資開始，在標頭上方補空行，完美去尾
            if (!first_case) {
                cout << "\n";
            }
            first_case = false;
            
            // 依據判定結果輸出
            if (success) {
                cout << result.size() << "\n";
                for (const auto& seg : result) {
                    cout << seg.l << " " << seg.r << "\n";
                }
            }
            else {
                cout << "0\n"; // 無解時依規範印出 0
            }
        }
    }
    return 0;
}
```


## 進階優化思考
**線性時間計數分桶優化（Bucket Covering 策略）**

在目前的實作中，前置排序耗費了 $\mathcal{O}(N \log N)$ 的代價。如果在實際大規模應用或競賽中，目標區間上限 $M$ 的數值範圍非常小（例如 $M \le 5000$），我們可以完全抹除排序，採用更高級的分桶預處理（Bucket Normalization）：

* **原理**：因為我們只關心在某個起點左界上「能延伸最遠的右界是什麼」。

* **做法**：可以直接宣告一個大小為 $M + 1$ 的一維整數陣列 int max_right_at[5005] = {0};，下標代表線段的左界位置。在讀入線段時，不需要將其塞入 vector，而是直接原地執行最遠更新。

* **效能改善**：這樣做能把前期雜亂無章的線段直接標準化壓縮成一條長度為 $M$ 的最遠右界映射軌道。後續的貪婪推導只需在這條連續的陣列上單向走訪一次，整體時間複雜度能由 $\mathcal{O}(N \log N)$ 劇烈逼近到最極致的絕對線性 $\mathcal{O}(N + M)$。這種免除實體排序的查表技術，在面對海量碎裂區間覆蓋時，能展現出無可比擬的運算速度與內存優勢。

**優化程式碼實作片段：**
```cpp
if (l >= 0 && l <= m) {
    max_right_at[l] = max(max_right_at[l], r);
}
```
