# UVa 10008 - What's Cryptanalysis?

## 題目簡述

讀取數行文字，並計算其中每個英文字母出現的次數。<br>
統計時一律不分大小寫（統一視為大寫），且忽略所有非英文字母的字元（如數字、標點符號與空白）。<br>
最後的輸出必須依照字母出現的「次數」由大到小排序；若有字母出現的次數相同，則依據該字母的「ASCII 碼（字母順序）」由小到大排列輸出。

**Sample Input**：

  **3** $\rightarrow$ 測資行數。<br>
  **This is a test.** $\rightarrow$ 測資包含大小寫字母、數字、空格與標點符號。<br>
  **Count me 1 2 3 4 5.** <br>
  **Wow!!!! Is this question easy?**

**Sample Output**：

  **S 7**<br>
  **T 6**<br>
  **I 5**<br>
  **E 4**<br>
  **O 3**<br>
  **A 2**<br>
  **H 2**<br>
  **N 2**<br>
  **U 2**<br>
  **W 2**<br>
  **C 1**<br>
  **M 1**<br>
  **Q 1**<br>
  **Y 1**


## 解題思路與多條件排序

### 核心觀念：頻率統計與自訂結構體排序
這道題目的本質是**字串處理解析（Parsing）與多條件排序（Multi-criteria Sorting）**。
為了在統計完 26 個字母的出現頻率後，能同時依據「出現次數」與「字母 ASCII 碼」兩種維度進行精準排序，最佳的做法是使用自訂結構體（`struct`）來維護狀態：

1. **結構體設計**：建立一個包含 `char name`（字母名稱）與 `int count`（出現次數）的結構體。
2. **多條件排序邏輯**：
   * **主要條件**：次數高者優先（降序排列）。
   * **次要條件**：當次數完全相同時，字母 ASCII 碼小者優先（字母順序升序排列）。
   這在 C++ 中可以透過撰寫一個回傳 `bool` 的自訂比較函式（如 `compare`）並傳入 `std::sort` 來完美實現。

### 演算法步驟
1. 讀入整數 $N$ 代表後續要處理的文字行數。
2. **關鍵動作**：調用 `cin.ignore()` 清除緩衝區中的換行符，避免後續的第一個 `getline` 讀到空行。
3. 初始化一個大小為 26 的結構體陣列（或 `vector`），依序將 `name` 填入 `'A'` 到 `'Z'`，並將 `count` 初始化為 0。
4. 執行 $N$ 次迴圈，每次利用 `getline(cin, line)` 讀入整行字串。
5. 遍歷字串中的每個字元：
   * 使用 `isalpha(c)` 篩選出英文字母。
   * 使用 `toupper(c)` 將字母統一轉為大寫。
   * 利用基底偏移公式 `alpha[c - 'A'].count++` 在 $\mathcal{O}(1)$ 時間內完成計數。
6. 使用 `std::sort` 搭配自訂比較函式進行穩定排序。
7. 遍歷排序後的陣列，**只輸出 `count > 0` 的字母**及其對應次數。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(L + A \log A)$
  其中 $L$ 為所有輸入文字行的字元總長度，每一位字元都需要走訪並進行字元轉換，耗時 $\mathcal{O}(L)$。而 $A$ 為字母表大小（固定為 26）。對大小為 26 的陣列進行排序耗時為微不足道的常數時間 $26 \log 26 \approx 122$ 次。因此，整體的執行時間完全取決於文字輸入量，屬於最優的線性時間。
* **空間複雜度**： $\mathcal{O}(A + M)$
  其中 $A$ 為字母表的空間（固定大小 26 結構體陣列），$M$ 為單行文字的最大字串緩衝空間（`line`）。未配置任何多餘的動態資料結構，空間配置極其精簡。


## 邊界條件與潛在陷阱

1. **`cin` 與 `getline` 混用快取地雷**：
   這是初學字串處理最常踩到的 Wrong Answer 或 Runtime Error 地雷。當輸入第一行的數字 $N$ 後（例如輸入 `3` 再按 Enter），`cin >> n` 只會吃掉字元 `3`，而換行符 `\n` 仍會被殘留在輸入流緩衝區中。若此時不加 `cin.ignore()`，下一個 `getline` 就會直接讀取到這個殘留的 `\n` 並誤判為一個空行，導致最後少處理了真正的一行文字。
2. **從未出現過的字母隱藏**：
   字母表陣列初始大小為 26（包含 X, Y, Z 等）。題目要求只印出「出現過」的字母。如果某個字母在全文中出現次數為 0，在最後的輸出迴圈中必須透過 `if (alpha[j].count > 0)` 將其過濾，否則會把沒出現過的字母一併印出。
3. **字元過濾精確度**：
   輸入可能包含驚嘆號、問號、希臘字母、特殊標點或數字。必須嚴格使用 `<cctype>` 庫中的 `isalpha()` 進行字元驗證，確保只有 `A-Z` 與 `a-z` 的字元會被記錄。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

// 定義資料結構，同時保存字母與出現次數
struct Data {
    char name;
    int count;
};

// 自訂比較函式：實現雙條件排序
bool compare(Data a, Data b) {
    if (a.count != b.count) { 
        return a.count > b.count; // 條件一：次數多的排在前面 (降序)
    } else { 
        return a.name < b.name;   // 條件二：次數相同時，ASCII 碼小的排在前面 (升序)
    }
}

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n; 
    if (cin >> n) {
        cin.ignore(); // 核心：吃掉讀取整數後殘留在緩衝區的換行符
        
        // 初始化大小為 26 的字母統計陣列
        vector<Data> alpha(26); 
        for (int i = 0; i < 26; i++) {
            alpha[i].name = 'A' + i;
            alpha[i].count = 0;
        }
        
        string line;
        while (n--) { 
            getline(cin, line); // 逐行讀取包含空格的字串
            for (char c : line) {
                if (isalpha(c)) {       // 篩選英文字母
                    c = toupper(c);     // 統一轉大寫
                    alpha[c - 'A'].count++; // 利用 ASCII 相減找出陣列索引
                }
            }
        }
        
        // 依照題目特殊規則進行排序
        sort(alpha.begin(), alpha.end(), compare);
        
        // 輸出統計結果
        for (int j = 0; j < 26; j++) {
            if (alpha[j].count > 0) { // 邊界過濾：次數大於 0 才輸出
                cout << alpha[j].name << " " << alpha[j].count << "\n";
            }
        }
    }
    return 0;
}
```


## 進階優化思考

原解法定義了結構體與自訂 compare 函式，程式碼結構非常工整且具有高可讀性。但在時間極致優化與程式碼精簡的考量下，有另一種利用 C++ 內建 std::pair 的小技巧。

**利用 std::pair 預設排序特性**

在 C++ 中，std::pair 的預設 operator< 排序規則是：「先比第一個元素（first，升序）；若相同再比第二個元素（second，升序）」。<br>
如果將頻率記錄儲存為：pair<int, char> 形式，並在填入資料時，將次數乘以 -1（將降序需求轉為升序需求），就可以完全不用寫自訂 compare 函式，直接調用預設的 sort 就能得到正確結果。

**優化重構程式碼片段：**
```cpp
// first 存次數的相反數，second 存字元本身
vector<pair<int, char>> alpha(26);
for (int i = 0; i < 26; i++) {
    alpha[i] = {0, (char)('A' + i)};
}

// 統計時 (假設統計完後大寫 'E' 次數為 5)
alpha[c - 'A'].first--; // 變為 -5

// 排序時直接套用預設排序
sort(alpha.begin(), alpha.end()); 
// 排序時 -7 会排在 -5 前面 (達到次數降序)；次數相同時 'A' 会排在 'B' 前面 (達到字母升序)
```
