# UVa 10931 - Parity

## 題目簡述

給定一個正整數 $I$，將其轉換為二進位表示法。接著計算該二進位字串中所有數字 `1` 的總個數（此數值即為該數的 Parity 值）。<br>
最後按照指定格式輸出該數的二進位字串以及其 `1` 的總個數。

**Sample Input**：

  **1** $\rightarrow$ 第一組測資 $I = 1$。<br>
  **2** $\rightarrow$ 第二組測資 $I = 2$。<br>
  **10** $\rightarrow$ 第三組測資 $I = 10$。<br>
  **0** $\rightarrow$ 當讀取到 0 時，代表輸入結束。

**Sample Output**：

  **The parity of 1 is 1 (mod 2).** $\rightarrow$ 1 的二進位為 `1`，包含 1 個 `1`。<br>
  **The parity of 10 is 2 (mod 2).** $\rightarrow$ 2 的二進位為 `10`，包含 1 個 `1`。<br>
  **The parity of 1010 is 2 (mod 2).** $\rightarrow$ 10 的二進位為 `1010`，包含 2 個 `1`。


## 解題思路與進位轉換

### 核心觀念：十進位轉二進位（短除法模擬）
這道題目的本質是**進位制轉換與位元計數（Bit Counting）**。
要將十進位整數 $I$ 轉換為二進位，最直觀的做法是使用「除以 2 取餘數」的短除法：
1. **餘數紀錄**：將當前數字對 2 取餘數（`n % 2`）。若餘數為 1，代表該二進位位元為 `1`，此時將 Parity 計數器累加 1，並將字元 `'1'` 加入字串；若餘數為 0，則加入字元 `'0'`。
2. **數值更新**：將當前數字除以 2（`n /= 2`），收縮數值。
3. **字串反轉**：由於短除法是從最低位元（LSB）一路計算到最高位元（MSB），因此最後得到的字串順序是相反的。在輸出前必須將字串進行反轉（`reverse`），才能得到正確的二進位排列。

### 演算法步驟
1. 透過 `while(cin >> n && n != 0)` 讀取輸入，當輸入為 0 時終止程式。
2. 初始化計數器 `count = 0` 與空字串 `s = ""` 用於儲存二進位碼。
3. 執行內層 `while(n > 0)` 迴圈：
   * 若 `n % 2 == 1`，`count++` 且 `s += "1"`。
   * 若 `n % 2 == 0`，`s += "0"`。
   * `n /= 2`。
4. 使用 `reverse(s.begin(), s.end())` 反轉字串。
5. 嚴格依照題目規範的格式格式化輸出結果。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(\log_2 I)$
  十進位轉二進位的迴圈執行次數取決於該數值的二進位總位元數，即 $\lfloor\log_2 I\rfloor + 1$ 次。隨後的字串反轉操作同樣耗費線性時間 $\mathcal{O}(\log_2 I)$。題目規範 $I \le 2 \times 10^9$，其二進位最多不超過 31 位元，因此程式會在微秒級別內瞬間執行完畢。
* **空間複雜度**： $\mathcal{O}(\log_2 I)$
  需要一個字串 `s` 來動態儲存轉換後的二進位碼。由於位元數極短（最大不超過 32 個字元），空間消耗為微不足道的常數級。


## 邊界條件與潛在陷阱 (Edge & Corner Cases)

1. **字串前後多餘空格（Whitespace Trap）**：
   原程式碼中初始化字串時寫成了 `string s = " ";`（包含一個初始空格）。這會導致在反轉字串後，空格被移到了二進位碼的尾端，或是直接插入在中間（如 `1010 `），進而引發 Presentation Error (PE) 或 Wrong Answer (WA)。**字串初始化必須維持絕對的空字串 `string s = "";`**。
2. **輸出格式微調（Spacing Check）**：
   觀察題目要求的輸出格式：`The parity of 1010 is 2 (mod 2).`。注意到 `is` 的前後都有空格（`" is "`），而原程式碼寫成了 `"is "`，這會造成輸出的字串與數字黏在一起（例如 `1010is 2`），導致格式錯誤。
3. **資料範圍與型態**：
   題目指定 $I$ 最大可達 $2 \times 10^9$，這剛好在標準 32 位元有號整數（`int`）的最大上限（約 $2.14 \times 10^9$）之內。因此不論使用 `int` 或是原程式碼中的 `long long` 都是絕對安全的。


## 程式碼實作
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 提升標準 I/O 串流效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    long long n;
    // 當讀取到的 n 不為 0 時，持續進行處理
    while (cin >> n && n != 0) {
        long long count = 0; // 記錄二進位中 1 的總個數
        string s = "";       // 核心修正：必須初始化為完全空的字串，不可包含空格
        
        // 執行短除法轉換二進位
        while (n > 0) {
            if (n % 2 == 1) {
                count++;
                s += "1";
            }
            else if (n % 2 == 0) {
                s += "0";
            }
            n = n / 2;
        }
        
        // 反轉字串以符合從高位到低位的正常二進位順序
        reverse(s.begin(), s.end());
        
        // 核心修正：補齊 " is " 的前後空格，確保格式嚴格相符
        cout << "The parity of " << s << " is " << count << " (mod 2).\n";
    }
    return 0;
}
```


## 進階優化思考

追求極致的代碼精簡度與執行效能，可以利用位元運算以及標準庫內建的黑科技工具。

1. 利用位元運算優化短除法
   在底層中，n % 2 等價於與 1 進行位元與運算 n & 1；而 n / 2 則等價於向右位移 1 位元 n >> 1。位元運算直接由 CPU 的邏輯閘驅動，效能比算術除法更高。
   ```cpp
   while (n > 0) {
    s += (n & 1 ? "1" : "0");
    if (n & 1) count++;
    n >>= 1;
   }
   ```
2. 使用內建內建工具 `std::bitset` 或 `__builtin_popcount`
   C++ 提供了內建的位元集合容器 std::bitset，它可以直接將整數轉換成二進位字串。另外，GCC 編譯器內建了 __builtin_popcount(n) 函式，能在 $\mathcal{O}(1)$ 常數時間內透過硬體指令直接計算出二進位中 1 的總個數。

   **內建優化工具其實現片段：**
   ```cpp
   while (cin >> n && n != 0) {
    // 計算 1 的個數 (Parity)
    int count = __builtin_popcountll(n);
    
    // 直接將數字轉換為二進位字串
    string s = bitset<32>(n).to_string();
    
    // 除去 bitset 產生的領頭多餘 0 (Leading Zeros)
    s.erase(0, min(s.find_first_not_of('0'), s.size() - 1));
    
    cout << "The parity of " << s << " is " << count << " (mod 2).\n";
   }
   ```
