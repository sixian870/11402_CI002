# UVa 679 - Dropping Balls

## 題目簡述

有一棵深度為 $D$ 的滿二元樹（Full Binary Tree），所有葉子節點皆位於第 $D$ 層。這棵樹共有 $2^D - 1$ 個節點，並按照層序從上到下、從左到右依序編號為 $1, 2, 3, \dots, 2^D - 1$。<br>
每個非葉子節點上都設有一個「開關」，初始狀態下所有開關一律指向**左側（False）**。

當一顆小球從根節點（編號 1）放下一路下墜時，會遵循以下規律移動：
1. 檢查當前節點的開關方向。
2. 若開關指向**左側**，小球會滾向**左子節點**，隨後該節點的開關方向會立刻翻轉為**右側**。
3. 若開關指向**右側**，小球會滾向**右子節點**，隨後該節點的開關方向會立刻翻轉為**左側**。

給定樹的深度 $D$ 以及放下的球的總個數 $I$，請計算出第 $I$ 顆小球最後會落在第 $D$ 層的哪一個**葉子節點編號**？

當輸入的 $T = -1$ 時，代表整個輸入流結束。

**Sample Input**：

  **1** $\rightarrow$ 測試資料組數 $T$。<br>
  **4 2** $\rightarrow$ 樹的深度 $D = 4$，詢問第 $I = 2$ 顆球的落點。<br>
  **-1** $\rightarrow$ 輸入結束標記。

**Sample Output**：

  **10** $\rightarrow$ 在深度為 4 的樹中，第 2 顆球最終停駐在編號 10 的節點。


## 解題思路與二元樹幾何性質

### 核心觀念：開關翻轉週期性與路徑狀態模擬
這道題目的本質是**二元樹的節點索引幾何特徵與奇偶性狀態壓縮**。如果採用最直觀的「暴力法」，宣告一個大小為 $2^20$ 的布林陣列去模擬每一顆球落下的過程，在 $I \le 500,000$ 且深度 $D \le 20$ 的大測資下，會因為重複走訪大量節點而直接超時（TLE）。

透過觀察開關隨小球通過而輪替翻轉的特性，可以發現球的編號奇偶性直接決定了其在各層的分流方向，進而能將單次小球的軌跡優化為**常數層級的二分判定**：

1. **奇偶分流規律**：
   對於任意一個節點，因為所有開關初始朝左：
   * **第 1, 3, 5, $\dots$ 顆（奇數個）** 通過該節點的球，必定會被導向**左子節點**。
   * **第 2, 4, 6, $\dots$ 顆（偶數個）** 通過該節點的球，外加開關已被前一顆球翻轉朝右，必定會被導向**右子節點**。
2. **球數量的狀態遞迴縮減**：
   
   * 當第 $I$ 顆球通過當前節點時，若 $I$ 為**奇數**，代表它是走向左子樹的第 $\frac{I+1}{2}$ 顆球。
   * 當第 $I$ 顆球通過當前節點時，若 $I$ 為**偶數**，代表它是走向右子樹的第 $\frac{I}{2}$ 顆球。
3. **二元樹索引換算**：
   在標準層序編號的二元樹中，已知當前節點編號為 `root`：
   * 其左子節點編號為 `root * 2`。
   * 其右子節點編號為 `root * 2 + 1`。
   利用上述幾何索引性質，只要讓迴圈迭代 $D-1$ 次，就能在不需要任何空間結構的前提下，一字不漏地直接計算出第 $I$ 顆球的最終葉子終點。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(T \times D)$
  其中 $T$ 為總詢問組數， $D$ 為樹的深度。對於每組詢問，內層 `for` 迴圈固定只會執行 $D-1$ 次。在迴圈內部僅執行基本的奇偶數判斷與整數乘除法，耗時均為常數時間。當 $D \le 20$ 時，每組查詢僅需約 20 次運算，總體時間複雜度達到最優狀態。
* **空間複雜度**： $\mathcal{O}(1)$
  完全擺脫了對實體二元樹或布林陣列的動態記憶體開銷。僅使用少數幾個整型純量變數（`t`, `i`, `d`, `root`）在暫存器中進行代數滾動更新，空間開銷為完美的固定常數。


## 邊界條件與潛在陷阱

1. **多重結束符號的讀取判定**：
   本題的輸入格式包含兩層結構：最外層是 `while(cin >> t && t != -1)`。當外層讀到 `-1` 時徹底煞車；內層則依據 `t` 的組數跑 `while(t--)` 迴圈讀取實體測資。原程式碼的雙層結構設計完全符合此規格。
2. **葉子節點的層數界定（迴圈次數控制）**：
   小球從第 1 層（根節點）出發，要墜落到第 $D$ 層，在幾何路徑上只需要向下跨越 **$D-1$ 條邊**。因此，內層路徑推導的 `for` 迴圈條件必須嚴格寫成 `for(int j = 1; j < d; j++)`。如果誤寫成 `j <= d`，會導致小球多往下走了一層，進而算出越界錯誤的編號。
3. **球數與索引的一致性變更**：
   在原程式碼內部：
   
   * 當球數 `i` 是奇數（`i % 2 == 1`）時，球往左滾（`root *= 2`），且在左子樹中，這顆球的相對排位變成了第 `(i + 1) / 2` 顆球。
   * 當球數 `i` 是偶數（`i % 2 == 0`）時，球往右滾（`root = 2 * root + 1`），且在右子樹中，這顆球的相對排位變成了第 `i / 2` 顆球。
   此滾動收縮邏輯在邊界數值上無懈可擊。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int t;
    // 外層控制：持續讀取測試組數 t，當讀入 -1 時代表測資流結束
    while (cin >> t && t != -1) {
        
        // 內層控制：依序處理當前區塊的 t 組詢問
        while (t--) {
            int i, d;
            cin >> d >> i; // 依序讀入深度 d 與球的編號 i
            
            int root = 1; // 小球一律從根節點（編號 1）出發
            
            // 幾何核心：從第 1 層下降到第 d 層，只需要向下跨越 d-1 次
            for (int j = 1; j < d; j++) {
                // 狀態一：當前球數為奇數，依規則此球必被導向「左子樹」
                if (i % 2 == 1) {
                    root *= 2;        // 左子節點編號為父節點的 2 倍
                    i = (i + 1) / 2;  // 更新其在左子樹中的相對球序
                }
                // 狀態二：當前球數為偶數，依規則此球必被導向「右子樹」
                else if (i % 2 == 0) {
                    root = (2 * root) + 1; // 右子節點編號為父節點的 2 倍再加 1
                    i /= 2;                // 更新其在右子樹中的相對球序
                }
            }
            // 輸出第 I 顆球最終停駐的葉子節點編號
            cout << root << "\n";
        }
    }
    return 0;
}
```


## 進階優化思考

原做法利用整數的算術乘除法（ `* 2` , `/ 2 `）與取餘數（ `% 2 `）在結構上已經非常優雅。但在計算機底層架構中，由於二元樹與二進位具有天然的同構性，可以引入位元運算將執行效能推向物理極限。

**算術指令的位元級別替代**

* **原理**：在二進位中，向左位移 1 位（ `>> 1 `）等價於除以 2，而向左位移 1 位（ `<< 1` ）則等價於乘以 2。另外，判斷奇偶性可以直接使用位元與運算 `i & 1` 。

* **效能改善**：位元操作直接在 CPU 的算術邏輯單元（ALU）中透過單個時脈週期的硬體邏輯閘驅動，完全規避了算術除法器較高昂的指令週期成本。這種低階優化思維在處理海量二元樹幾何結構或即時系統開發時，能帶來最純粹與極致的常數效能調優。

**優化程式碼片段：**
```cpp
for (int j = 1; j < d; j++) {
    if (i & 1) { // 等價於 i % 2 == 1
        root <<= 1; // 等價於 root *= 2
        i = (i + 1) >> 1; // 等價於 i = (i + 1) / 2
    } else {
        root = (root << 1) | 1; // 等價於 root = 2 * root + 1
        i >>= 1; // 等價於 i /= 2
    }
}
```
