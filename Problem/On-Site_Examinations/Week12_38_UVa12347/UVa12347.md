# UVa 12347 - Binary Search Tree

## 題目簡述

給定一棵二元搜尋樹（Binary Search Tree, BST）經由 **前序走訪（Pre-order Traversal）** 所得到的整數序列。<br>
請利用該二元搜尋樹的幾何性質，反推出這棵樹，並輸出其 **後序走訪（Post-order Traversal）** 的序列結果。

二元搜尋樹（BST）滿足以下特性：
1. 左子樹的所有節點值皆「小於」根節點值。
2. 右子樹的所有節點值皆「大於」根節點值。
3. 左右子樹也各自是一棵二元搜尋樹。

**Sample Input**：

  **50** $\rightarrow$ 前序走訪序列：[根] [左子樹] [右子樹]。<br>
  **30**<br>
  **24**<br>
  **5**<br>
  **28**<br>
  **45**<br>
  **98**<br>
  **52**<br>
  **60**

**Sample Output**：

  **5** $\rightarrow$ 對應後序走訪序列：[左子樹] [右子樹] [根]。<br>
  **28**<br>
  **24**<br>
  **45**<br>
  **30**<br>
  **60**<br>
  **52**<br>
  **98**<br>
  **50**


## 解題思路與二元搜尋樹性質

### 核心觀念：利用前序序列分治重建 BST（Divide and Conquer）
這道題目的本質是**二元樹的走訪轉換與分治法應用**。
在前序走訪中，序列的排列順序必定為：`[根節點] [左子樹] [右子樹]`。
配合二元搜尋樹（BST）「左小右大」的天然數值約束，可以發現：
1. 區間的第一個元素 `pre[l]` 必然是當前子樹的**根節點（`root`）**。
2. 緊隨其後的元素中，所有**小於 `root`** 的連續片段，必然屬於該根節點的**左子樹**。
3. 第一個**大於 `root`** 的元素開始，直到區間末尾，必然全數屬於該根節點的**右子樹**。

因此，可以利用**分治法（Divide and Conquer）**，藉由單個指標 `split` 線性掃描找出左右子樹的邊界切分點，隨後遞迴建立子樹。由於題目要求輸出後序走訪（順序為 `[左] [右] [根]`），只需在遞迴完左子樹與右子樹後，再印出當前的 `root` 即可。

### 演算法步驟
定義分治函式 `solve(l, r)` 代表處理前序陣列中索引從 `l` 到 `r` 的子樹區間：
1. **終止條件**：若 `l > r`，代表當前區間為空（空子樹），直接 `return`。
2. **鎖定根節點**：`int root = pre[l]`。
3. **尋找切分點**：初始化 `split = l + 1`。利用 `while` 迴圈檢查，只要 `split <= r` 且 `pre[split] < root`，就讓 `split++`。
4. **遞迴切分**：
   
   * 左子樹區間為：`[l + 1, split - 1]` $\rightarrow$ 呼叫 `solve(l + 1, split - 1)`。
   * 右子樹區間為：`[split, r]` $\rightarrow$ 呼叫 `solve(split, r)`。
5. **後序輸出**：當左右兩側子樹皆遞迴處理完畢後，印出當前的 `root`。


## 複雜度分析

* **時間複雜度**：
  
  * **平均/最好情況**： $\mathcal{O}(N \log N)$
    若二元搜尋樹結構相對平衡，每次切分點 `split` 大約會落在正中央。此時遞迴樹的深度為 $\log N$，每層分治區間的線性掃描總開銷為 $\mathcal{O}(N)$，總時間複雜度為 $\mathcal{O}(N \log N)$。
  * **最壞情況**： $\mathcal{O}(N^2)$
    若輸入的樹嚴重傾斜（例如輸入序列已完全升序排列 `5 24 28 30 ...`，退化成一條鏈），每次切分右子樹都會包含剩下的所有元素。此時遞迴深度退化至 $N$，總時間複雜度變為 $\mathcal{O}(N^2)$。由於題目規範節點總數 $N \le 10,000$，即使在最壞情況下，總運算量約為 $10^8$ 次，在 C++ 優化下仍可於時限內通過。
* **空間複雜度**： $\mathcal{O}(N)$
  主要包含大小為 $N$ 的全域 `vector` 儲存空間，以及遞迴呼叫時系統佔用的堆疊空間（Stack Space）。在最壞退化成鏈的情況下，遞迴深度為 $N$，空間開銷為線性 $\mathcal{O}(N)$。


## 邊界條件與潛在陷阱

1. **沒有明確給定節點總數**：
   題目並未事先告知共有幾個整數。必須使用 `while (cin >> n)` 連續讀取直到輸入流結束（EOF）。原程式碼中使用 `pre.push_back(n)` 動態收集數據，完全符合此不確定邊界。
2. **完全無左子樹或完全無右子樹**：
   * 若所有後續元素都大於 `root`，`split` 保持為 `l + 1`。此時左子樹呼叫 `solve(l + 1, l)` 會因 `l + 1 > l` 觸發終止條件直接返回；右子樹則正確接管 `[l + 1, r]` 的全部區間。
   * 若所有後續元素都小於 `root`，`split` 會一路遞增到 `r + 1`。此時左子樹承接 `[l + 1, r]`；右子樹呼叫 `solve(r + 1, r)` 立即返回。
   分治指標控制能完美相容所有傾斜樹的邊界形態。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

// 全域陣列，用來儲存前序走訪讀入的所有節點值
vector<int> pre;

// 核心分治函式：將 pre[l...r] 區間解析並以後序走訪形式輸出
void solve(int l, int r) {
    // 邊界防禦：當左邊界大於右邊界，代表當前子樹為空，結束遞迴
    if (l > r) return;
    
    int root = pre[l];      // 前序走訪的第一個元素必然是該子樹的根節點
    int split = l + 1;      // 初始化右子樹的切分起點
    
    // 根據 BST 性質：尋找第一個大於或等於 root 的元素，作為右子樹的開頭
    while (split <= r && pre[split] < root) {
        split++;
    }
    
    // 依據後序走訪順序：[左子樹] -> [右子樹] -> [根節點]
    solve(l + 1, split - 1); // 遞迴處理左子樹區間 (皆小於 root)
    solve(split, r);         // 遞迴處理右子樹區間 (皆大於 root)
    
    // 左右子樹皆處理完畢，最後輸出當前根節點
    cout << root << "\n";
}

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n;
    // 持續讀入整數直到檔案結束 (EOF)
    while (cin >> n) {
        pre.push_back(n);
    }
    
    // 確保輸入不為空的前提下，啟動全域分治重建
    if (!pre.empty()) {
        solve(0, pre.size() - 1);
    }
    
    return 0;
}
```


## 進階優化思考

雖然分治解法非常直觀，但在面對最壞情況下 $\mathcal{O}(N^2)$ 的複雜度，在資工的高階演算法設計中，存在另外兩種能將時間複雜度優化至絕對線性 $\mathcal{O}(N)$ 的經典打法。

**方法一：利用單調堆疊（Monotonic Stack, $\mathcal{O}(N)$ ）**

* **原理**：前序走訪在 BST 中有一個特性：只要數值在遞減，代表我們一直在往左子樹深入。一旦出現一個比先前節點大的數，代表我們開始向某個節點的右子樹轉折。

* **做法**：可以使用一個單調堆疊來維護祖先節點。每當遇到新元素，若小於堆疊頂端則直接作為左子節點並入堆疊；若大於堆疊頂端，則不斷彈出堆疊直到找出它是哪一個祖先的右子節點。在建立實體樹後，再跑一次標準後序走訪。此方法可將重建樹的時間強制壓低至 $\mathcal{O}(N)$。

**方法二：上界約束遞迴法（Upper Bound Range, $\mathcal{O}(N)$ ）**

* **原理**：不需要手動用 `while` 去找 `split` 。我們可以在遞迴時，傳入一個該子樹被允許的「最大數值上限 `max_val` 」。

* **做法**：維護一個全域的掃描指標 `idx` 。在 `solve(max_val)` 中，如果 `pre[idx]` 大於 `max_val` ，代表它不屬於當前子樹，直接返回。否則，該點即為 `root` ，隨後遞迴呼叫左子樹 `solve(root)` 與右子樹 `solve(max_val)` 。

* **效能改善**：此重構手法完全消除了內層尋找邊界的 `while` 迴圈。全域指標 `idx` 從 0 到 $N-1$ 嚴格遞增一次，使整體時間複雜度在任何樹形態下（包含極端傾斜樹）都穩居完美的 $\mathcal{O}(N)$ ，是應對大規模數據時最頂級的優化方案。

**優化程式碼片段**
```cpp
void bit_solve(int max_val) {
    if (idx >= pre.size() || pre[idx] > max_val) return;
    
    int root = pre[idx++];
    bit_solve(root);    // 左子樹的所有值都必須小於 root
    bit_solve(max_val); // 右子樹的所有值都必須小於當前子樹的上限上限 max_val
    cout << root << "\n"; // 後序輸出
}
// 主程式調用：bit_solve(INT_MAX);
```
