# UVa 10035 - Primary Arithmetic

## 題目簡述

模擬小學數學的直式加法過程，計算兩個整數相加時總共會產生多少次「進位（Carry）」操作。<br>
輸入會給定兩個不超過 10 位數的正整數，請逐位數相加並統計進位發生的總次數。

**Sample Input**：

  **123 456** $\rightarrow$ 每一行包含兩個待相加的正整數。<br>
  **555 555** <br>
  **123 594** <br>
  **0 0** $\rightarrow$ 當讀取到兩個 0 時代表輸入結束。

**Sample Output**：

  **No carry operation.** $\rightarrow$ 如果進位次數為 0，輸出特定字串。<br>
  **3 carry operations.** $\rightarrow$ 如果進位次數大於 1，operation 後面必須加上複數字尾 s。<br>
  **1 carry operation.** $\rightarrow$ 如果進位次數剛好為 1，維持單數不加 s。


## 解題思路與直式模擬

### 核心觀念：直式加法與進位傳遞（Carry Property）
這題的本質是**基礎數位模擬（Simulation）**。我們從個位數（最低位）開始，逐位將兩個數字對齊相加，每一次相加時，除了算入兩個數字當前的位數外，還必須加上**前一位數傳過來的進位值**。

### 演算法步驟
1. 使用 `while(cin >> a >> b && (a != 0 || b != 0))` 讀取測資，直到兩者皆為 0 時終止。
2. 初始化進位旗標 `c = 0` 與進位總計數 `count = 0`。
3. 當 `a` 或 `b` 還有剩餘位數時，進入迴圈：
   * 用 `% 10` 取出 `a` 和 `b` 的當前最低位數。
   * 將兩者與前一次的進位 `c` 相加： $\text{sum} = \text{digitA} + \text{digitB} + c$ 。
   * 若 $\text{sum} \ge 10$，代表發生進位，此時 `count` 累加 1，並將下一次的進位值 `c` 設為 1；反之則將 `c` 清設為 0。
   * 將 `a` 和 `b` 分別 `/ 10` 以處理更高的一位。
4. 根據 `count` 的數值，嚴格依照題目要求的**單複數格式**輸出結果。


## 複雜度分析

* **Time Complexity（時間複雜度）**： $\mathcal{O}(\log_{10}(\max(a, b)))$
  因為每次迴圈都會將數字除以 10，迴圈執行的次數取決於兩個輸入數字中位數較長的那一個。題目限定數字小於 10 位數，因此 `while` 迴圈最多只會執行約 10 次，時間複雜度為極低的常數時間 $\mathcal{O}(1)$。
* **Space Complexity（空間複雜度）**： $\mathcal{O}(1)$
  僅配置固定數量的整型變數（`a`, `b`, `count`, `c` 等）來紀錄數值與狀態，無使用陣列或動態記憶體，空間複雜度為固定常數。


## 邊界條件與潛在陷阱 (Edge & Corner Cases)

1. **連續進位陷阱（Chain Carries）**：
   例如 `999 + 1`，個位數 `9+1` 進位後變為 `10`，這個進位會像骨牌一樣一路往更高位傳遞（`9+0+1=10` ...），導致後續雖然其中一方數字已無位數（變為 0），但仍會因為進位 `c = 1` 而繼續觸發新的進位。原本程式碼中的 `while(a != 0 || b != 0)` 條件可以完美處理此狀況。
2. **輸出格式的文字陷阱（Grammar Check）**：
   這是本題最常出錯（Wrong Answer）的地方：
   * 0 次進位：`No carry operation.`（注意 `No` 的開頭大寫與結尾句點）。
   * 1 次進位：`1 carry operation.`（單數，`operation` 沒有 s）。
   * 2 次以上：`X carry operations.`（複數，`operations` 必須加 s）。
3. **資料型態選擇**：
   題目說明數字小於 10 位數（即最大可能接近 $10^9$），標準 C++ 32 位元有號整數（`int`）的最大值約為 $2 \times 10^9$，因此使用 `int` 儲存 `a` 和 `b` 是安全的，不需用到 `long long`。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 優化標準輸入輸出串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int a, b;
    // 當 a 與 b 皆為 0 時停止讀取
    while (cin >> a >> b && (a != 0 || b != 0)) {
        int count = 0; // 記錄總進位次數
        int c = 0;     // 記錄當前的進位狀態 (0 或 1)
        
        while (a != 0 || b != 0) {
            int digit_a = a % 10;
            int digit_b = b % 10;
            
            a /= 10;
            b /= 10;
            
            // 當前兩位數加上前一位的進位值
            if ((digit_a + digit_b + c) >= 10) {
                count++;
                c = 1; // 產生進位，傳給下一輪
            } else {
                c = 0; // 未產生進位
            }
        }
        
        // 嚴格比對單複數輸出格式
        if (count == 0) {
            cout << "No carry operation.\n";
        } else if (count == 1) {
            cout << "1 carry operation.\n";
        } else {
            cout << count << " carry operations.\n";
        }
    }
    return 0;
}
```


## 進階優化思考

在暴力法中，許多數字的後半段路徑是重複計算的。例如，數字 3 的路徑是 3 -> 10 -> 5 -> 16 -> 8 -> 4 -> 2 -> 1。當我們之後計算到數字 6 時（6 -> 3 -> ...），一旦走到 3，我們其實可以直接借用先前查到的結果，不需重複模擬。

**重疊子問題優化：記憶化搜尋（Memoization / DP）**
我們可以使用一個全域陣列（或 unordered_map）來當作快取（Cache），記錄已經計算過的數字及其循環長度。

**優化思路實作片段：**

```cpp
// 建立一個足夠大的陣列記錄已知的長度
int memo[1000000] = {0};

int get_cycle_length(long long n) {
    if (n == 1) return 1;
    if (n < 1000000 && memo[n] != 0) return memo[n];
    
    int length;
    if (n % 2 == 0) length = 1 + get_cycle_length(n / 2);
    else length = 1 + get_cycle_length(3 * n + 1);
    
    if (n < 1000000) memo[n] = length;
    return length;
}
```
透過這種空間換時間的動態規劃手法，可以將多次重複查詢的平攤時間複雜度逼近 $\mathcal{O}(1)$。
