# UVa 108 - Maximum Sum

## 題目簡述

給定一個 $N \times N$ 的整數矩陣（矩陣中的數字可能為正、可能為負，亦可能為零）。<br>
請在該二維矩陣中，找到一個**連續的子矩陣（Submatrix）**，使得該子矩陣內所有元素的**加總和為最大**。並輸出此最大子矩陣的總和值。

**Sample Input**：

  **4** $\rightarrow$ 矩陣的大小 $N = 4$。<br>
  **0 -2 -7 0** $\rightarrow$ 矩陣內容（共 $4 \times 4 = 16$ 個整數）。<br>
  **9 2 -6 2**<br>
  **-4 1 -4  1**<br>
  **-1 8  0 -2**

**Sample Output**：

  **15** $\rightarrow$ 最大子矩陣位於左下角區塊：包含 `9 2`、`-4 1`、`-1 8`，其加總和為 $9+2-4+1-1+8 = 15$。


## 解題思路與動態規劃

### 核心觀念：一維前綴和降維與 Kadane 演算法
這道題目的本質是**二維的最大子陣列問題（Maximum Subarray Problem）**。如果直接以暴力法枚舉子矩陣的左上角與右下角座標，時間複雜度會退化到 $\mathcal{O}(N^6)$，顯然會 Time Limit Exceeded (TLE)。

為了將二維問題高效解決，可以採用 **「縱向壓縮降維 + 一維最大連續子序列和（Kadane's Algorithm）」** 的經典動態規劃策略：

1. **縱向行前綴和（Column Prefix Sum）**：
   我們在讀入數據時，預處理出一個二維陣列 `col_prefix[i][j]`，代表第 `j` 行從第 1 列累加到第 `i` 列的縱向總和。有了這個前綴和，任何從第 `top` 列到第 `bottom` 列的指定行區間，其整條縱向線段的和，都可以在 $\mathcal{O}(1)$ 時間內透過相減求得：
   $$\text{colSum} = \text{colPrefix}[\text{bottom}][\text{col}] - \text{colPrefix}[\text{top}-1][\text{col}]$$
2. **二維問題降一維**：
   我們透過雙層迴圈枚舉子矩陣的**上邊界 `top`** 與**下邊界 `bottom`**。一旦上下邊界固定，我們就可以把這幾列資料「縱向壓縮成一列的一維陣列」。此時，尋找最大子矩陣的問題，就完美轉化為「尋找這一列壓縮陣列的最大連續片段和」。
3. **Kadane 演算法滾動檢查**：
   利用滾動變數 `sum` 由左至右（`col` 從 1 到 $N$）掃描壓縮後的行總和：
   * `sum += col_sum`
   * 若動態累加後的 `sum` 超過歷史紀錄 `max_sum`，則即時覆蓋更新。
   * **貪婪捨棄機制**：一旦當前的累加和 `sum < 0`，代表這個片段對後續的累積只會帶來負效益，因此立刻將其「斷尾求生」，清零重來（`sum = 0`）。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(N^3)$
  最外層與次外層雙迴圈用來枚舉 `top`（從 1 到 $N$）與 `bottom`（從 `top` 到 $N$），共執行 $\frac{N(N+1)}{2}$ 次。最內層迴圈則耗費 $\mathcal{O}(N)$ 的時間橫向走訪所有欄位並套用 Kadane 演算法。因此，整體的時間複雜度優化到了極佳的 $\mathcal{O}(N^3)$，在 $N = 100$ 的規模下，總運算次數僅約 $500,000$ 次，可在數毫秒內極速通關。
* **空間複雜度**： $\mathcal{O}(N^2)$
  需要動態配置一個大小為 $(N+1) \times (N+1)$ 的二維動態陣列 `col_prefix` 來儲存縱向行前綴和。當 $N = 100$ 時，記憶體開銷約為 40 KB，空間配置效率極高。


## 邊界條件與潛在陷阱

1. **全負數矩陣的極值初始化地雷**：
   這是本題最經典的 Wrong Answer 陷阱。如果輸入的矩陣內**全都是負數**，那麼最大的子矩陣總和必然也是一個負數（即其中最大的那個單一負數）。
   * **原本寫法漏洞**：原程式碼中將最大值初始化設定為 `int max_sum = -127 * 100 * 100;`（即題目給定最小值 $-127$ 乘上最大可能格子數 $100 \times 100 = -1,270,000$）。這個範圍在數值上是安全的。
   * **核心邏輯盲點**：然而，原程式碼內層的 Kadane 邏輯是先更新 `max_sum` 再進行 `if (sum < 0) sum = 0;`。這在處理全負數矩陣時，第一個數字加進去後 `max_sum` 雖然會被正確更新為該負數，但隨後 `sum` 會立刻被強迫清空為 `0`。在處理下一個欄位時，`sum` 就會從 `0` 開始累加，如果第二個負數比第一個負數大，程式會誤將 `0 + 第二個負數` 當作解，這在某些全負數的幾何邊界上會引發極致的邏輯錯位。**最安全的作法是將 `max_sum` 初始設為 `INT_MIN`，且在全負數時不採取 `sum = 0` 的斷尾，或者直接利用前綴和特性處理**。
2. **1-indexed 陣列越界防禦**：
   為了方便計算前綴和免去邊界判斷，原程式碼採用了 1-indexed（從 1 到 $N$）。因此在宣告 `vector` 時，大小必須指定為 `n + 1`，且在相減時使用 `col_prefix[top - 1][col]`，這樣當 `top = 1` 時會正確減去第 0 列的 `0`，安全防禦完全符合預期。


## 程式碼實作
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n;
    // 連續讀入矩陣邊長 n，直到檔案結束 (EOF)
    while (cin >> n) {
        // 配置 (n+1) x (n+1) 的二維陣列，用來儲存各行的縱向累積前綴和
        vector<vector<int>> col_prefix(n + 1, vector<int>(n + 1, 0));
        
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                int val;
                cin >> val;
                // 預處理：當前格子的前綴和 = 上一格的前綴和 + 當前格子數值
                col_prefix[i][j] = col_prefix[i - 1][j] + val;
            }
        }
        
        // 初始化全域最大總和為極小值
        int max_sum = INT_MIN; 
        
        // 固定子矩陣的上邊界 top
        for (int top = 1; top <= n; top++) {
            // 固定子矩陣的下邊界 bottom
            for (int bottom = top; bottom <= n; bottom++) {
                
                int current_running_sum = 0;
                
                // 橫向利用 Kadane 演算法走訪各行 (Column Sweep)
                for (int col = 1; col <= n; col++) {
                    // 利用前綴和在 O(1) 時間內壓縮並抽取出該行在指定上下界內的數值總和
                    int col_sum = col_prefix[bottom][col] - col_prefix[top - 1][col];
                    
                    // 滾動累加
                    current_running_sum += col_sum;
                    
                    // 即時更新歷史最大子矩陣和
                    if (current_running_sum > max_sum) {
                        max_sum = current_running_sum;
                    }
                    
                    // 核心貪婪斷尾：若當前累積和已經變成負數，則對後續無益，立刻清零重來
                    if (current_running_sum < 0) {
                        current_running_sum = 0;
                    }
                }
            }
        }
        cout << max_sum << "\n"; 
    }
    return 0;
}
```


## 進階優化思考
本題採用的 $\mathcal{O}(N^3)$ 降維打法已經是此題標準的時間最優解。不過如果我們想把代碼架構寫得更具備強健性，可以引入一維 Kadane 的封裝化思維。

**函數模組化重構**

我們可以把核心的一維 Kadane 演算法單獨抽離成一個獨立的輔助函式。這不僅能大幅提高程式碼的清晰度，也能完美杜絕二維狀態下多重迴圈變數互相干擾的風險。

**優化程式碼片段：**
```cpp
// 獨立的一維 Kadane 演算法，輸入一個 vector，在 O(N) 內回傳最大連續子陣列和
int kadane(const vector<int>& arr) {
    int max_so_far = INT_MIN, current_max = 0;
    for (int num : arr) {
        current_max += num;
        if (max_so_far < current_max) max_so_far = current_max;
        if (current_max < 0) current_max = 0;
    }
    return max_so_far;
}

// 在主迴圈內部的調用方式：
for (int top = 1; top <= n; top++) {
    for (int bottom = top; bottom <= n; bottom++) {
        vector<int> compressed_row(n);
        for (int col = 1; col <= n; col++) {
            compressed_row[col - 1] = col_prefix[bottom][col] - col_prefix[top - 1][col];
        }
        // 直接調用，結構極其簡潔
        max_sum = max(max_sum, kadane(compressed_row));
    }
}
```
