# LeetCode 31 - Next Permutation


## 題目簡述

實作 **下一個排列（Next Permutation）** 函式，將給定的整數序列 `nums` 重新排列成字典序中的下一個更大的排列。<br>
如果不存在下一個更大的排列（也就是說，該序列已經是字典序中最大的排列，即完全降序排列），則必須將序列重新排列成**最小的排列**（即升序排列）。

> 必須 **原地（In-place）** 修改原陣列，只允許使用 $O(1)$ 的額外常數空間。

**Sample Input & Output**：

* **Example 1 :**
  * **Input :** `nums = [1,2,3]`
  * **Output :** `[1,3,2]`
  * **解釋 :**: `[1,2,3]` 的字典序下一個就是 `[1,3,2]`。

* **Example 2 :**
  * **Input :** `nums = [3,2,1]`
  * **Output :** `[1,2,3]`
  * **解釋 :** `[3,2,1]` 已經是最大排列，因此下一個排列會繞回最小的升序排列 `[1,2,3]`。

* **Example 3 :**
  * **Input :** `nums = [1,1,5]`
  * **Output :** `[1,5,1]`


## 程式碼

1. **核心思考方向**：<br>
   要找到下一個「剛好大一點點」的排列，意味著我們要儘量保持高位數（左邊）不變，從低位數（右邊）開始進行微調。基本思維可以拆解成以下三個極其優雅的步驟：

2. **步驟一：從右向左，尋找第一個「破壞降序」的相鄰元素（找轉折點）**：
   - 如果一小段序列是完全降序的（例如 `5, 4, 3, 2, 1`），它就已經是這幾個數字能組成的最大排列，不可能再變大了。
   - 所以我們從右往左掃描，找到第一個滿足 `nums[i] < nums[i + 1]` 的索引 `i`。此時，`i` 就是我們的**轉折點**。
   - 如果一整條序列都找不到這樣的轉折點（即一路降序到頭），說明整個陣列已經是全域最大（如 `[3,2,1]`），我們直接進到步驟三把整條序列翻轉即可。

3. **步驟二：從右向左，尋找第一個「大於轉折點」的數字並交換**：
   - 既然要讓數字變大，我們要在轉折點右側那段降序序列中，從右往左找，挑出第一個比 `nums[i]` 還要大的數字（設其索引為 `j`）。
   - 將 `nums[i]` 和 `nums[j]` 進行交換（`swap`）。此時，高位數微幅變大了。

4. **步驟三：將轉折點右側的序列「由降序轉為升序」（恢復最小狀態）**：
   - 剛才交換完後，轉折點右側的序列依然保持著降序特性。但為了讓增幅「剛好大一點點」，轉折點後面排出來的數字必須是**最小的可能組合**。
   - 要讓一段降序序列變成最小的升序序列，非常簡單，不需要重新排序（`sort`），直接用雙指針 **原地反轉（reverse）** 這段子序列即可！
  
5. **複雜度**：
   - **時間複雜度**： $O(N)$，最壞情況下只需對陣列進行兩次線性掃描與一次反轉。
   - **空間複雜度**： $O(1)$，完全在原陣列上進行指標比對與數據交換，滿足 In-place 規格。

```cpp
#include <vector>
#include <algorithm>

class Solution {
public:
    void nextPermutation(std::vector<int>& nums) {
        int n = nums.size();
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--; // 從右往左，找出第一個破壞降序趨勢的相鄰元素（尋找轉折點 i）
        }
        // 如果找到了合法的轉折點 i（若 i < 0 代表整個數組已經是最大降序排列）
        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) {
                j--; // 從最右側往左找，找出第一個大於 nums[i] 的元素 nums[j]
            }
            std::swap(nums[i], nums[j]); // 將兩者交換，微幅提升高位數的價值
        }
        std::reverse(nums.begin() + i + 1, nums.end()); // 將轉折點 i 右側的殘留降序序列原地反轉，重置為最小的升序狀態
    }
};
```
