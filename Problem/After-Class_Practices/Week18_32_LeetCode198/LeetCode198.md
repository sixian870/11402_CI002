# LeetCode 198 - House Robber


## 題目簡述

你是一名專業的小偷，計劃偷竊沿街的房屋。每間房屋都藏有一定的現金，影響你偷竊的唯一制約因素就是：**相鄰的房屋裝有相互連通的防盜系統，如果兩間相鄰的房屋在同一天晚上被小偷闖入，系統就會自動報警**。<br>
給定一個代表每間房屋存放金額的非負整數陣列 `nums`，計算你 **在不驚動警報裝置的情況下**，一夜之內能夠偷竊到的 **最高金額**。

**Sample Input & Output**：

* **Example 1 :**
  * **Input :** `nums = [1,2,3,1]`
  * **Output :** `4`
  * **解釋 :** 
    - 最佳策略：偷竊 1 號房屋 (金額 = 1) ，然後偷竊 3 號房屋 (金額 = 3)。
    - 偷竊到的最高金額 = $1 + 3 = 4$。

* **Example 2 :**
  * **Input :** `nums = [2,7,9,3,1]`
  * **Output :** `12`
  * **解釋 :** 
    - 最佳策略：偷竊 1 號房屋 (金額 = 2), 偷竊 3 號房屋 (金額 = 9)，接著偷竊 5 號房屋 (金額 = 1)。
    - 偷竊到的最高金額 = $2 + 9 + 1 = 12$。


## 程式碼

1. **核心動態規劃思考**：<br>
   當我們走到第 `i` 間房屋面前時，面臨著兩種抉擇：
   - **抉擇 A（偷當前這間）**：既然偷了第 `i` 間，那相鄰的第 `i - 1` 間就絕對不能碰。此時的最大收益為：前 `i - 2` 間房屋能偷到的最大累積金額 + 當前房屋的財富 `nums[i]`。
   - **抉擇 B（不偷當前這間）**：如果不碰第 `i` 間，那我們的最高收益就會直接承襲「前 `i - 1` 間房屋所能偷到的最高金額」。
   小偷極其貪婪，理所當然會在這兩個方案中挑選金額最大（`max`）的那一個。

2. **狀態轉移方程式**：<br>
   定義 `dp[i]` 代表巡邏完前 `i` 間房屋所能洗劫的最大總額：
   $$\text{dp}[i] = \max(\text{dp}[i - 1], \text{dp}[i - 2] + \text{nums}[i])$$

3. **核心空間壓縮：雙變數滾動優化**：
   - 傳統作法會配置一個與 `nums` 大小相同的 `dp` 陣列，這會帶來 $O(N)$ 的空間開銷。
   - 觀察公式可以發現，要推導出當前的 `dp[i]`，我們其實**只需要前兩項的歷史數據**。
   - 因此，我們可以捨棄整條陣列，改用兩個整數變數 `prev2` 和 `prev1` 來動態記錄狀態：
     - `prev2` 代表 `dp[i - 2]`（初始化為 `0`）。
     - `prev1` 代表 `dp[i - 1]`（初始化為 `0`）。
   - 每來到一間新房屋，就用公式算出最新總額 `current`，並將兩個變數像輪子一樣向後平移滾動：`prev2 = prev1; prev1 = current;`。

4. **複雜度分析**：
   - **時間複雜度**： $O(N)$，其中 $N$ 是房屋的總數。只需要用一個 `for` 迴圈從頭到尾線性掃描一遍。
   - **空間複雜度**： $O(1)$。將快取極致壓縮至兩個常數級的滾動變數，不浪費任何額外記憶體。



```cpp
#include <vector>
#include <algorithm>

class Solution {
public:
    int rob(std::vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        int prev2 = 0; // 代表 dp[i - 2]，即前前一間的最高收益
        int prev1 = 0; // 代表 dp[i - 1]，即前一間的最高收益
        for (int num : nums) {
            int current = std::max(prev1, prev2 + num); // 不偷當前這間 (prev1) vs 偷當前這間 (prev2 + num)
            prev2 = prev1;
            prev1 = current;
        }
        return prev1; // prev1 內儲存的就是洗劫最大總額
    }
};
```
