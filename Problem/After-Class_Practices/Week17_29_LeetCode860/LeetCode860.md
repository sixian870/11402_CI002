# LeetCode 860 - Lemonade Change


## 題目簡述

在一家檸檬水攤位，每杯檸檬水的售價為 `5` 美元。顧客排隊購買，一次只買一杯。<br>
每位顧客只會向你支付一張面額為 `5` 美元、`10` 美元或 `20` 美元的鈔票。你必須給每位顧客正確的找零（例如顧客付 10 美元，你需要找零 5 美元；付 20 美元，你需要找零 15 美元）。<br>
注意：一開始你手裡**沒有任何零錢**。<br>
如果你能為每位顧客正確找零，回傳 `true`；否則，回傳 `false`。

**Sample Input & Output**：

* **Example 1 :**
  * **Input :** `bills = [5,5,5,10,20]`
  * **Output :** `true`
  * **解釋 :**
    - 前 3 位顧客各付 5 美元，你收入 3 張 5 美元。
    - 第 4 位顧客付 10 美元，你找零一張 5 美元（手中剩餘 2 張 5 美元、1 張 10 美元）。
    - 第 5 位顧客付 20 美元，你找零一張 10 美元和一張 5 美元（正確找零 15 美元）。<br>
    所有顧客都能正確找零，回傳 `true`。

* **Example 2 :**
  * **Input :** `bills = [5,5,10,10,20]`
  * **Output :** `false`
  * **解釋 :**
    - 前 2 位顧客各付 5 美元，收入 2 張 5 美元。
    - 接下來 2 位顧客各付 10 美元，你各找零一張 5 美元（此時手中 5 美元已耗盡，剩 2 張 10 美元）。
    - 最後一位顧客付 20 美元，你需要找零 15 美元（你需要一張 10 元和一張 5 元，或者三張 5 元），但你手裡只有 10 美元，無法找零。因此回傳 `false`。


## 程式碼

1. **核心思考方向**：<br>
   我們不需要記下 20 美元有幾張，因為 20 美元是最大面額，我們不可能拿它來找零給任何人。我們只需要專心記住目前手頭上 **5 美元** 和 **10 美元** 的張數。

2. **貪婪演算法的抉擇：為什麼收到 20 元時，要優先消耗 10 元？** <br>
   當顧客付 20 美元時，我們必須找零 15 美元。此時有兩種找零方案：
   - **方案 A**：找一張 `10` 美元和一張 `5` 美元。
   - **方案 B**：找三張 `5` 美元。
   
   **核心貪婪關鍵**：`5` 美元是萬能的零錢（能找給 10 元也能找給 20 元），而 `10` 美元只能找給 20 元。因此，**5 美元的市面流通價值遠高於 10 美元**！<br>

   為了給後面的顧客留條活路，當下能把 10 美元用掉就先用掉。這就是典型的貪婪思維：**遇到 20 元時，優先採取方案 A；若 10 元不夠，才退而求其次採取方案 B**。

4. **複雜度分析**：
   - **時間複雜度**： $O(N)$，其中 $N$ 是 `bills` 陣列的長度。我們只需要用一個 `for` 迴圈線性巡邏每一位排隊的顧客。
   - **空間複雜度**： $O(1)$。只需要兩個整數變數 `five` 和 `ten` 來累加鈔票張數，不需要任何額外的容器空間。

```cpp
#include <vector>

class Solution {
public:
    bool lemonadeChange(std::vector<int>& bills) {
        int five = 0; // 記錄手中 5 美元的張數
        int ten = 0;  // 記錄手中 10 美元的張數
        
        for (int bill : bills) {
            // 收到 5 美元
            if (bill == 5) {
                five++;
            }
            // 收到 10 美元（需找零 5 美元）
            else if (bill == 10) {
                if (five == 0) return false; // 沒 5 元可找，直接宣告破產
                five--;
                ten++;
            }
            // 收到 20 美元（需找零 15 美元）
            else if (bill == 20) {
                // 優先使用 10 + 5 的組合，把萬能的 5 元儘量留在手裡
                if (ten > 0 && five > 0) {
                    ten--;
                    five--;
                }
                // 若沒有 10 元，才退而求其次消耗三張 5 元
                else if (five >= 3) {
                    five -= 3;
                }
                // 零錢組合不出來，找零失敗
                else {
                    return false;
                }
            }
        }
        return true;
    }
};
```
