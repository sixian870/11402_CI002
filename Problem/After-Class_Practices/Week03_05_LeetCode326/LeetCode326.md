# LeetCode 326 - Power of Three


## 題目簡述

給定一個整數 `n`，如果它是 `3` 的冪次方，回傳 `true`；否則，回傳 `false`。<br>
如果存在一個整數 `x` 使得 $n = 3^x$，則整數 `n` 就是 `3` 的冪次方。

**Sample Input & Output**：

* **Example 1 :**
  * **Input :** `n = 27`
  * **Output :** `true`
  * **解釋 :** $27 = 3^3$。

* **Example 2 :**
  * **Input :** `n = 0`
  * **Output :** `false`
  * **解釋 :** 不存在任何整數 $x$ 使得 $3^x = 0$。

* **Example 3 :**
  * **Input :** `n = -1`
  * **Output :** `false`
  * **解釋 :** 3 的任何整數次方的結果皆為正數。


## 程式碼

1. **直覺的迴圈做法 $O(\log_3 n)$**：<br>
   我們可以用一個 `while` 迴圈不斷將 `n` 除以 3，只要過程中 `n % 3 != 0` 就代表它不是 3 的冪次方。雖然符合直覺，但這需要消耗對數時間。
   
2. **整數範圍內最大權值破局法**：
   - 由於輸入的 `n` 是一個標準的 32 位元有號整數（`int`），這代表 `n` 的最大可能值被限制在 `2147483647`（即 `INT_MAX`）以內。
   - 在 32 位元整數的合法範圍內，**3 的最大整數冪次方**是 $3^{19} = 1162261467$（下一階 $3^{20}$ 就會超過 `INT_MAX` 溢位了）。
   - 因為 3 是一個質數（Prime Number），這意味著 **$3^{19}$ 的所有正因數（Divisors），通通都必須是 3 的冪次方**（例如 1, 3, 9, 27...）。
   - 因此，我們只需要先防禦 `n <= 0` 的狀況，接著直接檢查 **$1162261467$ 能不能被 `n` 整除（`1162261467 % n == 0`）**。如果可以，`n` 就絕對是 3 的冪次方。
  
3. **複雜度**：
   - 時間複雜度： $O(1)$，只有一次模運算（Modulo），達到最極致的常數時間。
   - 空間複雜度： $O(1)$，完全不需要額外的記憶體空間。

```cpp
class Solution {
public:
    bool isPowerOfThree(int n) {
        if (n <= 0) {
            return false; // 小於或等於 0 的整數絕對不可能是 3 的冪次方
        }
        // 1162261467 是 3^19，也就是 32 位元 signed int 範圍內最大的 3 的冪次方，因為 3 是質數，只要 n 是 3 的冪次方，就一定能整除這個最大數。
        return 1162261467 % n == 0;
    }
};
```
