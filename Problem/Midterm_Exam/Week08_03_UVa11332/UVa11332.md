# UVa 11332 - Summing Digits

## 題目簡述

給定一個正整數 $n$，定義 $f(n)$ 為 $n$ 的各個位數總和。<br>
如果 $f(n)$ 計算出來的結果只有一位數，那麼這就是最終答案；如果大於等於 10（超過一位數），則必須將結果再次代入 $f(n)$ 計算，不斷重複這個步驟，直到結果縮減為單一數字為止。

**Sample Input**：

  **2** $\rightarrow$  第一個 $n$。<br>
  **11** $\rightarrow$  第二個 $n$。<br>
  **47**<br>
  **0** $\rightarrow$  輸入 0 結束。

**Sample Output**：

  **2** $\rightarrow$ $f(2) = 2$ <br>
  **2** $\rightarrow$ $f(11) = 1 + 1 = 2$ <br>
  **2** $\rightarrow$ $f(47) = 4 + 7 = 11$  $\rightarrow$ $f(11) = 1 + 1 = 2$


## 解題思路與考點分析

### 核心觀念：數值位數拆解與遞迴收斂
這道題目的本質是**基礎數學模擬與動態縮減（Digit Sum Evolution）**。
在數學上，這個不斷將各位數相加直到剩下個位數的過程，其最終結果被稱為該數字的 **「數位根」（Digital Root）**。

在演算法設計上，可以將其拆解為兩個核心步驟：
1. **位數分離技術（Digit Extraction）**：
   
   要取得一個十進位整數的各個位數，最經典的作法是利用算術運算子：
   * 利用 `% 10` 取出當前數字的最低位（個位數）並加入累加器。
   * 利用 `/ 10` 將已經處理完的個位數直接砍掉（向右位移一位）。
   * 重複上述動作直到數字變為 0，即可完整剝離出所有位數。
2. **多階段迭代收斂（Iterative Convergence）**：
   主程式維持一個監聽迴圈，只要 $n \ge 10$，代表其尚未縮減至個位數，就必須強迫將當前的 $n$ 代入位數加總副程式中進行覆蓋更新：`n = f(n)`。此過程在數學上保證必定會快速收斂至 1 到 9 之間的單一數字。


## 複雜度分析

* **時間複雜度**： $\mathcal{O}(\log_{10} n)$
  對於一個正整數 $n$，其總位數為 $\lfloor\log_{10} n\rfloor + 1$。位數加總副程式內部的 `while` 迴圈執行次數與位數呈線性正比。由於每次迭代都會使數字的位數劇烈萎縮（例如最大輸入 $2 \times 10^9$ 的各位數總和最大也僅為 $9 \times 10 = 90$），第二次迭代時便能在常數時間內直接收斂完畢。因此總時間複雜度約為 $\mathcal{O}(\log_{10} n)$，可在微秒內瞬間執行完畢。
* **空間複雜度**： $\mathcal{O}(1)$
  僅使用固定數量的純量變數（`n`, `sum`）進行數值滾動迭代，沒有開闢任何動態陣列或記憶體緩衝區，空間開銷為完美的固定常數。


## 邊界條件與潛在陷阱

1. **資料範圍與整數溢位防禦**：
   題目規範輸入的 $n$ 最大可達到 $2,000,000,000$。這個範圍非常逼近標準 32 位元有號整數（`int`）的極限上限（約 $2.14 \times 10^9$）。雖然使用 `int` 理论上勉強不會溢位，但**為了維持程式碼的強健性與防禦性，強烈建議將輸入變數 `n` 宣告為 `long long`**。原程式碼的資料型態防禦非常嚴密。
2. **輸入終止符 0 的精確攔截**：
   最外層必須使用 `while (cin >> n && n != 0)` 進行精確控制。當讀到 0 時應立即煞車結束程式，不應將 0 當作合法資料代入後續的計算中。
3. **單一數字輸入（ $n < 10$ ）**：
   若輸入本身就已經是個位數（如 Sample 1 的 `2`），內層的 `while (n >= 10)` 條件會直接不成立，迴圈不執行，程式會毫無阻礙地直接印出原始數字 `2`，邏輯完全相容。


## 程式碼實作

```cpp
#include <bits/stdc++.h>
using namespace std;

// 副程式 f()：利用算術位移剝離法，計算並回傳 n 的各位數總和
long long f(long long n) {
    int sum = 0;
    while (n > 0) {
        sum = sum + n % 10; // 取出當前的個位數進行累加
        n = n / 10;         // 消除已被統計的個位數 (向右截斷)
    }
    return sum;
}

int main() {
    // 提升標準 I/O 串流之效能
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    long long n;
    // 持續讀入正整數 n，直到讀取到 0 時代表輸入結束
    while (cin >> n && n != 0) {
        
        // 只要 n 依然大於或等於 10 (即超過一位數)，就持續反覆調用副程式進行縮減
        while (n >= 10) {
            n = f(n); // 以新產生的各位數和覆蓋舊值
        }
        
        // 輸出縮減至最後唯一的單一數位根結果
        cout << n << "\n";
    }
    return 0;
}
```


## 進階優化思考

存在一個完全不需要任何迴圈與副程式，在 $\mathcal{O}(1)$ 常數時間內直接秒殺答案的終極數學公式解。

**同餘理論與數位根公式（Digital Root Theorem）**

在數論中，任何一個十進位正整數與其各位數之和，在模 9（Mod 9）的系統下是完全同餘的（因為 $10 \equiv 1 \pmod 9$ ， $100 \equiv 1 \pmod 9$ ，以此類推）。這代表著，一個數字不斷重複加總各位數直到最後剩下一位數的結果，實質上就是該數字除以 9 的餘數！唯一的幾何修正點在於：如果一個數字剛好能被 9 整除（餘數為 0），因為最終縮減結果不可能是 0（正整數的位數和必大於 0），其對應的數位根應該是 9。

**優化程式碼實作片段：**
```cpp
while (cin >> n && n != 0) {
    // 數位根公式：若能被 9 整除則結果為 9，否則結果為 n % 9
    long long ans = n % 9;
    if (ans == 0) {
        cout << 9 << "\n";
    } else {
        cout << ans << "\n";
    }
    
    // 亦可精簡寫成一行流公式：cout << (n - 1) % 9 + 1 << "\n";
}
```
* **效能改善**：此重構版本將演算法的時間複雜度直接推向了物理極限的 $\mathcal{O}(1)$，且完全消除了副程式的調用框架與內部 while 迴圈的算術開銷。整條代碼簡化至極致，在面對海量數據流或極端巨大的超長整數時，能展現出數學理論無可比擬的優雅與速度。
